## 当前研究版本

正文主题为药监局、医保局、卫健委在安全性、有效性、经济性、创新性与公平性上的注意力配置差异。三部门51项来源对应4481条；另4项中央综合政策仅作背景。

原4481条全量结果完整保留。原200条的真人独立判读性质，以2026年10月14日用户更正及对应核查说明为准；该批材料后来用于规则修复，第六轮规则成绩属于开发诊断。AI独立复核另行保存。122条补充材料暂不发放。当前主方法选择仍待确认，不能把最新局部规则结果与旧全量结果拼成同一版本。

历史文档保留原题名及当时表述。旧归档中“最新”“最终”“交稿”等字样是历史文件名；判断当前状态请以本入口及10月15日记录为准。本次工作只整理和备份，没有改动研究标签、重跑分析或替研究者选择主方法。
