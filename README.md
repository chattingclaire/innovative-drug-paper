## 当前研究版本

正文主题为药监局、医保局、卫健委在安全性、有效性、经济性、创新性与公平性上的注意力配置差异。三部门51项来源对应4481条；另4项中央综合政策仅作背景。

最终稿采用4481条全量分析及466条人工核验，LLM为主要分析方法，规则编码用于方法比较。人工核验、误判与漏判实例、主方法选择依据集中于第4.2节；主要图表展示LLM，完整规则对照见补充材料E。相关数据未因本轮文字与呈现调整而重跑或改动。

主稿19页，软件统计14,327字/词，补计图中文字保守约14,707；7页补充材料另附。投稿前尚需作者审读、确定通信作者和确认补充材料提交方式。

当前版本以本入口及[当前论文状态](00-阅读入口/当前论文状态.md)为准。历史文档中的“最新”“最终”和待办均按其形成日期理解。10月16日完整归档快照继续保留，本次10月19日交付单独增补于`01-当前论文/最终稿-20261019`。
