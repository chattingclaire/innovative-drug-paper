## 当前研究版本

正文主题为药监局、医保局、卫健委在安全性、有效性、经济性、创新性与公平性上的注意力配置差异。三部门51项来源对应4481条；另4项中央综合政策仅作背景。

77条校准样本由人工独立编码，用于校准编码方案和判定标准；466条用于独立人工检验，4481条用于全量分析。三类材料的用途见[研究设计与材料](02-研究设计与材料/README.md)。

最终稿采用4481条全量分析及466条人工核验，LLM为主要分析方法，规则编码用于方法比较。人工核验、误判与漏判实例、主方法选择依据集中于第4.2节；主要图表展示LLM，完整规则对照见补充材料E。相关数据未因本轮文字与呈现调整而重跑或改动。

最新收录正文为10月30日投稿稿四文件包，按用户提供的修订版、清洁版和修改说明分别保留。此前登记的14,985字属于10月21日版本信息，不作为新稿的字数。本轮只归档和上传，不改变原文件；历史补充材料、数据与代码不覆盖、不重跑，也不自动标记为10月30日重新核验版。

当前版本以本入口及[当前论文状态](00-阅读入口/当前论文状态.md)为准。历史文档中的“最新”“最终”和待办均按其形成日期理解。10月16日完整归档快照继续保留，10月19日和10月29日稿各自留存，最新收录正文位于`01-当前论文/科技管理研究投稿稿-20261030`。
