## 一、来稿构成

［版式］来稿应包括9部分：①正文题名；②文章署名；③中英文摘要；④中英文关键词；⑤中图分类号；⑥文献标识码；⑦作者简介；⑧正文；⑨参考文献。

## 二、题名

| 条目 | 要求 | 出处 |
|---|---|---|
| 字数 | **不得超过20字** | 版式 |
| 字数（另一说） | 一般不应超过15个字 | 启事 |
| 用语 | 言简意赅，切中选题；避免标点符号及非公知、公用的缩略词、代号 | 版式／启事 |
| 禁用谦词 | **不能包含"一种""一类""初探""之我见""刍议""浅析"之类谦词** | 模板 |
| 中英文 | 须用中英文两种文字书写，英文题名置于英文摘要上方 | 版式 |
| 英文题名 | 实词需大写；第1个词不得用 A／An／The／And | 版式 |

## 三、署名与作者简介

| 条目 | 要求 | 出处 |
|---|---|---|
| 多作者 | 中间用空格隔开 | 版式 |
| 英文署名 | **姓大写；名有两个字时第一个首字母大写，两名之间用"-"链接，如 LI Zi-mu**；多作者用逗号隔开；置于英文题名下方居中 | 版式 |
| 作者简介格式 | **姓名（出生年－），性别，籍贯（具体到县或市），工作单位，职称职务，研究方向** | 版式 |
| 范例 | 李子木（1957-），女，河南郑州人，西南交通大学公共管理学院教授，研究方向：公共管理。 | 版式 |
| 须全 | 需要**所有署名人**的作者简介，按第一、第二、第三作者顺序排列 | 版式／模板 |
| 籍贯 | 模板口径为"精确到县" | 模板 |

## 四、摘要 ⚠️ 两处官方口径不一致

| 条目 | 要求 | 出处 |
|---|---|---|
| 中文字数 | **限制在200字以内** | 版式 |
| 中文字数（另一说） | **在150－300字以内** | 启事 |
| 英文字数 | **限制在200个单词以内** | 版式 |
| 人称 | **以第三人称撰写，不使用第一人称，如"本文""我们"** | 版式 |
| 人称（启事） | 以第三人称对全文内容准确概括，**禁用"本文""笔者"等主语** | 启事 |
| **不写背景** | **摘要部分不需要介绍研究背景** | 版式 |
| 内容（版式） | ①主要研究内容；②**论文的创新点和主要结论**；③主要政策建议或对实践的指导作用；④有待进一步研究和完善之处 | 版式 |
| 内容（模板） | (1) 用什么具体方法或技术进行了什么研究，要解决什么问题；(2) 研究取得了哪些结果；**(3) 进行的研究有何创新、价值** | 模板 |
| 英文摘要 | 一定要通顺、准确，并与中文摘要保持对应 | 版式／模板 |

## 五、关键词

- 以3个为宜，**最多不超过5个**，之间以分号分开［版式／模板］
- 启事口径：3－5个［启事］
- 须中英文两种文字；英文关键词小写（专有名词除外），置于英文摘要之下［版式］

## 六、中图分类号与文献标识码

- 中图分类号可网上查到，与文献标识码列在一行标示［版式］
- 文献标识码分类［版式］：**A**－理论与应用研究学术论文；B－理论学习与社会实践总结；C－业务指导与技术管理性文章；D－动态性信息；E－文件、资料

## 七、正文

| 条目 | 要求 | 出处 |
|---|---|---|
| 字体 | 五号宋体，段前空两格，行距最小值18－20磅；英文用五号 Times New Roman | 版式 |
| 标题层级 | 一号标题 `1`；二号标题 `1.1`；三号标题 `1.1.1` | 版式 |
| **段落内序号** | **宜用①②③表示** | 版式 |
| **时间、数目连接号** | **统一用"-"**。例：亩产1000公斤-1500公斤；每年10%-20%；**1997-2002年** | 版式 |
| 百分数 | "1%"、"1%－5%"、"提高1个百分点" | 版式 |
| 倍数分数 | "1倍"、"1/3" | 版式 |
| 缩写 | 须在中文全称或英文全称出现后加括号表明，之后连续使用；**切忌文中第一次出现即为缩写**。缩写词均大写，英文缩写的解释统一用小写 | 版式 |
| 公式 | 另起，前空两格或四格，靠右对齐；顺序编号（1）（2）；文中引用统一用"**式（1）**"，不可写"一式""1式""（1）式" | 版式／模板 |
| 变量 | 公式及正文变量用**斜体**，数学符号和数字用正体，矩阵用加粗黑体斜体；同一字母不得有两种含义 | 版式／启事 |
| 脚注 | 可用脚注，标号①②③连续编码 | 版式 |
| **基金标示** | **受基金支持的文章应用脚注标示**，脚注内容为基金名称+项目号，多个基金用"；"隔开 | 版式／模板 |
| 篇幅 | 以10000～15000字为宜 | 启事 |
| 正文引用 | 形如：张国宝（2008）[1]认为……总之（徐飞等 1998[4]；章新峰 2010[5]） | 模板 |

## 八、图表

| 条目 | 要求 | 出处 |
|---|---|---|
| **中英文题名** | **图表均须编号，并有题目的中英文、资料来源** | 启事 |
| 表名位置 | **位于表的正上方居中** | 模板 |
| 图名位置 | **位于图的正下方居中** | 模板 |
| 图表文字 | **图表中文字必须用中文** | 启事 |
| 小数位 | 表中数字最多保留小数点后3位，同一表中小数位数尽量一致 | 启事 |
| 单位 | 单位及符号齐全，可在表题后标"单位：×××" | 启事／模板 |
| 表注 | 以"注："起行置于表下 | 模板 |

## 九、参考文献

| 条目 | 要求 | 出处 |
|---|---|---|
| **数量** | **不得少于15篇，且最近三年的文献不得少于5篇** | 版式 |
| **中文须附英译** | **中文文献要一并翻译成相应的英文，紧随其后排列**；译后姓首字母大写，名只写首字母 | 版式 |
| 范例 | 张国宝.对石油市场及油价问题的看法[J].管理世界,2008,5:5-10.<br>Zhang G B. Some Advices for Oil Market and Oil Price [J]. Management World, 2008,5:5-10. | 版式 |

**著录格式**［启事］

  [序号] 主要责任者．文献题名［J］．刊名，年，卷（期）：起止页码．

  [序号] 析出文献主要责任者．析出文献题名［A］．原文献主要责任者．原文献题名［C］．出版地：出版年．析出文献起止页码．
报纸文章[N]

  [序号] 主要责任者．电子文献题名［电子文献及载体类型标识］．出处或获得地址，发表或更新日期／引用日期．

  [序号] 主要责任者．文献题名［Z］．出版地：出版者，出版年．

## 十、投稿与评审

| 条目 | 要求 | 出处 |
|---|---|---|
| **匿名评审** | 采用匿名评审制度。**须将文题、摘要、关键词、英文对照、作者单位通讯地址邮编、联系电话传真、E-MAIL 等信息单独写一页**；正文中的文题、全文和参考文献须去掉相关信息 | 启事 |
| **文件大小** | **上传稿件最好不要超过2M**，过大将影响审稿与刊用 | 指南 |
| 投稿方式 | 只接受网站投稿：www.kxjcm.com，先注册再投稿 | 启事／指南 |
| 退修 | 修改稿经[稿件管理]→[上传/下载修改稿]回传，**不可再用投稿功能**（否则视为新稿，原审稿结果作废） | 指南 |
| 联系方式 | 编辑部电话 010-52893585；邮箱 kxjcm1@126.com；地址：北京市海淀区阜成路14号 | 启事 |
| 刊登范围 | 只刊登科学决策研究领域专题成果，**不发表时评、漫谈、零讯一类稿件** | 启事 |
| 稿件要求 | 围绕经济管理决策中的实际问题，数据可靠、论证周密、语言通顺、文字简练；鼓励定性与定量结合 | 启事 |
