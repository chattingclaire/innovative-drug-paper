## 一、维度框架与依据（论述时必须写清楚的）

**采用的框架**：安全性、有效性、经济性、创新性、公平性五个维度。

**依据**（均已核对原件，2023、2024、2026 三版一致）：

| 维度 | 申报指南原文界定 |
|---|---|
| 安全性 | 药品说明书收载的安全性信息；该药品在国内外不良反应发生情况；与目录内同类药品安全性方面的主要优势和不足 |
| 有效性 | 临床试验和真实世界中，与对照药品疗效相比较该药品的主要优势和不足；临床指南/诊疗规范推荐情况；国家药监局药品审评中心出具的《技术评审报告》中关于本药品有效性的描述；与目录内同治疗领域药品相比该药品有效性方面的优势和不足 |
| 经济性（目录内申报药品提供） | 本次协议期内大陆地区药品销售金额、当前价格费用情况、预计未来两年销量和对医保基金的影响 |
| 创新性 | 主要创新点；该创新带来的疗效或安全性方面的优势；是否为自主知识产权的创新药；药品注册分类 |
| 公平性 | 是否能够弥补药品目录短板；临床管理难度及其他相关情况；目录外药品还需提供价格费用（单价、日均或疗程费用、参照药品价格费用） |

## 二、编码标准仍需修订（词典 v3 试跑后发现）

- [ ] **创新性共现规则过宽**：336 个命中里 69 个由“创新/新药 + 药/研发/产品”规则产生，其中包含“支持中药传承和创新”“鼓励采购使用疗效明确、价格合理的新药”“与改良型新药对比分析”等误判。收紧为：创新药、创新性、创新点、自主知识产权、研发创新、注册分类1类、突破性治疗、优先审评、附条件批准、临床急需、未满足需求。
- [ ] **经济性把“支付范围”计入**：45 句仅因出现“支付范围”而计入经济性，但支付范围是准入范围而非价格费用。规则改为必须出现价格、费用、成本、金额、基金、预算、销量、支付标准之一。
- [ ] **语料未清洗**：命中维度的 1195 句中有 327 句（27.4%）是标题、目录页、条目号或带页码的碎片。需制定清洗规则（剔除或单独统计），并在 4.1 说明。
- [ ] **有效性规则复核**：已要求“临床试验/真实世界”与疗效类词共现，仍有目录页误命中，随清洗一并处理。
- [ ] **安全性排除语境**已加（安全感、数据安全、生产安全等），复核后保留。
