# AIGC 自检（本地开源工具）

工具：Fast-DetectGPT（ICLR 2024，github.com/baoguangsheng/fast-detect-gpt），采样差异度 analytic 版
打分模型：Qwen/Qwen2.5-0.5B　运行：本机 M4 / MPS　日期：2026-09-14
对象：0914论文修订稿4（接受全部修订后的正文），按段落切分，剔除表题图题与参考文献

## 方法

语言模型逐字读一段文字，在每个位置计算三个量：实际出现字符的对数概率 `logp_x`；
该位置的期望对数概率 `μ = Σ p·log p`；方差 `σ² = Σ p·(log p)² − μ²`。标准化后得分数

```
d = (logp_x − Σμ) / √(Σσ²)
```

d 越大，说明文本比模型自身随机采样还要"典型"，越接近 LLM 输出；d 越小，说明出现大量模型意外的词。
零样本方法，不需训练分类器，也不需见过特定模型的输出。

## 局限

1. **面向英文校准**，中文分数不能对照其公布阈值判读，此处仅作相对比较。
2. **打分模型仅 0.5B**，换模型分数会整体平移。
3. **低分不等于人写**，句子长、术语密、信息量大也会拉低分数。
4. **与学校检测无对应关系**。知网／维普方法闭源、语料不同，本结果不能预测其判定，批注 #153 仍须用学校指定工具完成。
5. **本文语料上已见两处误判**：全文最高分（1.00）是原稿 5.2 一段人写的①②③列举；附录 A 中引用的 LLM 系统提示词（确为机器文本）仅列第 2（0.85）。

因此本结果的可用之处限于：定位需要人工复看的段落，以及在改写时提供"是否越改越糟"的反馈——第二轮的撤销即由此而来。
