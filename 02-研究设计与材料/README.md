## 样本及用途

| 材料 | 编码方式 | 用途 |
| --- | --- | --- |
| 77条校准样本 | 人工独立编码 | 校准编码方案和五维判定标准 |
| 466条检验样本 | 两名编码者分别独立判读，保留讨论、合并前各自的A、B结果 | 独立人工检验，形成供模型结果对照的最终人工参考编码 |
| 4481条全量材料 | LLM编码为主要分析，规则编码用于比较 | 分析三部门五维评价内容及注意力配置差异 |

77条人工独立编码用于开发校准，与466条独立检验的用途不同。两名编码者之间的κ使用讨论、合并前各自的人工结果计算；模型对人工的κ使用模型结果与最终人工参考编码计算。

77条的人工独立编码性质及466条的最终人工判读流程，已由作者于2026年10月21日确认。本次明确材料性质和用途，不变更已保存的编码值和统计值。
