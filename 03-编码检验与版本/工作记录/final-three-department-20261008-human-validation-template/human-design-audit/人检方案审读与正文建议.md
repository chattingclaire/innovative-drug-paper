## 可直接接入正文的短段落

**样本与流程：** 人工复核采用预先冻结的240条材料，每部门80条。两名真人编码员依据统一五维手册独立编码；封存原始提交并计算裁定前一致性后，由真人裁决分歧。样本按部门先在剩余正文族中等概率不放回抽取80族，再于每族随机抽取1条。药监、医保、卫健抽样框分别含1031、841、140族，对应1044、1113、140个单元。族内有k条、部门有F族时，单元入样概率为80/(Fk)，分析权重为Fk/80。结果回收并核验前，人工一致性及方法对人工的分类指标均待填。

**指标与区间：** 以设计加权四格计算Cohen κ及精确率、召回率和F1；设计权重不属于有序类别加权κ。拟以部门为层、正文族为初级抽样单位，每次在每层已抽80族中有放回抽取79族，将原权重乘以80/79及抽中重数，不作有限总体校正；5000次重算指标，以2.5%和97.5%分位数给出近似95%区间。未知标签与零分母显式标记NA。该区间近似不构成完整两阶段设计的精确覆盖保证。[Bessonneau等（2021），§3.1式(3.1)、§3.3](https://www150.statcan.gc.ca/n1/pub/12-001-x/2021002/article/00005/03-eng.htm)

**范围：** 人工复核对应排除既往开发、培训正文族及跨部门共有正文族后的剩余单元框；来源全文可能曾出现于培训上下文，不能称为新文档外部验证。全量4481条机器编码描述所收集文本；240条人工复核及其推断范围另列。

## 独立数学推导

以下推导是本次对实际两阶段设计的独立核查，不是声称文献逐字给出此特例。设某部门共有F族，抽n=80族。族j有k_j条，真实族总量T_j=Σ_i y_ji；族内均匀抽一条后的观测贡献Z_j=k_j y_j。则E₂Z_j=T_j，V_j=Var₂(Z_j)。令S_T²为F个族真实总量的有限总体方差（分母F−1），s_Z²为抽中n个观测贡献的样本方差（分母n−1）。假设不同族的第二阶段抽样独立、标签视为固定有限总体值。

总量估计为 T̂=(F/n)Σ_s Z_j。由全方差公式：

```
Var(T̂) = F²(1−n/F) S_T²/n + (F/n) Σ_{j=1}^F V_j
E(s_Z²) = S_T² + (1/F) Σ_{j=1}^F V_j
V̂_WR = F² s_Z²/n
E(V̂_WR) − Var(T̂) = F S_T² ≥ 0
```

因此，一族一条时不能单独无偏估计每个族的内部方差，但第二阶段噪声已经进入观测族贡献的样本方差；不能据此断言任何区间都不可估。上述非负差是对重复两阶段抽样取期望的**线性总量方差**性质，不表示每次观测的方差估计都大于真值，也不保证非线性κ、P/R/F1或比率的percentile区间至少覆盖95%。尤其卫健抽样比4/7较大，不FPC可能明显增加线性方差近似；不能把它写成普遍保守区间。[文献§6也明确区分大抽样比下方差性质与其他区间的覆盖问题](https://www150.statcan.gc.ca/n1/pub/12-001-x/2021002/article/00005/06-eng.htm)。

每次从n个已观察族中抽m=n−1=79次，M_j为重数，w_j*=w_j(n/m)M_j。则 T̂*=(F/m)Σ_draw Z_j，E_*T̂*=T̂，且：

```
Var_*(T̂*) = F²/m × ((n−1)/n) s_Z² = F²s_Z²/n = V̂_WR
```

这解释了79次及80/79重标的组合。若直接抽80次、原权重仅乘重数，其复制方差为上述估计的79/80，不能声称严格复现同一WR方差。实际抽样仍为80族不放回，bootstrap重抽79族并不改变真实抽样设计。多部门总量方差可按独立层求和；所有人工与机器方法必须共用同一组族重数以保留配对关系。这里的族是规范化正文族，不是政策文件。
