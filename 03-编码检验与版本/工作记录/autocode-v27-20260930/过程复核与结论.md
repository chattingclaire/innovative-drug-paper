# 自动规则五维编码：过程复核与现阶段结论

口径：CAL-5D-20260926-v1.3；分析单位为政策文本句/条。A、C 是按人工编码手册工作的 **AI 编码员**，不是两名真人编码员。本文所有对 A/C 的 κ 均为规则开发资料上的描述性比较，不是独立效度检验。LLM 一列保留先前 GPT-5.6-sol 结果，本轮未改其编码。

## 历史高值到底测了什么

历史 `κ=0.867204` 来自 v2 词典与 v2 LLM 对同一批 3,387 句的**方法间**五维合并一致性，不是自动规则对人工编码员的一致性。把范围固定为新版 LLM 能对齐的 2,965 句，v2/v2 仍为 `0.864515`；同批上分别换词典与 LLM，得到 v3词典/v2LLM `0.734800`、v2词典/v3LLM `0.603175`、v3/v3 `0.654447`。前后 3,387 个共同句子的原文相同；在 2,965 个对齐 ID 中，词典标签集变化 756 条、LLM 标签集变化 802 条。版本及操作定义的变化足以解释数值跃迁的大部，不能把 `0.867` 与截图中对 A/C 的 `0.345` 解释成同一可靠性估计突然崩溃。证据见 [历史版本复算](history_version_audit.json)及[复算脚本](audit_history_versions.py)。

## 查出的自动规则过程问题

v26.2 在 H427 的创新性上仅命中 A 的 12 个正例中的 3 个、公平性仅命中 24 个中的 8 个；低 κ 有真实漏判成分。逐句复查后，修订了明确药品注册创新分类、药物创新属性及数据保护支持、药物经济学分析、患者获取与药品配备供应等具有对象关系的规则。同时保留边界：只有“创新药”类别或程序时限不赋 I，目录名称、既往纳入年限、申报程序或预测销售金额不自动赋 F。

修订中发现一个新的具体误判源：公平性语法曾把“常规目录药品新增适应症”“已纳入目录的年限”“预测纳入支付范围的销售额”解析成药品保障范围的实质变动。在 1,268 句比较框架中这会把原本 A/C 都判 0 的句子推成 F=1，使 κ 下降。最终版要求“药品”成为纳入/调出保障范围的实际对象，并把明确断供句重新纳入；相应正反例已列入回归测试。完整实现为 [五维入口](policy_coding_v27.py)、[公平性与创新性规则](rules_if.py)、[回归测试](test_rules_if.py)。

源文与输入也已核验：4,924 条 ID 和句子原文均未改，8 条缺失必需列表按来源文件和哈希补齐，59 条创新资格范围以来源/组件/原文哈希绑定；上下文独立引起 15 条标签变化。详见[上下文修复记录](context_repair_audit.json)。

## 能用于论文的结论边界

可以如实说：旧规则在创新性和公平性存在可定位的语义漏判及覆盖关系误判，修订后与 A/C 的**开发集一致性**改善；有效性在 H427 几乎未改善，1,268 句的创新性/公平性仍有低召回（对 A 的召回约 0.533 / 0.523，对 C 约 0.490 / 0.465）。不能说五维自动编码的独立信度已经达到目标区间，更不能把对两位 AI 编码员的拟合写成真人复核结果。若论文要作正式信效度主张，应在本版规则与手册冻结后，让真人编码员对未用于规则开发的新样本独立判读，再报告各维正类率、κ、精确率、召回率及不确定性；后续有修改需另留测试集。
