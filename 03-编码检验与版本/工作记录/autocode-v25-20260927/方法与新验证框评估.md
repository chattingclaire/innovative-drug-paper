## 3. 可复现排除规则

程序只增加排除，不取消既有 3,393 条排除。规范化采用既有规则：Unicode NFKC、删除空白、去除首尾 `。.!！?？;；`。对四轮实际封存发包的目标文字及实际展示的正文/表格文本字段收集完整片段；不会把分散字段拼接成原文。

1. 排除既有已登记开发/暴露 ID，以及 H600/R200/V600/D668 所有实际目标 ID；再排除与这些单元原文 SHA 或规范化完整文本相同者。
2. 将候选完整文本与实际发包的目标、段落及核验上下文片段比对：规范化完全相等即排除；候选规范化至少 20 字且整体被实际展示片段包含时排除。不得反过来仅因共同短关键词命中而排除。
3. 对有效来源 SHA 与明确 paragraph_id 完全相同的已展示上下文群作保守隔离；保存匹配来源和旧盲编号。此项表示共享具体上下文群，不断言每条目标全文都已展示。明确引用的 source_unit_id 也核对，本次未产生额外命中。
4. 沿用旧冻结审计的明显近重复阈值：双方规范化文本至少 30 字、长度比至少 0.75、字符 5-gram 集合 Dice 至少 0.85。一跳种子限于实际展示片段和被其直接完整包含的单元；不把近重复结果或同段群排除项递归升级成新种子。它是可复现启发式，不是语义相似性的完美判定。
5. 页、有效来源、原文件条目的整体隔离仅作上表敏感性。空页码不能当成证明未展示。

## 4. 仍无法确认的内容

旧审计已经声明不能恢复全部历史阅读。477 因而是对**已登记历史**机械闭合后的框，不是所有历史上真正未见标签/原文的确定数量。当前无法完整确认的具体缺口包括：未登记的早期语料查看、四轮发包之外及本轮之后的源文阅读、规则迭代时可能未登记的示例，以及程序阈值未捕捉的改写近重复。不能以“没有查到记录”替换“已经证明未发生”。

233/477 条没有单元物理页码，部分文字来源本就没有 PDF 页码；同源段 ID 可用，但未额外人工确认其语义一致性。程序没有重新翻阅源 PDF 来补齐页码或验证每个段 ID。全部语料曾被机器处理也不等于每条都被开发者人工判读，但必须与“从未见过输入文本”分开报告。

本轮源码审查可继续使用旧开发材料。冻结前若读到 477 内任一目标或依赖上下文，应立即增补暴露登记并机械重算；不可在事后因为结果好而豁免。新增源文核验、单元修复、提示例句、宽检索规则的实例开发，也属于需要登记的活动。

## 5. 可执行的新验证设计

### 冻结顺序与角色

先完成旧开发材料上的错误诊断与修订，再冻结 v25 的代码、词典/语义规则、提示（若使用）、模型标识与参数、完整输入及上下文、输出解析、手册版本和待定机制；同时登记本轮所有新增读取。随后重跑本审计并封存最终框、排除理由、群、抽样/统计程序和预算。最终冻结之前不抽样、不向开发者展示新候选文本、不提前获取新参考标签。

冻结之后才能生成新版本预测和新判读材料。两个实际编码者使用相同完整单元和语境，对另一人答案及机器输出不知情；封存首次提交后再计算可靠性和处理争议。尽量由未参与规则开发的实际编码者承担；若均为 AI，则使用不继承开发诊断内容的独立任务上下文，并明确同类模型的共同偏差仍无法消除。没有真人执行，不声称真人专家信度、人工金标准或专家内容效度。

若有真人争议裁定，单独保存裁定标签及证据；没有裁定时，机器分别对 A/C 报告，不挑更接近机器的一人。冻结材料仍缺信息时保留待定；补充材料须同版提供并另存补充轮结果，不能悄悄覆写首次判断。

### 主样本与适用总体

最终框若仍约 477 条，可以比较“全框双判”和概率抽样的工作量。全框双判可避免仅为沿用旧 600 数字而虚构样本预算；它只意味着有限残余框的全查，不解决稀有阳性、共同参考错误和原总体覆盖不足。**此处不预定抽样预算，也未开展全查。**

若选择抽样，主方案按冻结部门×年份/相邻年段分层无放回随机抽取。稀疏格只能按事先规则合并或全取，保留所有单元非零纳入概率，记录 `N_h、n_h、pi、weight`、排序、种子和唯一抽样尝试。需要文件/上下文群整群抽样时，记录一阶段/二阶段概率并相应计算方差，不能仍套用单元简单随机样本公式。当前 GOV 仅 17 条，不能承诺精确的部门内稀有阳性指标。

作为预算讨论示例，若最终 N 恰为 477，简单随机有限总体二元比例、最坏 p=0.5、95%逐项区间半宽目标 5/4/3 个百分点，对应 n 约 214/267/330。此公式不保证 recall/F1/κ 的精度，不含聚类和不等权设计效应，也不是本项目的正式预算。

推断总体仅为最终冻结的残余框；源页隔离敏感性另报其子框。477 约为原 4,924 条的 9.7%，分布受到开发暴露选择影响；权重只能纠正残余框内部的抽样，不可补回原总体中零纳入概率的其余单元，也不可用来外推未来政策。

### 稀有阳性：覆盖漏判而非只检查模型阳性

先冻结规则，再以冻结模型预测及事先独立指定的宽检索产生互斥辅助层：模型阳性、模型阴性但宽检索命中、二者均阴性。五维可共现，辅助层重叠须按固定优先序或标签模式去重并记录最终概率；不能简单把五个阳性池相加。宽检索规则不能在阅读新验证文本后继续调参。

若在概率主样本内按辅助层增配，应在看到新参考标签前固定各层样本量和上限，并保留随机阴性及所有最终判为阴性的条目。以加权四格总量计算 precision/recall/F1，区间匹配实际设计。只抽机器阳性可以了解该阳性集合的误报，无法发现阴性中的漏判，不能验证完整 recall。

若采用目的性边界挑战集，应单列条件性表现及错误类型，不与代表性样本无权混合。挑战材料一旦用于修订，转作开发，不能继续充当最终验证。不能在取得“足够好分数”或“刚好若干阳性”时随意停样；如采用顺序规则必须事先明确并使用相应推断。

没有查看 477 的新预测或标签，因此每维实际阳性数未知。即使全查，假设某维只有 1% 阳性，也仅约 5 条；这是假设示例而非实测。不能保证获得 100 个阳性，也不能以总 n 达标替代阳性分母及区间。若最终分母过小，结论应为证据不足；若需要新来源材料，另行建立政策时间/来源范围明确的框，其目标总体与当前残余框分开。

## 6. 指标、待定与判定原则

每维首先报告抽中/全查数、A/C 的 0/1/待定三分类表、正例数、可判数及加权覆盖。编码者可靠性使用讨论前原始标签，逐维报告观察一致率、正类/负类一致和预先指定的 κ 或名义 Krippendorff α；AC1 若采用仅作事先约定的敏感性，不事后选择最高系数。A/C 高一致不等于共同正确。

机器表现逐维报告 TP、FP、FN、TN、precision、recall、F1、相应分母与区间；稀有 I/F 的 recall 尤需单列，不被总体准确率或微平均掩盖。除逐维主结果外，可预定样本级完全匹配率、宏平均和微平均作为辅助；不得把 5n 格当作独立观测。分母为零时为不可估计，不填 0 或 1。

机器与参考中任一方待定都不自动当 0。至少同时给出可判部分表现、联合可判覆盖、全部单元的待定分布，以及按待定可行取值的全样本敏感性边界。v24/v25 比较要使用同一完整输入和同一参考，主比较限定共同可判部分并并列覆盖变化；不能靠增加待定来制造看似改善。

概率样本的加权四格比例及非线性指标，应采用与分层/群设计相容的方法给区间，并报告区间方法与复现种子。若对全部最终残余框普查，固定参考下的有限总体结果没有抽样误差；不能用任意 bootstrap 把它包装成纠正未知参考误差的置信区间。跨文件推广或标注不确定性须另述假设，以 A/C 分歧、争议和待定敏感性呈现，不能凭普查声称效度确定。

冻结前指定主要用途和误差容忍度、主要指标及多重比较处理。逐维 95% 区间不表示五维同时 95%保证。绝对表现与相对旧版的差值分开；即便差值提高，也可能未达到论文用途。若没有合理用途阈值，就完整描述结果并限制解释，不事后补“通过线”。

发现问题后可以开发新版本，但应封存本次首次结果；已用于修订的材料立即改变证据地位。旧结果不得被覆盖，结果不好、待定多、阳性稀少都不是重抽或改标为 0 的理由。
