## 结论

核心统计实现成立：待定 3×3 保留完整；P/R/F1 只在预测和参考均为二元的单元上计算，主比较按每位参考、每个维度使用所有主方法共同可判的同一子集；64 顶点枚举给出的是二元完成的逻辑极值，不是置信区间；A/C κ、正类一致率和负类一致率公式正确且都基于 A/C 共同可判子集；首次输出与更正输出的文件选择规则没有按参考得分择优。

发现 1 个必须修复的边界缺陷：显式 `null` 的子类型字段没有按“未知”处理。另有 1 项与更正敏感性展示口径有关的可选改进。

## 必须修复：显式 null 子类型会中止分析

`scenario_labels` 直接执行：

```python
set(record.get('fairness_subtypes', []))
set(record.get('innovation_subtypes', []))
set(record.get('safety_subtypes', []))
```

缺字段和空数组会得到空集合，但 JSON 显式 `null` 会被读成 Python `None`，`set(None)` 抛出 `TypeError`。这与计划中的“positive with missing required subtype remains pending”不一致；显式空值也是未知子类型，应进入“待定”或先被明确验证拒绝，不能以未说明的运行时异常中止。

纯构造反例：

```python
record = {
    'labels': {'S': 1, 'E': 0, 'Ec': 0, 'I': 1, 'F': 1},
    'fairness_subtypes': None,
}
scenario_labels(record, 'F_access_affordability_only')
```

当前结果：`TypeError: 'NoneType' object is not iterable`。同样问题存在于 `innovation_subtypes=None` 和在 `safety_quality_basis` 缺失时的 `safety_subtypes=None`。

建议在三个字段进入 `set` 前统一规范化：`None` 按未知空集合处理；非 `list` 的其他类型显式报 `ValueError`。修复后应增加三个显式 `None` 的构造测试，断言受影响的正类标签变为“待定”。

## 已核对为正确

### 待定 3×3 与指标分母

`matrix` 明确保留 `(0, 1, 待定) × (0, 1, 待定)` 九格。`summarize` 的 TP/FP/FN/TN 只取四个二元格，因此 precision、recall、F1、specificity、accuracy 都是共同可判条件指标；待定没有被当作 0。总量、共同可判覆盖率、预测待定、参考待定和双方待定另行报告，分母含义清楚。

`evaluate_units` 对每位参考和每个维度先要求参考为 0/1，再要求所有主方法都为 0/1，之后让各方法使用完全相同的 `common` 子集。加权和未加权版本使用同一行集合，仅权重不同。

### 64 顶点二元完成界限

五个含待定的 3×3 格分别有 2、2、2、2、4 个可去向，共 `2×2×2×2×4=64` 个顶点。precision、recall、F1、specificity 都是非负仿射量之比；任一分母为正的内部完成值可写为相应顶点比值的分母加权平均，所以极小值和极大值必在顶点取得。accuracy 的总分母固定，更直接为线性函数。实现还单独记录是否存在分母为零的完成。因此这些是精确逻辑界限，不是采样置信区间。

现有随机构造测试逐单元穷举所有二元完成并与聚合 64 顶点结果比较，测试通过；它验证的正是该极值结论。

### A/C 一致性

在 A/C 共同可判四格中，κ 使用标准的观察一致率与边际期望一致率；正类一致率为 `2TP/(2TP+FP+FN)`，负类一致率为 `2TN/(2TN+FP+FN)`。这些量对交换 A/C 对称。退化分母返回 `None`，并同时保留完整 3×3、覆盖率和 A/C 各自正类率。

### 子类型敏感性（除 null 缺陷外）

缺字段或空数组时，受影响维度的正类在需要子类型判断的敏感性中进入“待定”，不会被强制为 0。单一被排除子类型转 0，混合子类型保留 1；原始记录未被就地修改。现有构造测试覆盖这些路径并通过。

### 首次输出与更正选择

主分析只读经 seal 哈希绑定且标记为 `first_outputs_primary` 的首次输出。更正敏感性从首次输出深拷贝，按每个 shard、每个 batch 选择最高修订号文件，并在使用前调用形状及输入包校验；选择不依赖参考一致率。主结果不会被更正覆盖。就这 6 个文件可见的选择逻辑而言，首次结果与更正敏感性的角色一致。

## 可选改进：明确更正表中的“首次”是重新配对后的值

主分析共同可判子集要求 3 个主方法可判；更正敏感性调用 `evaluate_units` 时加入更正方法，共同可判子集因此要求 4 个方法可判。这样能保证更正表内首次与更正使用相同分母，是内部一致的配对比较；但表中的“首次”不保证等于主结果中的首次点估计。

构造例：两条参考均为正；首次预测分别为 1、0，而更正预测分别为 1、待定，两个规则方法均可判。主分析的首次 recall 为 `1/2`；四方法共同可判只剩第一条，更正表的首次 recall 和更正 recall 都为 `1`。这不是当前公式的错误，但若表述为“主结果前后变化”会产生歧义。

建议在更正摘要中明确写“首次值按四方法共同可判配对子集重新计算”，并并列共同可判条数/覆盖率；如果目标是只评估 LLM 更正影响，可另用首次与更正两方法的配对子集。后者属于分析口径选择，不应无说明地替换现有预设口径。
