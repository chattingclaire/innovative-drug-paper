# 《科学决策》期刊与格式核验

核验日期：2026-10-06。只读核验基准稿：归档工作区《论文修订稿-匿名审稿版.docx》（2026-09-27）。正文数据来源和研究真实性由另外的统计、参考文献审查负责，本报告不宣称论文已经具备录用条件。

## 当前官方来源及版本

期刊现官网为 [科学决策](https://www.qkkxjc.cn/)，其真实性由[中国人民大学主办的预印本平台期刊资料](https://pssxiv.cn/journal/browseissue.htm?journalid=11549)交叉确认。新官网当期目录显示2026年第31卷第7期；检索能核对具体文章及DOI，例如[超大规模算力建设驱动具身智能产业高质量发展的价值意蕴与实践路径](https://www.qkkxjc.cn/article/doi/10.27034/j.cnki.ISSN1006-4885.2026.07.006)。这证明所查期刊和文章存在，不能据此保证本文录用。

[现行投稿版式](https://www.qkkxjc.cn/submission-format)页面的公开数据接口返回“2026年期起适用”的内容，页面附件链接实际下载的文件名称为《科学决策》稿件模板及规范要求（2026年9月修订）.docx。最新版附件应优先于页面仍保留的较早要求。下载地址为[2026年9月修订模板](https://www.qkkxjc.cn/news/exportNewFile?id=69)。网页在web浏览器抓取中间歇超时，但其网站HTML、公开newsData响应和DOCX附件已直接读取并保存；不是根据代投网站推定要求。

期刊刊号为ISSN 1006-4885、CN 11-3472/G3；现官网元数据和人大平台一致显示主管中国航天科技集团有限公司，主办中国航天系统科学与工程研究院、中国社会经济系统分析研究会、欧亚系统科学研究会。官网首页元数据明确自述CSSCI扩展库、AMI扩展，征稿页对CSSCI表述较笼统。南京大学评价中心[期刊介绍页](https://cssrac.nju.edu.cn/xscb/lyqk/20200524/i82752.html)可核对期刊身份，但属于历史资料。本次未获得南京大学2025—2026版正式目录原件，故不把官网自述升级为独立核实的当前CSSCI来源核心期刊，更不声称北大核心身份。

[征稿启事](https://www.qkkxjc.cn/contribution-invited)明确篇幅宜9000—15000字、数据可靠、双向匿名审稿。当前正式系统为[科学决策投审稿平台](https://manuscript.qkkxjc.cn/kxjc)。官网另有旧迁移时期“改为邮箱投稿并附保密审查”的[变更声明](https://www.qkkxjc.cn/news/51)，与现行征稿系统入口不完全一致；投稿时以系统当时提示为准。本次未注册、未投稿、未发送邮件。

## 格式核验矩阵

| 项目 | 2026年9月模板依据 | 基准稿现状与处理 |
|---|---|---|
| 中文标题 | 黑体四号14 pt，居中 | 当前Title样式28 pt，需要改为14 pt |
| 作者与单位 | 作者仿宋小四12 pt，居中逗号分隔；单位宋体五号10.5 pt，高校写到学院 | 匿名稿隐去个人信息合理；署名信息另行补齐 |
| 中文摘要 | 宋体五号10.5 pt，左顶格；目的、方法、结果、结论，约300字 | 当前316字符（266汉字），长度接近；需要改科学结论、核实来源，不再套旧200字上限 |
| 关键词 | 宋体五号10.5 pt，3—8个，分号分隔 | 当前5个，数量符合 |
| 英文前置 | 英题Times New Roman14 pt粗体居中；英摘要、关键词10.5 pt；对应中文内容 | 当前英文题摘在参考文献后，宜移至中文信息之后、引言之前；新模板未规定200英文词硬上限 |
| 正文和附录 | 宋体小四12 pt，首行缩进、不分栏、1.5倍行距 | 当前正文宋体12 pt、1.5倍，符合，不应改成旧模板五号正文 |
| 标题层级 | 黑体小四12 pt；缩进1字符，编号后空1汉字；章标题宜≤15字 | 当前层级与缩进基本符合，最长节题15字 |
| 首末章节 | 第一章“引言”，最后一章“结语” | 当前已为1引言、7结语 |
| 页幅及边距 | 下载模板A4，四边1.27 cm（这是模板实测值） | 当前A4、四边1.27 cm，符合模板；无需自行大改 |
| 图和表 | 标题与内容宋体五号10.5 pt；中文内容；三线表；先文后图表、正文引用、全篇顺序号 | 基准稿5表、2幅内嵌图，表格10.5 pt、中文内容；最终稿增表A1后为6表，保留原2图，23页渲染已逐页核对。最新版没有要求图表标题必须双语 |
| 附录位置 | 结语后、参考文献前；A/B依序，附录表公式另用A1/B1 | 当前位置符合 |
| 引用和参考 | 顺序编码，作者名后上标；正文不带引用年份；中英文混排编号对应 | 当前主体引用已无年份，需继续检查新增文献编号 |
| 文献排版 | 中文不需英译；五号；英文姓大写、名缩写；第4作者起等/et al；半角标点，条末点号 | 当前总体符合，外文题目大小写和空格需按最新版整理 |
| 参考文献限制 | 完整著录；拒绝中科院国际期刊预警名单刊物文章 | 2025官方名单原图已逐刊核对，原45条未命中；2026更新和年份适用口径待投稿时确认 |
| 文件大小 | 官网投稿指南建议≤2 MB | 当前DOCX698568字节（约0.70 MB），符合 |
| κ统一发表线 | 官方稿约未给0.8硬性录用线 | 不得写成本刊要求所有机器对A/C的κ均≥0.8 |

网页较早段落含仿宋四号摘要、图表小五号等，下载的2026年9月DOCX已改为宋体五号摘要和图表，因此本报告以新版附件为准。历史旧域模板的200字摘要、中文参考文献英译、作者年份引用等不能继续作为2026现行硬性要求。

| 全部5张表（不在上述段落统计中） | 357 | 1953 |

这些是程序逐段计数：汉字只统计Unicode中日韩统一表意字符，非空字符计入数字、英文、标点；不是Word的混合字词统计。单独正文主体在9000—15000字附近，没有必要先大幅压缩。期刊未说明参考、附录、表格是否计入篇幅；把全稿非空字符22712直接等同于“中文论文22712字”也不准确。全稿汉字含表为14581，但英文词、数字和符号另计，所以不能断言全稿严格处于15000字内。投递前应在Word中按编辑部口径确认，必要时把技术附录移为补充材料，不改正文研究逻辑。

## 核验边界与尚待完成

1. 本报告核实期刊存在、官方站点、当前目录与2026年9月稿件格式，未获得独立最新版CSSCI目录原件；仅凭网络自述不应使用“权威发表已达标”的保证措辞。
2. 最新模板要求研究客观真实。A/C既有结果来自AI判读，若未来改成人工验证，需要真实编码者、盲评记录、独立样本与重新计算的指标。把AIκ在正文中标为已经发生的真人验证即使单独待确认文档备注也不能使该事实陈述成立。
3. 期刊的2026年9月预警期刊限制需要另外核查。现已从中科院所属研究所2025正式发布页取得5刊原图，原45条所涉25种期刊均未命中；2026版是否发布仍未确认，详见预警名单核验/预警期刊专项核验.md。不能由“Frontiers”品牌整体推断某一本期刊在名单中，也不能用中信所名单代替稿约点名的中科院名单。
4. 本稿仍需完成数字与图表对应、文献逐条事实支持、新LLM重跑和真实独立人类验证，再由编辑部及同行评审决定可否发表。
