# 真人五维编码培训依据（agent预验证版）

本材料用于真人学习编码规范和审阅候选判例。两位专家agent各自完成300条独立判读，第三位agent裁决19条分歧并审查24条随机一致记录。所有执行者均为agent；这不是已完成的真人验证，也不是不可修订的人工金标准。

## 先理解测量对象

本研究测量政策文本对药品安全性、有效性、经济性、创新性、公平性的关注。每条分别判五个0/1，可多维同时为1，也可全部为0。标签1表示实质讨论该维度，包括评价要求、否定或条件性规定，不表示药品已经具有相应优点。不存在第六个“无关维度”。

完整规范：[五维手册v1.3](protocol/完整五维手册-v1.3.md)及[共用操作说明v1.4](共用操作说明-v1.4.md)。实际政策引文与教学构造例须明确区分。

## 每条的判断步骤

1. 读完整单元与同版语境，确认材料完整、当前对象及完整谓词。
2. 分别判五维。标题、部门、药名或程序名称不能直接代替实质命题。
3. 每个1标出当前单元的连续原文；依赖上下文时再引对象、父谓词或列头。
4. 每维写本条理由，创新性与公平性写清纳入或排除边界，保留来源子类。
5. 实质缺料先回查，不猜0；材料已完整但有边界争议，保留个人判断和理由，独立提交后再讨论。

## 最容易混淆的边界

|维度|应据什么判定|不能自动纳入的内容|
|---|---|---|
|安全性|药物损害、风险及相应证据；明确质量安全另留痕|数据安全、单纯质量二字、人员专业背景|
|有效性|药物效果、临床获益、疗效比较及证据要求|数据有效、一般研究设计、推荐身份本身|
|经济性|药价、药费、支付标准、药物费用责任|科研经费、行政收费、仅程序名称|
|创新性|创新属性、具体改良、创新研发实体支持、专有权利及有依据的创新资格|普通设计、一般手续、创新药名称或单纯宗旨|
|公平性|实际药物保障获取、未满足治疗需求、患者负担及具体临床管理难度|一般申报资格、常规试验供药、机构行政管理|

源文列表须按真实共同父谓词合读；表行须附实际表题、列名及行映射。不能把所有子项的标签复制给引导句，也不能因子项没有重复保障动词就忽略它实际承接的条件关系。

## 真人正式验证如何使用

真人先学习完整手册、共用说明和上述候选判例，再在另外封存的240条无答案材料上独立填写。两份材料原文相同、顺序及编号不同，未与这300条重叠。编码员姓名、专业经历和实施日期由真实执行者填写，不能预填。

先封存双方原始提交并计算协商前信度，再人工裁决分歧形成参照，最后检验两条机器方法。真人可以修正agent候选标准，但应说明原文和定义依据。任何据正式验证结果进行的调试须留版本，并另设后续确认样本。

不要求三种方法的注意力占比逐项完全相同。需要检验机器能否忠实执行五维定义，以及误差是否系统性改变部门注意力结论。占比分母统一为同部门五维编码句次之和。
