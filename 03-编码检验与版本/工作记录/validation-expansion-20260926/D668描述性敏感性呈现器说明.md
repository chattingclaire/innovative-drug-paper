# D668 描述性敏感性呈现器

`render_d668_descriptive_report.py` 只读取显式输入的完整敏感性结果 JSON，并将其 `provenance.primary_sha256` 与独立提供的主结果 SHA-256 比对。它不打开主归档、首次判读、原始材料或机器预测，也不调用分析程序。输入必须具有 `completed_pre_D_judgment_descriptive_sensitivity_addendum` 状态、完整五情景和封存来源元数据；不得使用 V600 或其他 schema 适配。

每个情景保留 A/C × 四个来源组及总体，共 50 个覆盖位置。可计算情景显示主口径及变体的 0 / 1 / 待定比例、原样复制的阳性百分点变化、原始受影响数、固定分母和精确受影响权重字符串。无法计算的情景保留十个“不可计算”位置及全部缺失/非法元数据记录与原始原因。每行带源 JSON Pointer，完整精确数值和受影响 ID 以 JSON 归档为准。

报告注明补充方案是在抽样之后、D 材料阅读授权及判读之前另存登记；样本是 1268 个分析单元，不是文件篇数。报告不新增区间、p 值、名次或共同稳健方向，不扩展主方案 580 项推断家族，也不构成真人评审或新的验证。

在完整敏感性 JSON 生成并核实主结果哈希后运行；下列占位路径和哈希须替换为实际值：

```sh
/LOCAL_HOME/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 \
  '/PROJECT_ROOT/outputs/validation-expansion-20260926/render_d668_descriptive_report.py' \
  --input '/绝对路径/完整敏感性结果.json' \
  --output '/绝对路径/新建描述性敏感性报告.md' \
  --expected-primary-sha256 '<已独立核实的完整主结果SHA-256>'
```

输出及其 `.partial` 路径必须不存在，程序拒绝覆盖。它记录敏感性 JSON、报告及主结果哈希，检查呈现期间输入原字节未变。补充时点封存的嵌入对象按原文件 UTF-8、`ensure_ascii=False, indent=2, allow_nan=False` 加换行格式重建并核验其 SHA-256；该格式已对封存元数据文件只读确认。呈现器不会重新读取或验证原始判读、主结果内容或补充方案文件。
