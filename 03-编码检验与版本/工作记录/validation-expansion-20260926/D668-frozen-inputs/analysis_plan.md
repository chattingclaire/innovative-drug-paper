## 3. 预定估计对象和点估计

固定c∈{A,C}、d∈{S,E,Ec,I,F}、k∈{0,1,pending}。各部门估计为

Qhat[g,c,d,k] = {Σ(h属于R_g) (N_h/n_h) Σ(i属于s_h) 1[label_cid=k] + (D_g/m_g) Σ(i属于s_Dg) 1[label_cid=k]} / U_g。

总体用Σ_g(U_g/4924)Qhat_g，不平均部门或两位AI。五维允许多标签，各维独立报告，不强制五维加和100%。两位判断保持分列，1268个不同单元不能写成2536个样本。

主要报告全部120个部门×AI×维度×三状态比例，以及30个总体比例。另报告40个部门和10个总体的potential_positive指示量（标签为1或待定）。每个AI×维度的点估计识别范围为[positive, positive+pending]。正类指标的非正值并非把待定编码为0；待定仍作为独立状态及识别范围显式展示。不使用仅可判条目作全框分母，不假定待定完全随机缺失。

估计对象为既定语料切分、部门归属、材料与共同手册下，各AI的操作性内容分布。不是政策文件份额、真实注意力强度、机构重要性或因果效应。

## 4. 边际区间及辅助设计方差

对每个二元指标，在每层h内观测x_h，样本量n_h，总体量N_h。给定固定有限总体编码函数，X_h服从Hypergeom(N_h,M_h,n_h)。反演M_h的等尾精确整数区间，范围M_h∈[x_h,N_h−n_h+x_h]；下端为满足Pr_M(X≥x_h)≥α_h/2的最小M，上端为满足Pr_M(X≤x_h)≥α_h/2的最大M。包含等号，普查时区间为[x_h,x_h]，零事件不能自动写成[0,0]。

对某部门的一项指标，将α=.05均分至该部门全部R层加D层（共H_g层）；各层整数下界相加/U_g、上界相加/U_g，得到至少95%设计覆盖的保守边际区间。总体指标按全部29层分配α=.05/29后相加/4924。所有层均纳入分配，不能因零事件或待定少而移出。

有限总体无偏设计方差估计另作辅助：Vhat(Qhat)=Σ_h N_h²(1−n_h/N_h)s_h²/n_h / U_g²，其中s_h²为样本二元指标N−1形式方差（实际为样本n_h−1分母），普查项贡献0。非普查层必须n_h≥2。本设计符合该条件。辅助SE为sqrt(Vhat)，不将退化Wald区间作为主区间。

这里“至少95%”以声明的概率设计及固定编码函数为条件。AI判断具有过程依赖或随机性、材料误差、共同偏差及语料覆盖误差，均不受这些区间控制；上下文延续和共同模型可能削弱固定测量近似，不能将条件覆盖表述为研究总不确定性保证。区间保守性不能当成效度证据。

## 5. 部门差值、待定与全部比较的同时控制

预定全家族为2位AI×5维×29层×2个指标（positive、potential_positive），共580个层级二元指标。每个层级等尾区间使用α_h=.05/580；对这些界的联合覆盖采用Bonferroni不等式。无需假定两位AI相互独立，也不因重复/零指标减少580这个数。

先将层界汇总至各部门，再输出全部2位AI×5维×6部门对=60组阳性差值及待定最坏补全差值；不得只挑显著对。部门顺序固定NMPA、NHSA、NHC、GOV；各对以顺序在前部门减在后部门。

阳性差同时界：[L(pos_g)−U(pos_h), U(pos_g)−L(pos_h)]。

待定补全差同时界：[L(pos_g)−U(potential_h), U(potential_g)−L(pos_h)]。

两位AI在同一维度、同一部门对的待定补全同时界都严格大于0，方可报告前一部门更高的有限方向；都严格小于0，方可报告后一部门更高。其余全部标记方向未获共同支持；不以点估计顺序填补。该规则控制所有预定比较，不声称建立完整部门名次。不输出显著性p值，不事后换更窄的方法以制造方向。

所有上述界均为同一固定分布测量假设下的抽样/待定结果，不能消除两个AI共同错误。补全界约束的是尚未判定二元指标的可能分布，不推定待定真实标签。
