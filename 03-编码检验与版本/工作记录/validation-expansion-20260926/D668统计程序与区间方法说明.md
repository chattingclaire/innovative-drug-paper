## 输入与使用

程序：`d668_statistics.py`。纯函数：`analyze(payload)`；不会发现、搜索或打开数据文件。仅 CLI 显式读取 `--input`。CLI 不覆盖已有输出。

```python
payload = {
    "schema_version": "d668-v1",
    "data_kind": "observed_coding",
    "design": frozen_design(),
    "coders": ["A", "C"],
    "dimensions": ["S", "E", "Ec", "I", "F"],
    "units": [
        # 每篇抽中文献一条；两名 AI 的标签放在同一个单位中。
        # {"unit_id": 文献唯一ID,
        #  "stratum_id": "R|NMPA|2020" 或 "D|NMPA" 等已冻结层键,
        #  "labels": {"A": {"S": "0", "E": "1", "Ec": "pending", ...},
        #             "C": {五个维度全部存在}}}
    ],
}
result = analyze(payload)
```

以上仅为接口说明，不是可以冒充研究数据的完整样本。编码值必须为字符串 `"0"`、`"1"`、`"pending"`；由桥接程序将原始整数或“待定”逐字映射，禁止在统计程序中补标、造共识或排除待定。

输入严格要求每条文献唯一、两名 AI 五维全部完整、每层实际单位数等于被冻结的 n，并逐项验证 29 层的层键、R/D、部门、N、n。仅总数相同不足以通过。文献数是 1268，不是 2536。缺标、重复、非法标签、未知层或输入中尝试修改 alpha 均报错。程序无法单凭输入验证文献是否确属抽样清单；桥接与外部审计仍须核对 ID、层归属和随机化来源。

正式 CLI 在全部标签完成、人工确认前瞻冻结后使用：

```sh
python3 d668_statistics.py --input 完整标准化编码.json --output 新的正式统计输出.json
```

`python3 d668_statistics.py --design-only` 只打印冻结抽样元数据。测试入口 `_analyze_synthetic` 的结果始终显式标记 `SYNTHETIC_SOFTWARE_TEST_ONLY`，不得引用为真实研究结果。

## 冻结的估计对象和抽样设计

固定总体 U=4924，部门分母分别为 NMPA=1848、NHSA=2100、NHC=533、GOV=443。R1531 分为 25 个部门×年份层，已有 V600 共 600 条；D3393 按部门分成 4 层，N/n 分别为 1077/133、1662/222、329/148、325/165。每层为不放回简单随机抽样，各层随机化设计独立；R 与 D 是不相交的固定框架分区。

对每个 AI、维度和二元指标，层内观察阳性数为 x_h：

- HT 总量估计为 Σ_h N_h x_h/n_h；比例以固定部门 N_g 或固定总数 4924 作分母。
- 总体比例等于各部门比例按 N_g/4924 加权，不按样本量加权。
- 辅助设计方差为 Σ_h N_h²(1−n_h/N_h)s_h²/n_h，再除以分母平方；s_h²=x_h(n_h−x_h)/[n_h(n_h−1)]。非普查层要求 n_h≥2；普查层贡献严格为 0。
- 逐一估计状态 0、1、pending 以及 1+pending；三个状态比例总和为 1，但五维并非互斥份额，不作跨维度归一化。

输出包含部门三态 120 行、部门潜在阳性 40 行、总体三态 30 行、总体潜在阳性 10 行，以及 290 个 AI×维度×层计数记录。每行保留分母、未加权观察计数、HT 总量、比例、辅助方差/SE和主区间。不能将辅助 SE 为 0 解读为总体没有事件。

## 主区间：分层精确超几何反演

每一层假设固定有限总体阳性总数 M_h，在可行整数范围 [x_h, N_h−n_h+x_h] 中，保留同时满足以下条件的 M_h：

P_M(X≥x_h) ≥ α_h/2，且 P_M(X≤x_h) ≥ α_h/2。

分别用 `scipy.stats.hypergeom.sf(x−1,N,M,n)` 和 `cdf(x,N,M,n)`，按 M 的单调性二分找端点。普查直接返回 [x,x]。零事件和全阳性样本仍按相同预定规则反演，不切换到 Wald 区间。

部门的每个指标使用 α_h=0.05/H_g，H_g 分别为 7、9、8、5；将各层总数下界和上界分别相加，再除以固定 N_g。总体每个指标用 α_h=0.05/29。通过 Bonferroni，每个主区间在固定编码函数、所声明概率抽样设计下具有至少 95% 的边际覆盖率。各指标的这些主区间不是全家族同时区间，不能用于批量比较或排名。

双尾比较使用固定绝对容差 1e−14，即 `probability + 1e-14 >= alpha/2`，仅为保守包含数值边界，不根据结果调整。理论反演是精确离散方法；SciPy 计算是浮点实现，因此版本和容差写入元数据。差值界是否排除 0 使用整数交叉相乘精确判断，不使用显著性容差。

## 同时界、部门差值与待定补全

全家族固定为 2 AI × 5 维 × 29 层 × 2 端点（阳性、阳性+待定）=580。每项 α_h=0.05/580；即使某层无待定、零事件或普查，也不删除项目或缩减校正。层界相加得到部门（以及总体）的端点同时界。

由于 union bound 不要求指标独立，两名 AI 的输出彼此相关、维度相关、阳性与潜在阳性嵌套均不影响该保证。各层设计独立用于辅助方差求和；Bonferroni覆盖本身不依赖指标间独立。

对每名 AI 每维每个无序部门对 (g,h)，输出：

1. 阳性差值估计和同时区间：[L(p_g)−U(p_h), U(p_g)−L(p_h)]。
2. 任意待定补全的最坏同时区间：[L(p_g)−U(q_h), U(q_g)−L(p_h)]，其中 q=p+pending。

共有 2×5×6=60 条部门对记录，每条含上述两类界。580项共同覆盖事件已同时蕴含这些派生界，无需再把 60 或 30 乘入校正。30 条共同方向判断仅在 A 与 C 的待定补全差值界都同方向严格排除 0 时报告稳健方向；否则标记 `not_orderable`。区间刚好触及 0 不算排除。该规则不产生强制完整排名。

## 合成测试与局限

`test_d668_statistics_synthetic.py` 的 18 项测试全部通过，运行日志为 `D668-statistics-synthetic-test.log`。覆盖独立有理数/组合数反演对照（N≤12、全部 n/x、3 种 alpha）、精确概率穷举覆盖率（N≤14、全部 M/n、2 种 alpha）、两层总体区间覆盖、HT 与方差估计无偏性的抽样分布核对、0/n/普查边界、混合 R/D 权重、等权、pending 三态、580家族恒定、共同方向规则、29层硬校验、缺失与重复拒绝、纯函数不修改输入及输出可复现。测试没有读取真实标签。

这些区间只量化固定编码函数在既定抽样设计下的误差，不涵盖 AI 运行随机性、两名 AI 共同偏差、构念效度或相对人工真值的正确率。将随机模型结果视为固定函数，需要对应的预定编码程序或对抽样独立的完整潜在编码结果进行条件化；不能声称因此涵盖全部模型误差。区间保守且可能很宽，尤其对稀有类与小层，这是预定离散覆盖和同时推断的代价。

方法、alpha、家族和方向规则均在读 D668 标签前预定；正式冻结应同时保存本程序、测试、说明、抽样元数据及其 SHA-256。冻结后若发现必须修复的缺陷，应保留旧版哈希并明确记录协议偏离，不能按观察结果选择区间方法。
