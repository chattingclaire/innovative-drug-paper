# D668 报告呈现程序

`render_d668_report.py` 是独立的纯呈现层，只读取显式给定的一份完整桥接结果 JSON，不导入统计程序、不调用 `analyze`、不重新估计比例或区间，也不打开引用的原始提交、收条、材料或机器预测文件。该程序不属于既有20份冻结统计/抽样文件；它不改变统计方法或判断规则。

正式桥接结果完成后使用：

```sh
python3 render_d668_report.py \
  --input 完整桥接结果.json \
  --output 新的中文报告.md \
  --expected-freeze-sha256 从已核验冻结记录独立取得的64位SHA256
```

输出和 `.partial` 必须不存在；独占写入，拒绝覆盖。报告记录原结果文件 SHA-256，发布前复核输入字节未变。呈现器本身只使用 Python 标准库。

程序严格核验完成状态、固定29层设计、1268个唯一分析单元、完整输出行及键、冻结20文件的哈希关联、R48份/D54份来源清单、原始映射、全局ID和归档运行时。冻结清单和三种元数据（R来源清单、R抽样映射、D抽样映射）的原写入格式已由主任务逐字节确认是 UTF-8、`ensure_ascii=False`、`indent=2`、`allow_nan=False` 加尾部换行，因此可按该已知格式重建并严格核对原 SHA-256。任意同义JSON改写并不被当作相同原始字节。

报告开头以全部结果概述共同支持数量和两名AI各自的待定范围，不筛选某位AI或仅报告排除零的比较。完整表格保留部门三态120行、潜在阳性40行、总体三态30行、总体潜在阳性10行、60组AI部门差值、30项共同方向判断；按AI分别呈现。每行带 JSON Pointer；完整主JSON链接与SHA-256是精确数值引用，不在读者报告中堆放原始JSON。独立纯函数 `build_source_audit` 为QA复制290个来源行映射，不加入Markdown。

“共同支持”及每位AI的方向直接来自既定原JSON字段，不从显示后的区间重新判断。部门差值的左右方向也保留原字段。百分比通常显示3位小数，极小非零数显示有效位，避免将非零端点显示为0.000%；更多显示位数不代表更高统计精度。待定范围估计 `[p̂,q̂]`、边际区间、家族同时界及抽样误差/待定包络分别标明，不混用。

报告明确指出：AI不是真人专家；D668为补充内容分析而不是新的未见样本验证；分母固定；不同分析单元数是1268，不能写成政策文件篇数；来源组按制度系统归属，组间差异不能直接解释为单个机关的偏好；区间只覆盖所声明设计下固定编码函数的抽样误差，不包含模型随机误差、共同偏差和效度。收条有效性依据桥接程序已完成验证的归档，呈现器不会声称重新读验每份外部收条。

合成测试文件为 `test_render_d668_report_synthetic.py`，最终日志为 `D668-report-renderer-synthetic-QA-v3.log`。7项QA通过：独立audit逐项核对全部290来源行、完整表格指针及显示值、两AI完整摘要、极小非零数显示、缺行/缺源/错误哈希拒绝、合成标识隔离、输入对象与原JSON字节不变、输出不覆盖，以及不存在统计导入/调用。测试仅生成带 `synthetic_test` 标识的临时夹具，未保存可被误认成研究结果的报告。

合成模式必须显式使用 `--synthetic-test`，且结果顶层 `synthetic_test=true`、统计元数据与输入种类均为合成标识。合成数据禁止通过正式呈现模式。当前未读取真实D668材料或标签，也未生成正式研究报告。
