### 初审缺口与修复确认

**目标全文也必须进入已展示正文的包含检查。** 初版只对目标做规范化同文和近重复匹配：若一个 30 字既定分析单元完整包含在已展示的 100 字目标中，其长度比 0.3、5-gram Dice 约 0.426，既不相等也达不到近重复门槛，却已经逐字展示。实际旧包中 799/800 个目标恰被自己的语境全文覆盖，另有 H600-0310 的 332 个规范字符正文没有 `text` 语境，因此不能依赖语境字段偶然补足目标检查。修复后 `row['text']` 与所有语境 `text` 一起进入展示正文集合，合成短片段已被正确排除。本审查未声称 H600-0310 已造成实际遗漏。

**原始展示语境需要直接作为近重复种子。** 初版只从 999 个直接映射到分析单元的可见正文扩展近重复。若某原始展示语境本身不是一个可精确映射的分析单元，而另一候选只是改变一个字符，可能没有可见单元种子启动匹配。合成 100 字例中，改变一个字符后的 Dice 约 0.948，初版路径可能遗漏。修复后直接从全部展示目标/语境正文对尚未排除单元匹配，保持相同 min30、长度比 ≥.75、Dice ≥.85，并单独记录来源正文规范哈希、来源盲 ID 与匹配分数。v3 新增 1 个排除；其来源正文哈希和盲 ID 已在旧材料中核实。

针对修复后实际源码，本次用 AST 仅提取纯选择语句在内存合成框执行，没有调用 `main()` 或读取全语料。5 项检查确认：目标与嵌套语境均收集、短目标片段排除、无已映射单元种子的原始语境近重复排除、无关单元保留、不会无限递归扩展。

### 尚需保留的暴露限制

- 这是已知暴露审计，不是“未见过文本”的证明。它继承旧 1269 排除清单，不能单独证明更早开发、旧练习语境或人工阅读记录已穷尽。
- min20 的包含规则、min30/长度比/.85 的近重复规则有明确边界：较短片段、改写、多处重排或低于阈值的相似文本可能留在框中；超过阈值也不等于已人工确认语义完全相同。当前措辞将其作为透明保守排除，未把相似度当标签泄漏的事实证明。
- 单步扩展不是近重复关系的无限传递闭包。合成 A→B→C 中，A 与 B 达标、B 与 C 达标而 A 与 C 不达标时，C 可保留；这是已声明的规则边界，不应宣传“已排除所有关联文本”。
- 语境展示是原文暴露，未必同时暴露参考标签；两个事实应分开。继续开发若读出新目标、上下文、示例或其近重复，仍须补登记并重新冻结框。
- 源码导入的 `frame()` 是既有分层逻辑，审计本身不验证未来抽样真的随机、参考提交独立或模型预测正确。最终冻结应同时绑定程序依赖与实际输入；本审查不替代完整冻结程序。

## 2. 成对版本统计的核查

### 分母与 ID 对齐

每行必须有唯一非空 ID、明确层及 `N_h/n_h`、A/C 与 baseline/candidate 的精确五维标签图。复用 `survey_metrics.prepare()` 检查实际层内数、总体数、上下限和标签；布尔、浮点、None、缺维或多维均拒绝。A/C 身份显式为 AI，两版均需版号与格式正确的预测哈希。

`prepare()` 按层与 ID 排序整行后，再按每行 ID 连接两版标签，已消除“基础准备函数排序后机器数组仍按原输入顺序”的错位风险。倒序输入和跨层乱序的合成例均通过。

每版的普通 PRF 使用“该版与该参考均可判”的自身集合；成对 ΔRecall/ΔF1 则对各维、各参考单独使用“baseline、candidate、该参考均可判”的共同集合。它保留原始共同可判数、设计加权共同覆盖，以及仅基线/仅候选可评数。A 与 C 的共同可判集合可以不同，分别报告，不生成共识参考。

### 共享有限总体复制及差值

实现对每个非普查层一次生成 2000 组 `Multinomial(n_h−1,1/n_h)` 计数，并使用：

`(N_h/n_h) × [1 + sqrt(1−n_h/N_h) × (n_h m_i/(n_h−1)−1)]`。

同一复制矩阵同时用于所有维度、两位参考和两个版本。层内复制权重和保持 `N_h`，总体权重和保持 N；普查层不随机重抽。它符合当前支持的“互斥层内单元无放回简单随机抽样”设计，不支持目的性、两阶段或层内不等概率抽样。

差值为 candidate 减 baseline，来自同一复制中的两个指标，不是两个独立 bootstrap 的差，也不是边际区间端点相减。每次任一版对应指标无定义则差值无定义；报告无定义比例，超过 10% 抑制稳定区间。全普查的抽样方差为 0，全无参考阳性等退化情形仍保留 NA。

这个重缩放方案在非普查层使用严格正权重，因此原样本中已观察到的类别不会像普通重抽那样整类消失。无定义复制比例很低，甚至为 0，不能证明稀有分母充分。程序已披露稀有比率的近似区间限制。

### 共同子集输出修复

为计算共同集合，程序内部把不在共同集合的预测暂时遮盖为待定。初版把这些临时三格表和补全界原样输出，容易被后处理误读为机器真实弃判。修复后的 `common_subset_view()` 只发布真实共同可判部分的 2×2 表、TP/FP/FN/TN、条件性 PRF 等指标及其区间，并明确原始待定和全样本补全界位于 `comparisons`。

新增合成检查确认：不再输出计算用三格待定数/补全界；原始基线无弃判、候选有弃判的数量仍各自正确保留；输出过滤不改变 ΔRecall/ΔF1；共同集合为空时四格数为 0、相应比率与差值为 NA。该修复解决输出含义问题，没有改变计算定义。

### 合成验证摘要

统计部分共核查 **37 项/类合成条件**：程序内置 6 类，独立补充 27 项，以及最后输出修复的 4 项。它们不是 37 个真实验证样本，也不证明区间在所有分布下具有准确覆盖率。

- 手算版本收益、相同版本差值及区间为 0、输入乱序/跨层 ID 连接一致。
- 不等层权重下手算 ΔRecall/ΔF1；共同可判、单方可判、A/C 不同参考待定与全参考待定。
- 交换 baseline/candidate 后差值和区间对称反号；全普查的定义良好差值区间退化到点值。
- 权重复现、正权重、各层/总体权重和固定、普查单元固定。
- 重复 ID、非法/缺失标签、额外维度、错误总体/层大小、非普查单例层、缺参考身份及非法哈希等输入拒绝。
- 10% 与超过 10% 无定义边界，以及最终共同子表输出。

另用一层 `N=8,n=4` 的合成二元比例核验线性方差：解析设计方差 `0.0416666667`，2000 次复制的经验方差 `0.0416723779`，相对差约 `0.0137%`，在预先采用的 12% Monte Carlo 相对容差内。这检验线性方差匹配，不是 Recall/F1 区间的覆盖证明。

暴露工具另有嵌套 `text` 提取与 NFKC/空白归一合成检查，以及上述 5 项修复后实际选择代码检查；发现缺口时使用的反例与修复后通过分开叙述，不将反例发现包装为旧程序无误。

## 3. 使用前仍需落实的边界

成对模块是纯统计引擎。预测哈希只检查格式，不能自行证明其对应真实冻结文件；它也不能证明两个版本输入完全一致、样本概率正确、全部原始提交完整，或两位评审使用新上下文。调用方仍须用封存桥完成这些绑定并保存原始记录。当前 CLI 仅允许合成自测，本审查未执行真实新样本统计。

输出 `population_N` 只代表调用者提供的有限框；不能外推原 4924 条或未来政策。PRF/差值是相对两位明确 AI 对照的符合程度，A/C 一致性与算法效度、内容效度仍是不同证据。未生成真人金标准、共识标签、新的通过线或“正文两套编码已验证”的结论。

区间是逐维逐指标的近似区间，不是同时区间；不计 AI 共享误差、编码错误和未知暴露。待定补全界不含抽样误差，且当前未实现全样本成对差值的补全界。无论点估计是否改善，都不能拿新一轮结果与旧 H600 直接作版本提升证明；应使用本工具所支持的同样本成对比较，并保留旧结果。

本报告确认的是上述具体版本的有限程序检查及行政一致性。下一轮修订版冻结、正式框选择、概率抽样、两份独立提交及实际统计，均不因本报告而变成已经完成。
