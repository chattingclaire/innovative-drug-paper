# 固定分层 SRSWOR：独立数学复核

日期：2026-10-10。复核仅使用公开原始方法文献及人工合成的小总体；未读取 pilot02、coverage 的任何未封存结果，未读取项目正文或未曝光语境，未读取或抽取真实 ID，未调用规则、LLM 或母统计引擎。

**结论：指定重复因子可用于固定分层、层内单位级 SRSWOR。线性总量及已知总体分母的比例，其完整 bootstrap 条件方差与解析 FPC 方差估计量严格相等；非线性指标和 95% 分位区间属于有条件的近似推断。数学核定通过，不构成真实数据结果跨过 0.8 的证明。**

## 1. 文献形式及本任务的核定公式

核定设计为：有限总体按事先固定的层划分，各层总体大小为整数 $N_h$；各层独立、等概率、不放回抽取固定数量 $n_h$ 个单位。基础权重 $w_{hi}=N_h/n_h$、一阶纳入概率 $\pi_{hi}=n_h/N_h$。重复抽样对象必须是原设计的抽样单位；若一条记录是同一单位的子记录，应共同使用该单位的重复因子。

[Beaumont 与 Émond (2022), §3.3, 式 (20), p.345](https://doi.org/10.3390/stats5020019) 直接给出 SRSWOR 的含 FPC 调整因子：

$$a_{hi}^{(b)}=1-\sqrt{\frac{m_h(1-f_h)}{n_h-1}}+\sqrt{\frac{m_h(1-f_h)}{n_h-1}}\frac{n_h}{m_h}k_{hi}^{(b)},\qquad f_h=\frac{n_h}{N_h}.$$

该文将其溯源至 Rao–Wu (1988) 及 Beaumont–Patak (2012)；其 $m_h=n_h-1$ 的常用取值正好化为本任务公式：

$$m_h=n_h-1,\quad (k_{h1}^{(b)},\ldots,k_{hn_h}^{(b)})\sim\operatorname{Multinomial}(m_h;1/n_h,\ldots,1/n_h),$$

$$\boxed{a_{hi}^{(b)}=1+\sqrt{1-f_h}\left(\frac{n_h k_{hi}^{(b)}}{m_h}-1\right),\quad w_{hi}^{(b)}=\frac{N_h}{n_h}a_{hi}^{(b)}.}$$

这里是在原已抽样单位中放回重抽 $m_h$ 次；不是从总体重抽，也不是再次运行标注器。不同层独立生成同一次重复的因子。

[Rao、Wu、Yue (1992), §3.3, 式 (3.4), pp.214–215](https://www150.statcan.gc.ca/n1/pub/12-001-x/1992002/article/14486-eng.pdf) 是将重缩放施加在权重上的原始文献；该处未包含 $1-f_h$。因此，“引用 RWY(1992) 后直接忽略 FPC”不能支撑本任务的有限抽样率设计。2022 年原文的式 (20) 是此处完整形式的直接依据。

全取层 $n_h=N_h$ 应先行分支：$\pi=1$、基础权重为 1、所有重复因子固定为 1、设计方差为 0。$N_h=n_h=1$ 合法，不能先计算 $m_h=0$ 再相除。非全取层要求 $n_h\ge2$；非全取 $n_h=1$ 缺少可估计的层内离散度，本引擎接口须拒绝，不能给零方差或暗中合层。

## 2. 独立条件矩证明

以下推导独立完成，不依赖母引擎。省略层下标，条件于已抽到的 $n$ 个单位及其固定观测值。多项计数满足

$$E_*k_i=m/n,\quad \operatorname{Var}_*k_i=m(n-1)/n^2,\quad\operatorname{Cov}_*(k_i,k_j)=-m/n^2\ (i\ne j).$$

取 $m=n-1$ 后，核定因子满足

$$E_*a_i=1,\qquad \operatorname{Var}_*a_i=1-f,\qquad\operatorname{Cov}_*(a_i,a_j)=-\frac{1-f}{n-1}.$$

每次重复的 $\sum_i k_i=m$，因而 $\sum_i a_i=n$、$\sum_i w_i^{(b)}=N$ **逐次严格保持**；不是仅在期望中保持。有限 $N$ 下非全取层 $0<f<1$，最小因子 $1-\sqrt{1-f}>0$，最大因子为 $1+\sqrt{1-f}(n-1)$。

任意两个固定的单位变量 $y,z$，令 $s_{yz}=\sum_i(y_i-\bar y)(z_i-\bar z)/(n-1)$。则

$$\operatorname{Cov}_*\!\left(\sum_iw_i^{(b)}y_i,\sum_iw_i^{(b)}z_i\right)=\frac{N^2(1-f)}{n}s_{yz}.$$

推导要点是保留因子之间的负协方差：

$$w^2(1-f)\left[\sum_i y_i z_i-\frac{1}{n-1}\sum_{i\ne j}y_i z_j\right]=w^2(1-f)\frac{n}{n-1}\sum_i(y_i-\bar y)(z_i-\bar z).$$

独立层的协方差相加。因此对 HT 总量 $\hat T_y=\sum_hN_h\bar y_h$，

$$\boxed{\operatorname{Var}_*(\hat T_y^*)=\hat V_{\mathrm{SRSWOR}}(\hat T_y)=\sum_{h:n_h<N_h}\frac{N_h^2(1-f_h)}{n_h}s_{y,h}^{2}.}$$

对于总体分母 $N=\sum_hN_h$ 已知的总体比例或平均数，再除以 $N^2$ 即得方差。该条件方差等于**给定样本下的解析方差估计量**，不是声称每一份样本都已获知真实总体设计方差。对原抽样设计再取期望，$E_p s_{y,h}^2=S_{y,h}^2$，故 $E_p\operatorname{Var}_*(\hat T_y^*)=\operatorname{Var}_p(\hat T_y)$。

省略 $\sqrt{1-f_h}$ 会在单层线性情形将方差膨胀到正确值的 $1/(1-f_h)$。加上 FPC 后不得在最终 bootstrap 方差之外再乘一次 FPC。

## 3. 五套标签、所有指标共享重复权重

同一个人工合成或未来封存单位的 A、B、裁定、rule、LLM 标签，以及由它们生成的各格指示量，均应绑定同一个 $a_{hi}^{(b)}$。对每次重复，先生成一张单位权重，再用这张权重重算所有边际、四格、比例、差值和已预先规定的非线性指标。不能按标签、指标、比较对或阳性/阴性子集独立生成重复权重。

原因不是便利性：同一单位变量之间的协方差正是上述 $s_{yz}$。若分别重抽 rule 和裁定，将错误地删除配对差值的协方差项。合成五维实例中，共享权重的 rule−裁定比例方差为 0.04958677686；错误的独立重复权重给出 0.06611570248。

此设计推断条件于冻结后的标签、规则输出和 LLM 输出，刻画抽样引起的有限总体不确定性；它本身不包含重新标注、重新提示或重新模型运行的随机性。范围必须是冻结抽样框所对应的有限总体，不能据此扩张到框外企业、文本或未来语境。

## 4. 95% 分位区间的用途与精度边界

对固定的指标函数 $g$，每次重复用同一完整估计定义重算 $\hat\theta_b^*=g(\hat{\boldsymbol T}_b^*)$，分位区间是

$$[Q_{0.025}(\hat\theta_1^*,\ldots,\hat\theta_B^*),\ Q_{0.975}(\hat\theta_1^*,\ldots,\hat\theta_B^*)].$$

[统计局刊载的 2019 年设计区间研究，§2.2](https://www150.statcan.gc.ca/n1/pub/12-001-x/2019003/article/00009/02-eng.htm) 给出按 bootstrap 指标分布取 percentile interval 的应用。它的示例抽样率近乎可忽略；此处区间构造沿用该定义，重复权重则须用本复核已核定的含 FPC 形式。

未来封存实现须固定重复数、随机种子、可复现单位排序及经验分位插值方法，并记录有效/无定义重复的数量和原因。独立校核为避免插值争议，使用完整离散分布的广义逆 $Q_q=\inf\{x:F_*(x)\ge q\}$；这不强制母引擎采用同一有限 $B$ 插值实现，只要求它事先冻结且明确。

方差的严格等式只覆盖线性总量及固定总体分母的比例。精确率、召回率、F1、机会校正一致性等非线性函数需要分母与校正项不在退化边界附近，并需要足够的有效样本与设计正则条件。其通常一阶近似为 $\nabla g^T\hat\Sigma\nabla g$；bootstrap 协方差保留全部配对依赖，但非线性 bootstrap 均值不必等于原点估计，方差亦不与一阶解析公式严格相等。2022 年文献 §8 对光滑非线性函数提供一阶线性化论证，而没有宣告任意稀疏指标的有限样本精确覆盖。

分母为零或指标无定义时，不得把指标填成 0、1，或删除这些重复后仍将剩余分位数标成无条件 95% 区间。若所有原样本单位都落在同一格，重加权也不能创造未见类别；重复分布可能完全退化。增加 $B$ 只能减小重抽样数值误差，不能创造未抽到的信息。

独立反例：$N=10,n=3$，总体中某类别仅 1 个单位。原样本零该类别的概率为 0.7；此时全部重复比例均为 0，分位区间为 $[0,0]$。穷举全部 120 份 SRSWOR 样本及全部重抽结果后，名义 95% percentile 区间覆盖真实比例 0.1 的设计覆盖率仅为 0.3。**这是说明精度边界的合成反例，不是项目 coverage 结果。**

区间在本任务中用于报告估计的不确定性与稀疏性诊断，不新增“CI 下限超过 0.8”或“半宽达标”等验收门槛。也不新增 AC1 宏平均、CVI 或 KMO。

## 5. 零格有限总体保护：单类别与联合四格

[R 官方 stats 超几何文档](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/Hypergeometric.html) 给出不放回抽样的 PMF。以下保护由该有限组合模型独立推导。单个**预先固定的类别**在层 $h$ 有 $K_h$ 个总体成员，抽样计数 $X_h$ 满足

$$P(X_h=x\mid K_h)=\frac{\binom{K_h}{x}\binom{N_h-K_h}{n_h-x}}{\binom{N_h}{n_h}},\quad P(X_h=0\mid K_h)=\frac{\binom{N_h-K_h}{n_h}}{\binom{N_h}{n_h}}.$$

全取层观测零该类别即确定 $K_h=0$。非全取的观测零不能被解释为总体零。

单层观测 $x=0$ 的零专用单侧上界可定义为 $U_0=\max\{K:P(X=0\mid K)\ge\alpha\}$，保留边界等号以保持保守。要说明覆盖含义，可将完整上界程序定义为：$x=0$ 返回 $U_0$，$x>0$ 返回 $N$。若真实 $K>U_0$，唯一可能的错误是 $X=0$，其概率小于 $\alpha$。$\alpha=0.05$ 对应单侧 95% 辅助上界；双侧等尾 95% 的上端尾概率为 0.025，二者不得混称。

固定分层下，层间独立，所以全体样本零该类别的概率是 $\prod_h P(X_h=0\mid K_h)$。若未知的是总体总数 $K=\sum_hK_h$，必须对可能的整数层间分配取最坏值：

$$G(K)=\max_{\substack{\sum_hK_h=K\\0\le K_h\le N_h-n_h}}\prod_h\frac{\binom{N_h-K_h}{n_h}}{\binom{N_h}{n_h}},\qquad U_0=\max\{K:G(K)\ge\alpha\}.$$

不能将总 $N$ 与总 $n$ 当成未分层 SRSWOR，也不能只选有利的 $K_h$ 分配。独立函数用精确有理数动态规划计算 $G(K)$，并用全部整数分配穷举比对。示例 $(N_h,n_h)=(8,3),(5,2),(1,1)$ 的总体类别零专用单侧 95% 上界是 5；相应最坏漏见概率 $G(5)=3/56$，而 $G(6)=3/140$。

四格 $(00,01,10,11)$ 是相互排斥且合计为总体的类别。层内总体格数和样本格数需满足 $\sum_cK_{hc}=N_h$、$K_{hc}\ge x_{hc}$、$\sum_cx_{hc}=n_h$；联合抽样概率是

$$P(\boldsymbol X_h=\boldsymbol x_h\mid\boldsymbol K_h)=\frac{\prod_{c=1}^{4}\binom{K_{hc}}{x_{hc}}}{\binom{N_h}{n_h}}.$$

四个分别为 95% 的边际上界不自动拥有 95% 同时覆盖率。独立反例 $N=16,n=8,\boldsymbol K=(4,4,4,4)$：每格零专用边际程序覆盖率均为 0.96153846，但四格同时覆盖率只有 $1816/2145=0.84662005$。同一反例中，预先固定四格家族并使用 $\alpha/4=0.0125$ 的 Bonferroni 分配后同时覆盖率为 1；这只是该小总体的离散保守性，普遍保证为至少 $1-\alpha$。

可接受的联合四格保护应是预先规定家族错误率的保守同时区域，例如四个固定类别各用 $\alpha/4$，再与格数的整数/总和/观测可行性约束相交；或通过预先规定排序/检验统计量的精确多元超几何检验反演联合区域。若按层分别做边际保护，还须明确跨层及跨格的错误率分配。不能把“观察到该四格表的点概率”当作联合 $p$ 值；须求对应拒绝尾部的概率和。

**固定**的若干格的并集可合并为单类别：未见并集的概率只由并集总数决定。但是，“看完样本后才选所有零格组成的并集”是数据依赖选择；未经同时保护或联合反演，不能直接套单类别 $\alpha=0.05$ 就宣称四格联合 95%。在同时区域上推导非线性指标保护时，必须对可行四格表整体求极值，保留分子/分母共用格数的关系。零格保护用于阻止退化 bootstrap 被误读为总体确定性，不应伪装成原 percentile 区间本身已具有精确覆盖。
