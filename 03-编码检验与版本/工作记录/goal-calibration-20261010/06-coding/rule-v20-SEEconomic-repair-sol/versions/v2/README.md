# S／E／Ec v2 独立候选

已实施现冻结材料支持的通用执行修复：中文 AE／ADR／SAE／AESI 邻接、获益风险否定与证据不足、药物损害／耐受性／处方核验、概括安全有效与疾病控制效果、真实价格协商／报价／结算价、支付与费用信息、基金统计／支付能力／自费率口径，以及直接内容父谓词和有限同对象指代。纯报告名称、命名／压缩包上传、填写归类、行政／数据／基础疾病风险、孤立 PK／PD 与无标准治疗保留排除。未改手册定义。

关系执行已核条／款地址、当前与补充段的同源及组件、完整容器首末、成员序列与真实同源下一段。明确款次只消费本款；下一条／款只作闭合证据，不捐献标签。同段关系保存选定原句范围，拒绝标明另一药品／项目的独立事项。`affected_dimensions` 与 `only_IF_consumers` 取交集；价格关系也遵守消费者限制。

当前五模块算法绑定 SHA 为 `88eead7588d2e8353a4de6768cedd42a95ba4cb75c3dc819f6dd05aec9f5ac32`。入口：`source_packet.semantic_unit(bundle)` → `relations.RelationView(unit)` → `dimensions.judge(view)` → `evidence.validate_decisions(unit, decisions)`。输入是原冻结材料包；分类函数不读审查标签、ID、部门、年份或标题阳性表。标题、日期与 SHA 仅用于确指同版来源完整性约束。

封存后的定向回归实际核读 34 个冻结材料，核验 84 次阳性语境引文的精确字符位置与 source_ref。21 项结构控制、21 项剩余依赖控制、7 项消费者／跨源控制、4 项容器身份／款闭合控制及1项缺中间成员控制全部符合固定预期。40 项既定控制保留 A450 一项差异：原包只有孤立有序成员，没有容器末界，输出 null。旧 42 项控制保留2项合成“完整条文”差异，bridge 20 项开发暴露保留1项同类差异：这些旧合成包只有编号与句号，没有真正末边界，v2 停为 null。原预期未改；新增有真实闭合的对应条文测试通过。这些计数仅描述开发回归，不构成独立准确率、正式验收或真人金标准。

所有修改前／中途失败和输出保留。初次技术失败因引文字段增加额外属性，已改为在关系 details 保存边界角色，`evidence.py` 保持原样。早期探索运行未逐次绑定代码 SHA，不冒称其为逐次封存版本；最终八份回归结果已绑定当前精确算法。v1 封存49成员及 source_packet／source_receipts／evidence 均核验未变；本轮没有重跑800或77，没有读取正式 LLM 部分标签，没有接入新投影。

`merge-dependencies.json` 和三个 shared patch 列出 ROOT 合并冲突：`_add` 去重身份、`_units` 的边界证据与有限消费、judge 消费者交集，以及 `RelationView.__init__` 新调用。保留另一分支 I／F 的功能及精确请求解析，不将其支持或权利机制扩为本分支安全／效果／费用内容。

共同材料仍需补齐 A450 续约清单闭合；A307／A415 第八条原件末界；其余被冻结材料未交付的程序标准、恢复研究的风险条件、PRO 端点定义与价格／续约节点。已闭合第七条可独立支持实际涉及的维度，同时保留第八条未闭合请求，不声称整套条件已核完。A157 GLP、S八项未定、Ec A79／A149／A337、E704 不作为拟合目标，原复审判断保持。候选身份为非真人 AI／规则开发，需 ROOT 合并和独立边界复审。
