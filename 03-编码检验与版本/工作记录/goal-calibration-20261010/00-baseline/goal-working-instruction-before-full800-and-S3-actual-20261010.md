# 论文修订：完整Goal指令

最终目标是在当前对话完成创新药研究论文的完整修订：先核定成熟、科学的政策文本编码分析方法与完整指标体系，完成必要修正和独立检验，指标达到既定验收要求后，再以真实、可追溯的最终结果修订整篇论文，形成符合《科学决策》要求、可用于投稿的完整稿件。具体任务可随新证据调整，最终目标与既定验收要求不变。不能把一份阶段说明、局部手册或部分指标当作最终完成。

按下列完整步骤执行，有依赖关系的步骤顺序推进，独立任务可用并行对话或代理加速，最终由本对话整合：

1. **接收并核定研究材料。** 参考“盲评两份校准表”等旧对话的操作与过程文件，定位当前权威论文稿、原始政策语料、访谈、五维编码手册、A/B原始结果、机器预测和既有方法/指标研究。以`outputs/goal-calibration-20261010/`作为本次完整工作根目录，建立独立Python环境、原文/语境快照、来源/版本/哈希记录、代码、编码结果、统计、论文及交付目录和可执行的进度表。旧对话和旧目录只读；所有重编码、重计算和论文修订输出写入本次目录，绝不反复覆盖共同文件。用户已授权必要时从头编码和计算；是否重做以及具体范围由方法和版本依赖决定，不能自动把旧结果当新结果。保留全部原始判断及实际执行记录，并明确并行任务各自的输出范围。

2. **恢复完整科学的方法结构与指标体系。** 阅读本地相关文献和必要的新检索文献，优先原论文、官方政策和成熟方法资源。逐步说明参考谁的具体做法：研究范围与语料选择、分析单位和必要语境、定向内容分析与操作定义、开发校准、独立判读、分歧裁定、机器验证、重复稳定性、抽样/区间及注意力分布稳健性。找回此前专门研究指标的过程文件，形成“步骤—参考方法—实际实施—指标—证据—验收”的完整矩阵。区分统计公式错误、分母/样本/版本口径变化、实际标签误判和构念边界问题，分别修正。不能只检查κ和召回率，也不能加入与本研究无关的量表指标。

3. **校准并冻结五维共同手册。** 优先解决创新性、公平性，同时核查安全性、有效性、经济性。依据理论、权威政策原文和实际分歧，明确各维定义、纳入排除条件、必要语境、否定/条件/例外、计数归属及正反例。开发校准后将通用决定写入同一手册并记录实质变更；人工流程、自动规则和LLM共用相同概念口径。不能依期待部门占比、论文结论或提高分数选择定义及标签。

4. **实施冻结后的独立编码检验。** 先冻结手册、材料、抽样和统计方案，再让A/B独立判断未用于本轮开发的材料，遮蔽机器答案和另一方判断，保存协商前标签、理由和材料版本；之后另行裁定形成共同参照。明确AI初判、真人事后复核与真人独立初判的实际身份和作用。涉及真人执行时先准备完整盲包、操作说明和提交表，未执行的真人检验不得写作完成。保持覆盖三部门、罕见正类和机器阴性材料的可解释抽样，报告纳入概率/权重；开发富集材料与总体检验用途不能混写。

5. **修正、复算并验收全部必要指标。** 保留人工独立编码逐维Cohen κ≥0.80，以及两机器相对可信裁定参照逐维κ、Precision、Recall、F1≥0.80的项目目标。结合步骤2核定的完整体系，报告正负例数、可判/待定/失败数量、原始和适用的加权四格、观察一致率、正负类一致性、95%区间、实际误判类型；依成熟方法检查输出稳定性及下游注意力结构的稳健性，其他诊断指标按适用性预先确定，不能机械赋同一阈值。独立复算确认公式、方向、权重、分母和版本绑定。NA不得填成1，稀少样本不得以退化区间宣称充分。未达要求时只据可核查错误或有依据的边界修订；检验材料用于修订后转为开发，新的独立检验另行设计。保留实际失败及全部执行，不用挑选输出或协商后一致性抬高指标。共同手册与参照核定后，才启动必要的机器全量重编码；指标合规后，才能开始完整正文修订。

6. **确定最终结果与论文论证。** 从合格且可追溯的编码结果计算三部门五维注意力占比、明确分母、部门差异及组内排序；检查多标签、重复条文、年度系列、文件篇幅、联合发文及边界取舍对核心发现的影响。将分类效度、输出重复性与聚合结果稳健性分别解释。结合政策原文和已核实访谈建立“发现—解释—协调建议”的证据链，核心主张服从最强证据，不把文本呈现直接写成真实决策赋权或未经识别的因果效应。

7. **完整修订论文，并明确执行以下写作要求。** 以本地权威相关论文、实际检索的原论文及《科学决策》现行投稿规范为参照，形成完整的标题、摘要和关键词、引言、文献与理论/分析框架、研究设计与方法、研究发现、讨论与协调建议、结论和参考文献；根据论证需要合并或调整章节，不机械照搬其他论文。围绕创新药全链条三部门注意力配置的研究问题、独特贡献和成立的发现组织正文。方法部分明确“参考XX的具体做法”和本研究的操作化取舍，写清实际完成的流程及指标；正文不写成修改日志，不堆叠指标，不把AI代理称为真人专家，不虚构访谈、样本、检验或完成状态。全部数值、表图和关键引文对应同一最终版本；摘要、正文、讨论、结论及建议相互一致。保留必要的边界说明，避免过度防御和超出证据的主张。精简参考文献：优先高相关原始研究、经典方法、必要制度来源和直接支持论证的近期权威文献，同一方法步骤用最少必要的核心来源；删除重复、低相关和只在开发过程用到的文献。数量由实际论证和期刊规范核定，不为凑数量堆文献。表图、章节编号、摘要/关键词、中英文信息和引文格式符合期刊要求，技术细节及完整过程记录按需进入附录/配套材料。

8. **核验并交付完整修订稿。** 交付可编辑的完整DOCX、核验后的PDF、必要附录/编码手册与统计复现材料、简明修订说明；如投稿需要，制作署名和匿名版本并核查匿名性。核对全部指标/分母/表图/引用/编号、参考文献实际引用及来源、未完成事项和期刊格式；完成文档渲染及逐页视觉检查。只有完整方法、指标验收、论文正文及配套材料都实际完成且经过核查，才能把Goal标为complete。“可发表/可投稿”表示方法与稿件达到本项目和目标期刊要求，不保证期刊录用。
