# 第三轮三条关系的只读审查

2026年10月15日。范围仅04550/I、02232/I、02375/S。已读共同手册与原保存语义输入中的当前句段和必要语境，未改代码、原始标签或论文。本报告给出实现边界，不因人工标签为1就认定规则必须改成1。

## 04550：创新类别决定生产核查义务，I4可以成立

**当前完整句：**“对于创新药、改良型新药以及生物制品等，应当进行药品注册生产现场核查和上市前药品生产质量管理规范检查。”

**直接前段：**“第四十七条 药品审评中心根据申报注册的品种、工艺、设施、既往接受核查情况等因素，基于风险决定是否启动药品注册生产现场核查。”

这里有一个明确制度关系：一般情形基于风险决定是否启动；对当前列明的创新药、改良型新药等类别，则规定应当执行指定核查。不是仅在题名中出现创新药，也不是以创新身份描述任何一项日常义务。

**精确手册依据：**

- §六第4项：“明确的法定创新/改良分类若在当前被设为决定差异化准入、续约或其他权利义务的条件，可记录该分类的制度使用，不要求重新评价创新；这不是I3研发支持，也不证明产品临床优越。”
- §六后续解释：“引用既有法定类别时，须有当前创新/改良资格到实质准入、待遇或权利义务的决定关系。”
- §五末段：“I4同样要求创新/改良资格与当前实质权利义务相连，不能对一维使用内容门槛、另一维使用字段门槛。”

**最小可泛化实现：** 当前明确类别条件“对/对于创新药、改良型新药…”直接治理具体注册核查/检查义务；保存类别和义务两个连续锚点，必要时附相邻一般风险决定语句支持差异性。该句已使用类别中文名称，不必因未出现“1类/2类”拒绝；数字类别的药类与时期校验仍保留。并列“生物制品”分支不能统称创新。该I4不自动产生S：生产质量检查未展开药物损害关系时不能由质量检查补安全性。

**必须保留的近邻反例：**

1. “本指南适用于创新药、改良型新药，申请材料应签字盖章。”——一般对象＋手续，不应有I。
2. “该创新药按一般要求提交安全性更新报告。”——项目身份＋通用义务，不能仅凭应当新增I。
3. “对于生物制品，应当进行生产现场核查。”——没有创新/改良类别，不据生物制品身份判I。
4. “材料中填写是否属于创新药，以及现场核查日期。”——字段记录没有当前资格—义务决定关系。

**原输入定位：**当前/完整段 `CTX-8977352dd41b6f1b6554`；前段 `CTX-edd0a65dfc86c97c7658`；主来源SHA `d959108cdaaa3b46c8334c217619a42f14c4d83f17af0934502a08c5d62864be`；当前 `p0110/u00146`。本例不是临床试验登记义务，是注册生产现场核查及上市前生产质量管理规范检查，应使用原文准确名称。

## 02232：按研发需要选择同段已定义资源倾斜通道，I3可以成立

**当前完整句：**“申请人应当根据品种研发的实际需求，合理选择30日通道或者60日默示许可，并将临床试验开展等情况登记至药物临床试验登记与信息公示平台。”

**同段直接定义：**“30日通道是国家药监局将现有审评审批资源向符合条件的创新药临床试验申请倾斜的改革举措。”其后说明12周启动承诺及快速临床研发需要，然后才是当前选择句。

**手册依据：**§六I3明确包括“办理便利或申请机会”，创新/改良研发须是“对象选择条件、支持目标或实际适用依据”；§二允许必要语境补当前已表达的对象、指代和同一具名安排直接机制。当前并非单纯登记，前半句已规定按研发需要使用可选审评路径，后半句手续不清空前半句。

**最小可泛化关系：**

1. 当前实际选择/申请某个具名审评通道，且选择与研发需要直接连接；不只匹配名称或时限数字。
2. 同源同一原段、当前之前，有该同名通道“是/指……”的完整定义。
3. 定义同时给出实际审评资源倾斜/加快机会、明确创新药研发对象和二者联系；仅同段标题含创新药不足。
4. 保存当前选择锚点及定义整句；仅把已定义的那一个选择分支记为I3。这里30日通道定义成立，不自动认定60日许可也以创新资格分配同等资源。

不必硬编码30、60；可抽取通道名称并核对同名定义。数字自身不证明更快。若通道同名但来源SHA不同、定义不在同一段、当前转向别的对象或只是填报形式，不能使用本路径。缺少理想化定义而当前没有确指缺材关系时，不应无限要求补材料。

**近邻反例：**

- “将选择30日通道的情况登记到平台。”——这里只记录已选状态，没有当前使用/授予机会。
- “根据实际需求选择纸质或电子方式提交临床试验材料。”——形式渠道，不是研发资源。
- “30日通道是材料格式核验通道，供所有申请人使用。”——不能从全文创新题名补I。
- 当前选择另一通道、同段只定义30日通道，或另一段定义向仿制药倾斜——不能移植创新对象/资源关系。

**原输入定位：** `CTX-ef584d0a627b3b27b940` 为完整同段，structure中 `paragraph_id=interp_p015`、PDF第4页；主来源SHA `98d27e43d9bd4c8174e42d221dbdfc8489882a9ba92b308473abca071e0f7a1a`；当前 `interp_u028`。前段只是小节标题，不能拿它代替完整定义。

## 02375：近效期先出并避免过期药品，可作有限安全控制路径

**当前完整句：**“遵循近效期先出的原则，避免出现过期药品。”

**同一原段：**以“（四）加强医疗机构药品安全管理”开头，随后规定采购、贮存、发放、调配、使用全过程管理，以及库存养护、质量检查，再到当前避免过期药品，后续另有特殊/高警示药管理。

**手册依据：**§三将药物风险的预防与控制纳入；“质量内容明确关联药物损害、用药风险或其控制时纳入”；边界允许“用药/治疗服务中的具体药物风险管理”，但排除仅稳定性/质量可控。§二要求当前与必要语境有直接关系，不能复制整个标题的标签。

本例可以作为窄S修复：当前已具体规定防止过期药品出现的流转措施，同段局部治理范围明确是医疗机构药品安全管理，且涉及发放、调配和使用，足以把避免过期解释为当前风险控制。理由只写“药品安全管理中的过期预防措施”，不要补写原文未提及的中毒、失效概率或已经造成损害。

**最小实现边界：** 当前同时有药品对象、近效期先出/避免过期的具体操作与目标；同一原段显式药品安全管理谓词承接这一动作，范围在当前之前且没有另起对象或分支。保存当前预防锚点与同段治理范围，不能只加“过期”到S关键词表。若只有同文档其他段安全宗旨，则不触发本路径。

**近邻反例：**

1. “按近效期先出减少库存损耗。”——若只有成本目的且没有药物风险控制关系，不自动S。
2. “登记药品有效期”“统计即将过期药品数量”“药品说明书有效期字段不能为空”——不能由字段或库存数据推安全控制。
3. “定期检查药品稳定性/包装颜色/贮存条件”——仅质量要求不能仅因同段安全标题就都赋S。
4. 同段“对药品使用数量进行科学预估”“实现来源去向可追溯”——本路径不能将其全部纳入S。
5. “避免过期合同/证书”——对象不是药品。

**原输入定位：**完整同段 `CTX-51bd797d322a647bf254`，structure为 `paragraph_id=p0008`、PDF第45页；主来源SHA `41fd5850064ce8c323aba84a3f39f08be93821d7998b256ca6be93323baeea33`；当前 `u00027`。heading“二、强化药品合理使用”本身不足，实际使用的是同段开头及当前具体控制动作。

## 实现与核验要求

三条均可在已提供的有限语境中处理，不需要查新政策或重跑模型。I4类别义务、I3同名通道使用、S过期预防应分别留痕；不得由某一维成立带动其他维。新增路径先用上述近邻反例检查，再回放77+200，人工参照保持原样。它们属于已知分歧的开发修复，不能把同批回归改善改称新的独立检验。
