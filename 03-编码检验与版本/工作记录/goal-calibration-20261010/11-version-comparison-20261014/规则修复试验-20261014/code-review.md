原因：新增排除仅豁免“评价/评估/比较/分析/测算/核验”，但手册明确将提供、提交、核对等实质内容要求纳入。后半句脱敏的是企业/患者身份，不是对前半句实质要求的否定。全句提前返回True绕过了原有分句判断。

建议：只把当前维度作为文件版本筛选、删除对象且没有独立实质内容要求的分句排除；独立提供/提交/补充/核对指定维度信息的分句保留。仅机械扩充动词白名单仍可能误把“提交两个版本”的形式操作当内容要求，应检查动词与指定实质内容关系。保留已有纯版本删去经济性信息的反例。

已执行反例：
