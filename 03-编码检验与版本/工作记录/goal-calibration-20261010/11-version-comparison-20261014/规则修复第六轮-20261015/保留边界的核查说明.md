# 本轮没有扩展的编码边界

本文件记录继续核查时保留的判断边界，不裁定人工答案错误，也不修改共同手册。实际剩余分歧及数量以最终逐项复算为准。

|记录|涉及维度|当前材料及本轮处理|
|---|---|---|
|00129|创新性、公平性|当前为申请优先程序者设置检验通知、初步审查及通知安排。申请程序不能直接等同已经纳入程序；2日、25日数字本身也不能证明给予创新研发或按需优先资源。本轮不把纳入后的全部待遇移给当前手续。|
|02507|创新性|当前确实提供创新药目录准入政策指导，但具体用途为主规格、参照药及支付范围。是否将这种支付准入服务纳入手册所指的实际创新研发支持，需要直接用途联系，不能仅从“研发支持力度”标题或创新药对象推定。本轮未扩大I3定义。|
|03796、03798、03799|创新性|同段明确延长附条件上市转常规批准药品的目录申报机会，说明其有利于临床数据积累和价值确认，也称为对创新的支持。这里的边界是目录准入机会与创新研发支持、创新资格之间的关系；不能把附条件批准、新通用名自动当成创新分类，也不能只因“支持”一词消除分歧。当前完整条件与原人工答案均保留。|
|03840|创新性|当前针对1类新药开展参照药预沟通，主要为后续药物经济学研究及目录评审提供基础。仍需区分法定创新分类的实质资格使用、药品支付对象与创新研发技术服务，不能只凭“1类”数字跨药品类别推定。|
|03526|安全性|当前培训内容包括知情同意、试验管理及风险控制。风险控制可能包含药物损害，也可能包括一般试验管理；本轮没有从全篇安全宗旨或远处用药风险段落直接给本句加标签。具体承接关系仍保留审查。|
|03780|公平性|同段的多元支付关系可以支持经济性判断；“多层次医疗保障体系”尚未单独说明患者支付能力、具体治疗保障缺口或按需获取差异，不由经济性自动推出公平性。|

这些边界不能靠回改人工答案、把未识别项删出分母或继续扩充词表解决。若后续决定调整测量范围，须先统一手册并形成新版本，再评价该版本；不把同一批材料反复调整后的分数表述成未经调整的独立检验。
