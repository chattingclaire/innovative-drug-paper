# AI 复核工作簿交付准备

此处仅保存生成程序、校验记录和预览支持文件。准备阶段不读取两位 AI 的判读结果，不导入或导出工作簿。

两份 predictions.json 都提交并经协调者明确通知后，执行：

```sh
/Users/rainbow/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node '/Users/rainbow/Desktop/战略院/药企项目-创新药/outputs/goal-calibration-20261010/09-delivery/AI独立复核-200条-20261013/_build/build-ai-workbooks.mjs' --confirmed
```

程序填入原始空白工作簿的 D、E 两列，并将两列表头明确标为 AI 判定及 AI 理由。D 表头主动分行。保留原有“独立初判”工作表名称、A–C 列、材料链接、顺序和单元格样式。按每行理由的中文、英文显示宽度和显式换行估算所需行高，行高不低于原模板；E 列按理由长度分布最多扩到 96 列宽单位，D 列适度扩宽。每项可读性变化都记录在对应 layout-adjustments.json 中。超出 Excel 安全行高时停止，不能截断交付。原始真人工作簿不变。导出分别保存到 AI复核者A/AI复核-A-200条.xlsx 和 AI复核者B/AI复核-B-200条.xlsx。

材料和附件从对应原始文件夹复制，并原样复制“材料目录.html”和“共同编码手册.txt”，逐文件核验 SHA-256。不会复制原“开始阅读.html”、真人填写说明、真人提交说明或空白工作簿。两位复核者各自提交的“AI复核说明.txt”必须已经存在，程序只读并校验处理前后 SHA-256 相同，绝不覆盖。程序另写“AI交付说明.txt”，并为原样材料目录所依赖的“填写说明.txt”生成 AI 身份明确的兼容导航说明，指向现有 AI 复核说明。保存当前 AI 工作簿后，生成“AI复核阅读入口.html”链接工作簿、材料目录、共同手册、复核者原始说明及技术交付说明。两份产物均为 AI 复核，不能用作真人首次独立提交。

每份导出使用独立只读校验器核对全部 2000 个判定及理由单元格、200 条完整身份、1000 条材料链接、复制文件的 SHA-256，以及原始数据、全部单元格样式、黄色输入区、A–C 列宽、冻结和校验设置。D/E 列宽和各行高度必须与明确记录的可读性调整一致，且不得降低原行高。不得隐藏行列。核验全部 200 个材料页、原样材料目录、新阅读入口中的本地 href/src 路径，跳过外链，确保文件存在。校验未通过即停止，不报告完整交付。

完成运行后必须查看 A、B 各三个 PNG 预览（开头、最长理由、末尾），确认文字可读、无裁切。build-report.json 中 visualReviewPending 为 true 表示程序未代替人工或代理视觉检查。未经视觉检查不可报告完整交付。

程序可重复运行。operation-started.json 用于避免同一编辑任务重复发送启动标记。全部支持文件均留在本目录。
