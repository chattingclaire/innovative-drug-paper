# 统计引擎分域接口 1.1

本目录仅交付源码、接口说明和构造数据验证。真实抽样、真人编码、新 AI 标签或预测、真实项目统计执行次数均为 0；没有安排人员。所有 toy ID 均为构造字符串。输出中的 `formal_acceptance` 始终为 false。代码和哈希不能认证真人身份、盲法、材料版本或参考标准的可信度。

## 改动范围

旧版 `prospective-engine-sol` 整目录保持原样。旧源码的本地副本 `old_engine_source_frozen.py` 只用于构造数据回归，避免在旧目录产生缓存。`old-version-preservation-baseline.json` 记录旧目录全部 56 个文件的基线，包括旧缓存；其中原封存清单的 54 个文件已逐一验哈希。最终复验另见 `old-version-preservation-final.json`。

| 项目 | 旧版 1.0 | 本版 1.1 |
|---|---|---|
| 输出视图 | ALL、部门 | ALL、remaining、exposed、部门、非空分域×部门 |
| 分域依据 | 无显式域字段 | 冻结 `stratum.domain`；只能是 remaining 或 exposed |
| 重复权重 | 一次完整单位矩阵 | 同一次完整矩阵应用所有视图、方法、维度；不按域重抽 |
| 点指标 | 每个视图的加权四格表 | 相同；全域四格先相加，再算 κ/P/R/F1 |
| 数值门槛 | ALL 的逐维 κ / κP/R/F1 点值 ≥0.8 | ALL 门槛保留；另报告各视图自身的逐维 flags |
| CI | v2 FPC rescaled bootstrap | 不变：默认 B=5000、seed=20261010、linear percentile；保留 NA/退化提示 |
| 有限计数 guard | ALL | ALL 和声明完整层归属的分域视图；不赋予跨视图联合覆盖 |
| 解析协方差 | 协方差与梯度 SE | 相同，只作诊断；未增加正态 CI、验收门槛 |

旧设计完全不含 `stratum.domain`、`design.domain_population_N`、`design.domain_partition` 时保持 legacy 行为。构造数据回归逐项对照旧版比较表、点值、数值 flags、CI、unknown/failure、部门注意力差值、正式审核状态及 W 哈希；新增说明字段不改变数值。

## 输入与冻结约束

唯一入口是调用方明确提供的完整标签 ledger；引擎不会找语料、取正文、抽 IDs、生成模型答案或自动加入参考标签。每个单位一行，同一组人、规则、LLM 和参考标准在同一 ledger 中对齐。共同手册、材料、设计、规则和 LLM protocol 的 seal 仅在全局 metadata 中声明；分域使用同一组全局绑定。`domain_inputs/domain_input_seals/domain_artifact_seals/domain_protocols` 覆盖被拒绝。

命名分域模式由上述任一 domain 字段出现触发。一旦触发，每个层都必须明确写入 remaining/exposed 和非空固定部门；部分缺失、null、空字符串、其他域标签均拒绝。行必须显式给出与该层一致的部门；行级 domain 字段被拒绝，不能用答案或 ID 推断归域。层 ID 唯一，单位 ID 唯一，每个单位归属一个登记层，因此域掩码互斥且覆盖全部登记单位。

`domain_population_N` 可以由完整正纳入概率层的 ΣNh 推导；若提供，键集合必须恰好等于实际存在的域，每个值是严格正整数且等于该域 ΣNh。声明 `domain_partition: remaining_exposed` 时必须两个域都非空。命名 `full_4481_audit` 须恰为 remaining=1444、exposed=3037；命名 `remaining_1444` 只允许 remaining=1444。构造小样本使用明确的 synthetic scope，不冒充真实项目。

新 41 层设计示例在两个 `full*-synthetic-schema.input.json` 中使用完整双域声明和上述 4481/1444/3037 检查。这些示例仅采用原计划的 N/n/domain/department/schema 投影，全部单位 ID 和标签由封闭公式构造，与原辅助标签无关。原剩余域 n600 分配未重算、未修改。

每层仍须严格整数 1≤n≤N。非普查层 n=1 不支持方差估计而拒绝；n=N=1 的普查层合法。不得删去未返回或执行失败的单位来改变 n。

## 输出及同一次 W 的使用

输出视图 key 为 `ALL`、`domain:remaining`、`domain:exposed`、`department:<部门>`、`domain:<域>|department:<部门>`。只有非空视图登记；单 remaining 设计不输出虚构 exposed 结果，空交叉视图不伪造 0 或通过 flags。

`analysis_scopes` 包含冻结层成员、n、可识别的总体 N、assigned 加权总量、普查状态、完整单位 mask 哈希、同一个 W 哈希、重复 assigned 总量范围及全局 seal 引用。`comparisons.*.domains` 和 `attention.*` 使用这些相同 key。`numeric_targets_by_analysis_scope` 报告各视图独立的点值 flags；`numeric_targets/project_review` 原有全域入口仍只取 ALL。没有平均域指标，也没有新增“各域全部通过”或 CI 下限/半宽验收条件。

所有视图将 full-length 单位指标在域外置零，再计算 `W @ X`。不会缩小 n、另算 FPC 或按 comparison/domain 重新生成 W。full800、full1000 的默认 5000 次重复分别验证全域权重常数 4481、remaining 常数 1444、exposed 常数 3037，并验证每一比较×维度的完整 16 状态表和部门交叉表可相加。

remaining/exposed 是互不重叠完整层的并集；在该分层设计下，它们的解析抽样交叉协方差为 0，Var(ALL)=Var(remaining)+Var(exposed)。legacy 的同一层内部观测部门划分通常具有非零交叉协方差，不能机械相加部门方差。解析协方差仍只输出诊断 SE。

域内全部成员层普查时，已定义指标可有零抽样误差区间；没有可比较 pairs 或分母为零时仍保持 NA。legacy 仅凭抽中单位的部门不能认证总体部门归属；全总体普查或完整冻结层部门归属才支持部门普查判断。

## unknown、failure 和 guard 的边界

κ/P/R/F1 的点值继续只针对双方完成且确定的二元 pairs。其余 assigned 单位、设计权重、语义 null、缺失返回、整体失败及逐维失败继续进入 4×4 表、状态分母和注意力 unknown 范围。unknown 范围是部分识别范围，不是 95% CI。

有限计数 guard 仅对某个完整层并集视图缩小计数的总体宇宙；不会缩小或重生 W。单类别 guard 是单个类别的边际覆盖；joint16 是某个视图中一个比较×一个维度的完整 16 类计数集合。它们不提供所有视图、45 指标或 κ/P/R/F1 的联合区间。joint16 的严格非线性指标投影尚未实现，输出固定明确标注 false。

## 运行与验证

使用项目现有 Python/Numpy/Scipy 环境，无新增依赖。相邻 `verify_domain_engine.py` 运行必要分域回归；两份独立 review 放在 `independent-math`、`independent-interface`。运行示例中的输入与输出均限本目录构造数据：

```text
python -B metrics_engine.py --input toy-small.input.json --output toy-small-defaults.cli.output.json --guard-mode joint_table
python -B verify_domain_engine.py
```

CLI 默认值确认为 B=5000、seed=20261010，并在结果中记录完整输入文件和源码 SHA256。正式输入还需要真实的事前冻结设计、输入 seal/对应投影、一致材料和手册、独立初始真人与可信人工仲裁，以及外部身份和来源证据审查；这些均没有在本轮实施或认证。
