本目录为分域统计引擎的独立年度接口扩展。仅使用明确构造的标签与来源年份；未读取真实机器标签或 Gold，未计算真实年度结果，未修改旧引擎、抽样、标签、progress 或 Goal。

`metrics_engine.py` 在旧分域引擎上增加 `records[].policy_year`。整个输入未启用年份时，`analyze()` 的完整返回值与旧 1.1 接口一致；启用后输出版本为 1.2。命令行的引擎路径及哈希指向这个新文件。

启用年份后，每条已分配记录必须明确提供整数或 null。`metadata.year_mapping` 绑定独立冻结的来源赋年工件和连接后的年份投影；实际项目采用该文本版本的成文或原公布年。输入不接纳文件名赋年，也不会从 ID、标签或生效日推断。哈希校验保证所提交映射不被静默替换，真实日期证据仍须由调用方核验；本引擎不打开来源正文或外部映射文件。

新增 `year:2020`、`department:alpha|year:2020`、`domain:remaining|department:alpha|year:2020` 等视图。未赋年的全部权重、未知和失败状态保留在 `year:unknown` 及相应交叉视图中，其 `calendar_year_effect=false`，不能解释为年份效果。年度视图均使用原层 N_h/n_h，以及同一次全设计 Rao-Wu FPC 复抽矩阵的全长掩码；年度并未变成新的抽样层。

年度 q 为主：每种方法分别以自己的五维命中总量归一。p 为覆盖率补充。年度 `q` / `p` 仅在对应标签与分母完整可定义时给出；未完成时返回 null 和 `unresolved_labels`，同时保留已知命中量、null/失败量和未知界限。全部已知 0 时 p 五维为 0、q 五维为 `NA(no_dimension_mentions)`；若其他维已有命中，本维真实 0 的 q/p 均为 0。`known_hit_*` 和其区间始终只是名称所示的已知部分，不能冒充未完成的年度 q/p。

`requested_years` 可显示空年；只有独立冻结的 `no_source_views` 或已全查的父范围能判定无来源。概率样本没有该年观测时，状态为 `NA(no_assigned_year_observation_population_presence_unknown)`，年度总体 N 为 null；不能据此断言全框无来源或维度为 0。冻结的无来源声明对应 `NA(no_observed_source)`、N=0、q/p=null，且不得与任何已分配记录矛盾。非全查年度的 `weighted_assigned_total` 是原权重 HT 分母估计，不是独立核实的年度总体规模。

年度域可能切开原层，因此新年度视图不会套用原来要求“完整层并集”的有限计数 guard，也不会把年度样本数改作新的 n_h。相关输出明确标为不可用。年度区间仍可按全设计权重计算，稀少阳性、无定义分母、退化复抽与无法作无条件区间声明均保持显式。整体 ALL/.80 点门槛和既有项目复核保持原样；年度点标志只供描述，未增加逐年过线、CI 下限或半宽门槛。

重现控制：在本目录运行 `PYTHONDONTWRITEBYTECODE=1 python3 run_controls.py`。脚本自行生成带意义说明的构造输入、独立冻结来源年份映射、真实控制输出和报告，并实际运行一次命令行接口。`control-report.json` 汇总跨层非均匀纳入概率、共享复抽矩阵、单年仅 1 个阳性且 0 错误、真实零与 NA、null/三类失败、年份绑定拒绝及旧接口回归。36 个旧接口组合比较整个返回值；主要概率构造控制使用原默认 5000 次和 seed 20261010。

`input-seal.json` 绑定三个只读依据文件、构造输入与来源年份映射；`output-seal.json` 绑定新代码、契约、说明、控制报告及实际输出，并绑定 input seal。二者自排除避免递归哈希。本交付仅增加年度验证域接口；来源/组件/系列敏感性、相邻年差及实际论文年度发现仍由冻结计划和后续已验收全量输出完成。
