## 2. 未来输入合同

顶层 `data_role` 只能为 `synthetic`、`historical_arithmetic` 或 `sealed_project`。历史算术和合成数据均不能构成前瞻验收。`metadata.analysis_stage` 允许：

| 阶段 | 允许输入的方法 | 可计算比较 |
|---|---|---|
| `human_first` | A、B | A 与 B 的独立初始一致性 |
| `machine_reference` | reference、rule、LLM | 两种机器分别对可信裁定参照 |
| `combined` | 五套方法 | 三组比较及各方法关注度 |

只接收当前阶段的方法；夹带其他未封存输出会拒绝。部分阶段不可能满足整个项目的全部数值目标。

每条分配单位仅允许 `unit_id`、`stratum_id`、`department`、`outputs`。正文、语境和判定理由不进入统计台账。单位 ID 必须非空、唯一。完成输出必须为：

```json
{
  "status": "completed",
  "labels": {"S": 1, "E": 0, "Ec": null, "I": 0, "F": 1}
}
```

五维各自独立，标签只接收整数 0、1 或 JSON null；布尔值、字符串、NaN 均拒绝。`null` 表示语义不可判。方法技术失败写 `status: "execution_failure"` 且 labels 为空或 null；某维技术失败用 `dimension_status` 将该维标为 `execution_failure`，对应 label 必须为 null。缺失返回、整套方法失败、单维失败分别记账。失败不能携带有效标签。一个维度不可判或失败不会删除其他维度的有效结果。

对 `sealed_project`，引擎先核验当前阶段全部输入 `sealed` 必须为真正的布尔 true、原始提交 SHA256 格式有效，再处理标签。加入后的台账还必须符合：

1. `design.assigned_ids_sha256`：在回答之前冻结的分配 ID 集哈希；对排序后的 ID 列表进行规范 JSON 哈希。
2. 每套方法的 `joined_projection_sha256`：按 unit_id 排序的 `[{"unit_id": ..., "output": ...}]` 哈希，包含全部标签、状态及缺失返回。不能把初始提交改为讨论后的标签再沿用旧绑定。
3. `input_seals[method].sha256`：原始封存文件字节哈希，调用方保留原文件并独立核验；本引擎不打开这些原始路径，仅检查绑定字段及加入投影。

规范 JSON 使用 UTF-8、`ensure_ascii=False`、`sort_keys=True`、紧凑分隔符且禁止 NaN；可直接使用引擎 `canonical_hash`、`projection_hash`。投影绑定应从已封存提交建立，先核验、后加入台账；不能在修改标签后重新生成一个哈希并称其为原始封存。

真实身份与冻结元数据包括 A/B 的不同真实人身份码、独立初始提交证明、裁定人员身份与可信性、裁定对机器盲法、共同手册与材料、回答前设计、讨论前初始提交、机器比较前参照、测试反馈前最终规则与 LLM 版本，以及外部证据审查。软件读取这些明确声明，不能凭声明自行认证真实身份或时间顺序。

## 3. 设计、范围和分母

实现范围是**固定分层、层内单位级简单随机不放回抽样**（`stratified_srswor`）；抽样单位为 `source_unit`，每层记录整数 `N_h`、`n_h`。所有非空总体层均须有正纳入概率；`1 <= n_h <= N_h`，实际分配记录数须等于 n_h。非响应保留为失败行，不能删掉后减小 n_h。全取层包括 `N_h=n_h=1` 合法；非全取 `n_h=1` 拒绝，不能伪造零方差或事后合层。本实现拒绝家族/整群/两阶段设计。

层基础权重为 `N_h/n_h`，未知和失败单位仍携带此权重。建议部门作为冻结分层的一部分并明确 `stratum.department`；这样部门纳入总体与分母直接由该部门各层 N_h 确定。若允许一个层跨部门，部门结果是使用原设计权重的域比例估计，部门权重分母亦为估计量，不能声称已知固定部门总体大小。

范围必须分别标识：`remaining_1444`、`full_4481_audit`、`development` 或明确的合成/历史算术域。只有对应冻结抽样框的正概率域可以作该有限总体推断。1444 剩余域不能证明全部 4481 条；开发材料不能拼入剩余域冒充独立测试。开发或其他非概率材料用 `nonprobability`，权重列等于原始描述总量，不给总体 CI。

每维输出原始与设计加权的完整 4×4 表，状态顺序固定为 `[0,1,null,execution_failure]`；另给 0/1/null 的 3×3 表、失败总量、各侧全部分配的阳性/阴性/未知/失败数、各侧可比阳性/阴性数及可比 n/权重。二元指标只用该维双方已完成的 0/1 配对，描述**可比确定子域**。引擎保留其他分配单位并报告未知和失败；不把完整案例重新解释为整个分配总体。

## 4. 指标方向与 0.80

四格统一为 `(a,b,c,d)=(行1列1,行1列0,行0列1,行0列0)`。人工为 `(A1B1,A1B0,A0B1,A0B0)`，不假定 B 是真值；机器为预测在行、可信参照在列，即 `(TP,FP,FN,TN)`。

令 M=a+b+c+d，则 `Po=(a+d)/M`，`Pe=((a+b)(a+c)+(c+d)(b+d))/M²`，`κ=(Po-Pe)/(1-Pe)`；`Ppos=2a/(2a+b+c)`，`Pneg=2d/(2d+b+c)`。机器 `Precision=a/(a+b)`、`Recall=a/(a+c)`、`F1=2a/(2a+b+c)`。额外诊断 `Specificity=d/(b+d)`、`NPV=d/(c+d)`；两者方向已用不相等的 FP/FN 算例与 sklearn 对照核验。

Ppos 与 F1 公式相同；人工 Ppos 是对称阳性一致性，机器 F1 是对可信参照的阳性重叠，数值相同不等于可靠性与有效性相同。M=0、Pe=1 或相应分母为零时指标为 JSON null，不能将 NA 改为 1。F1 直接按四格求值：例如 TP=0、FP>0、FN=0 时 F1=0，即使 Recall 无定义。

原始与加权点值分别报告。设计加权四格使用有理数，并用精确 `4/5` 检查 0.80，避免显示四舍五入造成误判。目标只适用于每维人工 κ，以及每套机器每维 κ、P、R、F1；ALL 目标不被部门值、Ppos、宏平均、AC1、CVI 或 KMO 替代，也没有新增 CI 下限或半宽门槛。

`all_numerical_point_targets_met` 仅说明当前可比子域点值的数值标志。`metadata_attestations_complete_for_project_review` 仅说明元数据声明齐备。`formal_acceptance` 始终为 false，正式项目结论需要另行核验真实独立人工、可信参照、版本、范围与未知材料处理。合成示例即便全部点值达到 0.80，也不能通过真实项目验收。

## 5. 共同单位 bootstrap 与有限总体修正

每次重复在各非全取层，从已抽中单位中有放回重抽 `m_h=n_h-1` 次，令多项计数为 k_hi，取：

```text
f_h = n_h/N_h
factor_hi = 1 + sqrt(1-f_h) * (n_h*k_hi/(n_h-1) - 1)
replicate_weight_hi = (N_h/n_h) * factor_hi
```

全取层权重固定为 1。每层每次权重合计严格为 N_h，非全取重复因子为正。**只生成一张单位重复权重矩阵，五套方法、五维、所有比较与部门域共同使用**；不能分别重抽机器与裁定，或仅重抽可比/阳性案例。

该式是 [Beaumont–Émond (2022), §3.3 式 (20)](https://doi.org/10.3390/stats5020019) 在单阶段 SRSWOR、m=n−1 下的 FPC 重缩放特例。不能用忽略 FPC 的 RW 包选项代替，也不能在结果方差外再乘一次 FPC。对任意单位变量向量，解析总量协方差为 `Σ_h N_h²(1-f_h) S_h/n_h`（S_h 的样本分母为 n_h−1）。完整条件 bootstrap 协方差与此估计量严格相等；非线性 κ/P/R/F1 另给梯度线性化 SE，属于一阶近似。

## 6. 零格、稀疏格与保护接口

引擎反演层内超几何抽样模型的参数 T，保留 `P_T(X>=x)>=α/2` 且 `P_T(X<=x)>=α/2` 的整数总体类别数。依据是不放回抽样的 [超几何 PMF](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/Hypergeometric.html)；区间是总体参数 T 的置信集，不能直接使用抽样计数的 `hypergeom.interval` 分位数。

`--guard-mode single_category` 对预先固定的 FP/FN 或 A1B0/A0B1 各自给一个跨层 Bonferroni 总数保护，**每个类别分别为边际 95%**；这些区间不能当成同时四格或 κ/P/R/F1 的区间。`--guard-mode joint_table` 对一组比较×一维的全部层×16 个状态类别分配 `α/(H×16)`，给同时类别计数集，并要求层内整数计数合计 N_h。它包含未知与失败，避免将四格擅自合计为全部 N_h。

**本版未实现从联合计数集自动投影到非线性指标的优化器。** 已输出严格接口：必须在整个耦合可行整数集合上求指标极值，保留无定义分母的可能性，只有独立绑定的总体边际才能加约束。不能逐个替换边际端点，或把单类别上界直接冠名为指标 CI。联合保护家族也只是一组比较×一维，不跨越 45 个指标。遇到需要此类严格稀疏指标界限的真实结果，保留 count set 与保护状态，待可信投影实现/复核，不输出冒名 CI。

## 7. 关注度、未知比例与部分识别

政策文件绑定为 `inputs/unknown-and-denominator-policy.json`。每套方法每部门/全域记录已知阳性 k_d、语义 null、技术失败及其分型；u_d 包括 null 与失败，不能拿机器标签补成人工裁定。

覆盖度为 `p_d=k_d/N`；关注份额为 `q_d=k_d/H`，`H=Σ_d k_d`。同一单位可命中多维，各维至多计一次。未知覆盖范围为 `[k_d/N,(k_d+u_d)/N]`。H>0 时，各维 q 的边际范围为 `[k_d/(H+Σ_{j≠d}u_j),(k_d+u_d)/(H+u_d)]`。这些是给定观测/设计加权总量的部分识别范围，**不是 95% CI，五维极值也不必同时实现**；已知命中率/份额的抽样 CI 另列。

H=0 时观测 q 无定义；无未知时没有可定义份额。若未知只在目标维，条件于最终总命中大于零该维份额为 `[1,1]`；若只有其他维未知，该维为 `[0,0]`；双方都有未知则为 `[0,1]`。程序同时记录“正总命中是否可能”和“零总命中导致无定义是否可能”，不把五维零向量当份额。部门差值的范围为 `[lower_A-upper_B,upper_A-lower_B]`，条件于双方总命中为正，另保留无定义可能性。
