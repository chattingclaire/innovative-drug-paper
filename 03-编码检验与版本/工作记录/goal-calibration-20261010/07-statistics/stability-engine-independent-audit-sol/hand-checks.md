## 两个原接受反例与两个外部依赖边界

`inputs/census-boolean-pi/` 将全核 π 填为 JSON true。原CLI成功产出 `originalbugoutput/census-boolean-pi/`，因为原程序用 Python `True == 1`。修复副本复用精确正有理数解析器，拒绝 bool，继续接受数值1及精确字符串1/1。

`inputs/retry-policy-json-type/` 将两个要求为 true 的重试策略字段填为数值1。原CLI成功产出 `originalbugoutput/retry-policy-json-type/`，因为字典相等比较把1当True。修复副本显式检查两字段为bool。该输入同时含数值3.0；它作为 JSON Schema 数值 const3 的等价值并不单独列为缺陷，补充回归确认两个布尔正确时仍接受3.0，实际最多三次规则不变。

`boundary-originaloutput/external-quote-not-rechecked/` 保存不存在的构造CTX/引文但绑定外部检查器断言为true的接受结果。原程序确实只重核parse/ID/五维/schema；不重核原文引用。该接受属于候选已明示的外部信任边界，不能写为本统计代码重新核过引文。

`boundary-originaloutput/source-first-not-certified/` 的来源JSON保留一个外来构造assignedID和 `prior_model_labels` 构造元数据，重新完整绑定后原程序接受。源语义SHA只证明解析后对象绑定，不证明纯来源或来源身份正确。冻结协议要求的递归关闭来源适配器、原来源定位/CTX核对和前置资格检查不在本统计输入契约中实现。此例仅用构造元数据；未打开任何真实packet。没有获准定义新的正式来源schema，因此未用任意黑名单伪装修复这一资格缺口。
