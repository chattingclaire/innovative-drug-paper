本目录是现版验证的完整统计接续候选。它从已审的真实时序元数据、原始人工表、机器盲裁定和完整同版机器首答生成固定 ID 的统计输入，再运行原统计核心。真实登记仍为空，尚未取得的新抽样和人类结果没有补造；当前只有明确标为 NONHUMAN/TOY 的端到端控制完成了计算。

实际操作者只使用 `handoff.py`。旧 200 的独立 A/B 用途仍走原修复入口，本目录不修改其表格、原抽样权重或结果。这里的新总体固定为当前已冻结的 1261 条：旧 91 条按固定 ID 全取、权重 1；补充层用新设计 n/N 和 N/n，既可随机抽取，也可 n=N 全查。没有把旧 91 当作重新获得随机代表性的样本，也没有自行决定实际 n 或种子。

真实运行需要一次完整接收中的这些原件，由项目接收者组织请求文件，编码者继续交 Excel：

- 已冻结的新分层成员、实际 n/种子、唯一真实抽取记录；当前机器/域/C 固定以及旧判读和补充组各自真实的时序、盲法和反馈事实，采用已审 `reuse-admission` 的字段。
- A、B 原发放 200 表的首交 Excel及各自补充组首交 Excel。补充 Excel 绑定实际发放模板、盲号、材料和顺序，使用同一五维填写/理由规则。旧材料兼容链、真实身份、首交/锁定及实际使用材料回执均须已核实。
- 机器比较阶段所需的实际机器盲人类裁定原件。当前支持已有五维逐项状态 JSONL 格式的裁定原件；不能从 A/B 一致自动生成，也不能由 AI 代填。
- 当前完整 4481 两机冻结首答及来源身份。入口复核已经采用的完整原件/批次链，随后才按新样本 ID 取值，不重新选择首答，不把旧 01402 的 5 个历史失败当作当前失败。

唯一实际登记在本目录 `ROOT-registry.UNADOPTED.json`，外锚位于 `support.py`。未来采用时，将已审完整请求及实际收据写入这一登记、更新同一外锚并封存独审版本即可；不需要再给旧 `reuse-admission.admit_real` 或旧动态引擎登记，也不修改这些封存入口。新入口先核这份登记，复用已审 `validate_metadata/current_view` 的真实分组时序，再重读首交原件。纯 helper 的 `actual_ROOT_adoption=false` 保留原值，新入口的实际身份来自自己的外锚登记，不靠改布尔值获得。

调用方式为 `python3 handoff.py --request <已完整接收并登记的请求.json> --output-dir <本目录/runs/新目录>`。请求中的 `analysis_stage` 可以是 `human_first`、`machine_reference` 或 `combined`，对应原核心 5、40 或 45 项点目标。`human_first` 不读取机器标签、不要求伪造裁定；正式五方完整比较使用 `combined`。输出目录必须新建，原件或既有结果不能覆盖。实际登记为空或原件未审时，入口在打开人类或机器标签前拒绝。

合法 NULL、整条未返回、单维失败和未完成填写都保留在固定分配行中，空白不会变成 0。合法 NULL 仍需原规范中的明确理由；未完成与合法 NULL 分开。缺原件、身份/模板/材料漂移或不可信裁定会拒绝计算。保留未知行后产生的指标仍只描述明确可比较部分，数值达标不等于项目验收。

原 `frozen_year_core.py` 文件未改。新适配器只替换当前实例的 `_validate_metadata` 和 `review_eligibility` 两个资格函数，28 个其他函数对象及其 AST 保持原样；没有虚填 `before_answers`，没有改变数据角色绕过真实准入。45 项点目标、0.8、5000 次共享 W、RaoWu/FPC、状态表、稀少类别处理和区间算法保持原版。混合全查/随机与全补充全查两种合成设计的全部统计输出，除真实时序资格说明外，逐字段与原核心一致。未扩展年度统计。

最后一轮 `control-results.json` 有 20 项端到端检查全部通过，包括旧/新 Excel 原件、相对工作表路径、可信裁定格式、完整机器链、45 项实际计算、分阶段计算、NULL/失败/未返回，以及真实空登记、假时序、开发使用反馈、漏必取行、缺首件、原件替换和合成读取项目原件的拒绝。另有机器投影及动态 Excel 的有限检查记录。首次端到端脚本有一处 `else40` 拼写错误，在执行前即失败，修正记录保留；没有把该次运行说成成功。前几轮控制原件保留，最后一轮为最终代码验证依据。

独审可先使用交付的 seal SHA 运行 `verify_candidate.py` 作只读核验，再在副本运行 `test_handoff.py`；控制会在新的 controls/run-* 与 runs/control-* 目录生成明确非真人材料和结果。原 200 格式有固定 1000 个槽，所以 TOY Excel保留该格式；实际合成统计样本仅 12 或 16 个来源，不生成真实人类答案或新抽样。
