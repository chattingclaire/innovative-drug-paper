# 当前版本验证的最小衔接

最新设计判定：旧200是旧800内的二次抽样，后续开发又使用了同一800的分歧与共同阴性。因此，直接从旧200删去29条、沿用旧概率，不能自动得到对当前1261条剩余材料的正式独立验证。为保留已开始工作，已形成[补充设计候选](supplement-design-candidate.json)：把旧91条按固定名单全部纳入新设计，再从其余1170条独立分层随机抽取。原200、原41层及原权重继续完整保留；新设计中的91条是必取组、权重为1，补充组另有新概率。

| 部门 | 旧91条全部纳入 | 待随机补抽的总体数 |
|---|---:|---:|
| 卫健 | 10 | 84 |
| 医保 | 34 | 457 |
| 药监 | 47 | 629 |
| 合计 | 91 | 1170 |

这是针对**当前固定1261条剩余域**的新有限总体设计，不能由它直接宣称全4481或未来政策的准确率。按标准分层总量估计，必取组贡献其实际四格数量，其他层贡献按新概率加权的四格数量；κ/P/R/F1由这些总量计算。必取组没有抽样方差，但人工测量、待定或缺失仍需如实处理。这个应用是本次结合固定名单作出的设计推导，依据为[分层SRSWOR总量与方差公式](https://www150.statcan.gc.ca/n1/pub/12-001-x/2019002/article/00006/02-eng.htm)及[概率抽样、必取层和工作量原则](https://www150.statcan.gc.ca/n1/pub/12-539-x/steps-etapes/4058330-eng.htm)。

既有数学核心支持上述六层及全查层，但旧接入契约要求设计在答案形成前完成，不能直接为已开始的91条填写该声明。[如实时序接入组件](reuse-admission/README.md)现已完成并[通过独立复核](reuse-admission/final-independent-review.json)：44项接收控制和11项原数学检查独立复现通过。它支持如实记录原判读的开始区间，核查首判独立、机器答案未向编码者展示，以及人工测试反馈未进入机器开发或新设计决策。仅仅先开始填写不等于答案已被开发者使用，也不能据此虚构“尚未开工”。

在此基础上，[完整统计接续候选](statistics-handoff/README.md)已贯通原件读取、固定样本合并和原统计核心，并[通过独立复核](statistics-handoff/independent-review.json)。20项端到端、14项补充Excel及14项定向对应关系检查均独立复现通过；混合全查/随机与全查两种构造设计均产出45项既定指标，数学输出与原核心一致。它支持原200及补充组Excel，保留待定、失败和漏填，未生成虚假的“开始前冻结”声明。这仅确认程序候选已准备好；当前实际登记仍为空，真实原件接收、补充抽样及正式统计尚未完成。元数据齐备不表示人工填写完成，实际结果仍须结合既有覆盖、失败和共同可比较数量解释。

如果原200条先于新设计及抽样完成而交回，应先保存原件。不得用这些答案或一致性结果选择新设计分配，再追认“人工反馈未用于设计”；实际反馈、盲法和时序须如实记录。

当前尚未确定补充n、分配与随机种子，没有进行新抽样或开放正式统计。已询问原200之外可承担的额外工作量；样本量充分性仍需结合各维正负例、覆盖及区间审查，不把200视为必然够用，也不新增区间下限门槛。

1170条中，F或I有任一机器阳性标记的共有40条，其余1130条没有这两维的机器阳性标记。[设计复核](supplement-design-review.md)确认，可优先采用“40条全部纳入＋其余按部门随机补抽”的方案：40条为医保8条、药监32条；随机框为卫健84条、医保449条、药监597条。现有数学核心和接收组件支持这种分层，无需新增一套计算方法。这能覆盖已知稀少预测，但仍需抽取无阳性标记的材料以发现机器漏判；1130条中还含13条在F/I至少一机待定的材料。该建议尚未登记为实际设计，也不保证某个补样数量充分。

当前[元数据登记](adoption.json)已完成：开发曝光框独审确认1261条剩余、3220条曝光；原200中109条曝光、91条剩余。当前两机4481条的真实来源与文件绑定、稳定性800条的材料兼容均已核验。两位编码者可以继续使用原表；材料、手册及原抽样权重不变。
