# 01402 第六条材料比较：运行前语义判断

完整同版第六条更支持当前 I=1，依据是 I4 的实质改良资格与当前权利保护/许可限制直接相连。原期待 I=1 仅保留为已有控制期待，不作为语义权威；本判断先于本轮分类输出封存，不是独立人工核定。

第1、2款把对象限定为改良型药品，并规定首次境内上市许可起的4年数据保护。第3款把受保护数据限定为证明与已知活性成份药品/已上市生物制品相比有明显临床优势的新临床试验数据，同时排除生物利用度、生物等效性和疫苗免疫原性数据。第4款就是当前记录：在此保护期内，未经持有人同意依赖其受保护数据的仿制/类似药上市或补充申请不予许可；自行取得且未依赖该数据的申请除外。

因此当前不是普通报送、签章或仅有文件名，而是在同一实质改良对象和数据范围下实施保护权利。手册§二允许有限补全同一安排的对象与直接机制，§六I4允许具体创新/改良资格决定差异化准入或其他权利义务。当前只是限制许可，不证明药品已优越，也不等于 I3 研发服务；第3款的临床优势内容不能给当前记录自动增加 E。

反对读法在旧材料下有实质理由：仅见‘持有人/数据保护/同意’并不足以建立技术新颖性或实质改良，原邻段虽限定数据范围，却未提供完整第六条对象和时期。新增四款及下一条标题只补足同版有限关系，不能借另一条、新政策、整个数据保护制度或旧机器答案补足。完整限定与自行取得数据例外都必须保留；不能把仿制申请人直接认定创新主体、把例外推广为所有依赖申请均可许可，或把数据保护视为所有产品的市场禁入。

后续只固定同一 combined-v2 五模块，实际比较旧、新01402两份材料；若输出仍不足，另记未成立的消费依赖，不能据该判断即时改代码或标签。
