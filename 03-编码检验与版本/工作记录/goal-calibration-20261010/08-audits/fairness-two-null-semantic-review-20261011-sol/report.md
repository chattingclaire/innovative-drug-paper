# 两项 F=null 的有限语义边界核查

结论：已有共同手册支持把“所需产品在境内尚无通常上市取得选项，且按这一临床需要与缺口配置优先申请或直接纳入机会”操作化为 F。v7 将三类例示缺口作为穷尽式匹配条件，因而对此关系过窄。可在独立候选中修正这一分支，无须先扩大 F 的实质定义。此结论并非声称文字只容许一种读法；具体实施仍须保留同一对象、真实治疗需要、产品取得缺口与针对性机会的合取关系。

本报告只读核查，不执行分类器，不修改 v7、手册、真人参照或 LLM 生产输入。两项原 null 保留。已知原 A/B 参照并核对既有单元格，本次不是盲审或新的真人复核，也未把 κ 目标作为判断标准。

## 支持较宽读法的同版证据

共同手册 §7 的一般定义是“患者按治疗需要获得或持续接受所需药品治疗的合理机会与负担，以及可避免、不合理的获取差异或保障缺口的关注”（manual.txt 第147行）。第154行把“明确药物保障缺口”与按需要的补偿、优先保障或资源分配相连；第160行要求能辨认“所需药品保障缺口”；第170行要求保存目标治疗需要/缺口及以此为条件的优先、申请或支持资源机会。上述文字并未规定所有有效替代品必须不存在。

两项当前命题自身均把临床急需的罕见病所需药品、同一药品境外已上市而境内未上市、具体优先机会直接连接。00110 的完整当前命题为：

> 其中,对于列入国家药品监督管理局《临床急需境外新药名单》临床急需境外已上市境内未上市的罕见病药品,申请人可以在提出药品上市许可申请时按照适用范围“(六)国家药品监督管理局规定其他优先审评审批的情形”提出优先审评审批申请。

00118 的完整当前命题为：

> 对于列入国家药品监督管理局《临床急需境外新药名单》的临床急需境外已上市境内未上市的罕见病药品,药审中心受理后直接纳入优先审评审批程序,不再对外公示。

两项证据位置均为各自 packet 的 `/source_bundle/source_record/text`。同版原政策全文已完整包含在两 packet 中：五个连续全文块合计9612个字符，与冻结原文及归档原文逐字相同，SHA-256 为 `980acf76a2fb9b9537e89e6c223462549e984b39e6b1d9a54443e2dadce37036`。原文第175行分别对应优先申请，第180行对应直接纳入；第184行明确一般130日与此类药品70日审评时限。因而资源优先不是从一般“提速”概念补造。原政策中文标点与 packet 当前记录标点差异分别留存，没有冒称这两种字符串字节相同。

## 支持较窄读法的证据及其限度

手册第155行的例示使用无有效治疗选项、境内无获批对应治疗选项、现实供应不足；第170行也强调目标适应症选项，且三类缺口不能相互推定。第166行明确“急需、未上市或短缺词本身不足”。政策适用条件还容许相对现有治疗手段具有明显临床优势：同版原文第10行出现“或者与现有治疗手段相比”，第164行要求临床价值并参照突破性治疗的临床优势条件。因此“该药境内未上市”确实不能证明全部有效替代品或全部适应症获批选项均不存在。

这反驳的是普遍无替代选项的推断，不能单凭它否定已经直接表达的所需产品取得缺口与针对性机会关系。这里应把缺口命名为“该所需产品境内通常上市取得选项缺口”，并与“目标适应症全部获批选项缺口”“全球无有效治疗”“现实断供”分开。不得推断患者没有临床试验、特殊进口等其他路径；也不得推断上市已经完成、患者已经取得该药或公平结果已经实现。

v7 dimensions.py 第795—796行在当前有境外已上市/境内未上市及机会词、但三条 GAPS 正则未匹配时，一律进入“单品种未上市与按需优先机会”手册边界请求。这能保存争议，却没有检查上述同一所需产品、真实临床需要与具体机会的完整关系。

## 最小通用候选及反例

建议只替换争议分支：当前或合法直接父谓词同时表达真实临床急需目标、同一所需产品境外已上市而境内未上市、并以该条件实际提供优先申请或直接纳入机会时，才能新增该产品缺口的 F 正关系。部门名称、名单名称、记录 ID、既有真人答案和成绩均不得作为特征。余下情形保持旧边界或现有排除规则。

已在 counterexample-boundaries.json 固定六个构造边界，未执行分类器：

| 条件 | 预期 | 边界理由 |
|---|---:|---|
| 仅境外上市/境内未上市，普通审评 | 0 | 缺实际治疗需要与针对性优先机会 |
| 临床急需加优先，境内已上市且供应足 | 0 | 缺可指认产品取得缺口 |
| 临床急需、同产品未上市，但仅收件/通知/签章 | 0 | 缺实质资源机会 |
| 其他兄弟名单项具临床急需缺口，本项仅登记另一产品身份 | 0 | 不能跨兄弟对象倒灌关系 |
| 同一临床急需产品未上市，允许提出优先审评申请 | 1 | 三要素与针对性申请关系闭合 |
| 同一临床急需产品未上市，受理后直接纳入优先审评 | 1 | 直接纳入是实质机会，非单有受理 |

候选须实际通过这些关系反例及既有回归后才可供 ROOT 采用。若以后拟把任意未上市、一般罕见病身份或一般加快上市直接计入 F，那会越出这里的既有定义操作化，需要另行实质定义讨论。
