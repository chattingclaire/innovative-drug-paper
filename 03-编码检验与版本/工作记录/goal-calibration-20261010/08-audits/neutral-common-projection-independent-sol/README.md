# 中立共同材料投影：独立审查

**结论：材料投影及其全量路由机械检查通过，可作为 ROOT 另建未来共同材料候选 release 的依据。此目录不发布 release，不改变当前已跑版本、77/800 开发材料或原判断。**

实际核对了候选 builder 和四份 inventory 的精确 SHA，4481 个原 packet 的实际字节/规范 JSON 绑定、身份路由及完整覆盖，以及 17 份已有 UTF-8 原件的实际字节 SHA、长度和严格 UTF-8 往返。对全部记录在内存执行两次投影，并独立按原 literal 范围的补集复算：1227 条各新增一个缺失连续范围，142 条 TXT 原包已完整、不新增，3112 条没有 TXT 来源、不新增。283 条已有来源扩展元数据均保持不变，没有“已有扩展且又新增范围”的交集。所有新增范围的字符、字节、物理行、原件权限和 leaf SHA 均通过；未运行任何维度判断或预测。

投影选择仅使用原 packet 已绑定 `source_documents` 中的 TXT 原件、既有同 SHA literal 范围及其补集。源码完整静态阅读和 AST 核查未见目标答案、条款 ID、记录/盲号、药品名或文件标题白名单；source ID 仅路由，source SHA 仅对应原件/资源身份。原记录、原语境及既有资源逐字段不变，新增版本明记候选和未记录实际消费。

同一个 `project(bundle)` 没有人工/LLM/规则的角色分支；五个真实有限样例也通过冻结 source adapter 的形状/库存读回，新增库存仍为 `not_recorded`。因此同一候选内容可以共同交付。真正共同 release 仍须另建新的外层包、canonical SHA 与交付绑定，并为绝对 snapshot 路径提供同 SHA 的共同可解析映射；目前只有 source catalog 和 routes，不是三方已收取、已读取或已使用的证据，不能替换既有运行的 frozen 输入。

有限语义检查包含：

- A271 / RECODE25-04592：连续核读同版第59–62条（原件 L197–207），完整保存对象/条件、纳入、两项服务和终止。当前不再符合条件→撤回同一待遇，不能解释成所有条件失败；原包叶片数为0，未来补足消费不得倒记成旧包已消费。
- RECODE25-04587：同一突破性程序的第60条普通申请义务，不能因共享全文而继承后句纳入或其他条的全部阳性关系。
- RECODE25-04599：同章相邻附条件程序的证书载明事项，不能移借突破性第59–62条对象及服务；其自身解释须在第63–67条内另核。
- RECODE25-00044：已有5个连续 TXT 叶片完整覆盖，投影后整个原包不变。
- RECODE25-03478：PDF 原包不增加 TXT/OCR/页码，整个原包不变；未读该 PDF 正文或像素。

**实际消费者兼容限制：A271虽然新增全文可见且形成有界支持关系，仍保留一项 `cited_standard`“同版标准原文缺失”/`dependency_status=stopped` 请求。** 因此不能把本材料投影通过写成算法已经解除标准解析阻断或能完成正式判断。该未来消费问题已告知 ROOT/负责人；本次不改其封存版本、不接当前800、不复跑旧开发。材料可用性不能泛化为跨条款适用或阳性，也不保证所有旧关系路径已经支持新材料。
