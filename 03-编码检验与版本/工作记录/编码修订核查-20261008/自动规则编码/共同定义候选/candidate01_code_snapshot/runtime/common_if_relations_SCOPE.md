# I/F 纯文本关系检测器范围

本模块依据共用规则 SHA256 `6b902fd7518379d5edc8e100c1192b627202a0069e69d6e40fea72cad7880a28` 及静态迁移范围报告实现，不读取文件、标签、ID、部门、旧分数或模型输出。入口集成、材料完整性、必要语境认证和其他维度由根节点处理。本次未读取真实开发检查文本、工作参照或候选结果，也未运行全文或模型。

## 接口

```python
inspect_innovation(text: str, *, drug_scope: bool = False) -> list[dict]
inspect_fairness(text: str, *, drug_scope: bool = False) -> list[dict]
```

每个关系包含 `start`、`end`、`quote`、`kind`、`subtype`、`basis` 六个字段；偏移为原始 Python Unicode 字符索引，右端不含，严格满足 `text[start:end] == quote`。不做全半角、空白或文字规范化。`basis` 为中文共同判据说明字符串。输出按偏移排序，并按偏移、kind、subtype 去重；重叠的不同关系可以保留。

`text` 必须是已经确认的当前命题内容；`drug_scope=True` 只补足当前已核验的药品对象，不补创新属性、公平关系、患者支付能力或必要语境的标签。不允许把整个父段或全文作为当前内容传入。显式异对象优先于这个布尔范围。

## 已实现的有界语法

I 检测四类局部关系：药物新颖／原创属性陈述或实质评价要求；明确“改良”或“实质改进”的产品／治疗属性；创新／改良研发对象与实际指导、资源、通道或参与实施安排；创新对象、申请支持资格及比较条件的合取关系。普通剂型规格或适应症变化、药物专利期限、创新身份、一般安全义务没有独立赋 I 分支。否定、不确定或取消具体支持不被一般否定词一律排除。

F 检测患者支付能力／可负担性内容及证据要求、困难患者的药品负担措施、治疗需要与药品配置供给、明确保障缺口、地区人群条件造成的药物治疗获取障碍、明确不合理限制及药品保障公平目标或评价。普通自付比例、常规处方通道、目录身份、临床管理难度、咨询服务或一般人群名称没有独立赋 F 分支。

默认在逗号分句内识别，句号、分号和换行断开。只有目标—供给、工具—用途、需求评估—规则及条件—获取等明确连接语法允许有限相邻分句桥接，最多两个逗号。不会以全段有“创新”“公平”或药品对象而放行所有证据。书名号内部默认等长遮蔽；唯一指南特例须同时匹配具体创新指南供给及当前研发指导功能。保密、文件名、字体、格式等局部载体事项与显式软件、器械等对象有排除门。

## 子型与手册留痕的对应

以下是本模块的检测关系子型，不与 LLM 输出的同名或近名字段默认为同一变量：

| 模块 subtype | 手册留痕对应 | 解释限度 |
|---|---|---|
| `attribute` | 属性与创新价值 | 新颖／改良属性或实际注册类别；不等于已证优效 |
| `research_support` | 创新研发支持 | 明确对象与实际工具／安排；不等于产品已经创新认定 |
| `qualification_advantage` | 创新资格比较条件 | 当前创新对象的资格及比较关系，不递归扩展外部程序 |
| `needs_based_guarantee` | 保障覆盖与实际治疗获取中的按需安排 | 只记命中的当前按需关系 |
| `patient_affordability` | 患者可负担 | 不等于普通患者自付或基金承受能力 |
| `opportunity_barrier` | 保障机会／负担分配中的地区人群差异或障碍 | 不推定措施已消除差异 |
| `guarantee_equity` | 明确药品保障公平目标或评价 | 包括目标与评价要求，不能直接等同 LLM 的 `equity_evaluation` |

`guarantee_equity` 对应 `kind=equity_goal_or_evaluation`，保留了本模块有界语法尚未进一步区分“公平目标”与“评价要求”的事实。集成时应保存原始方法、kind 与 subtype；若另建统一留痕变量，需明确映射及陈述性质，不能把该子型无说明重命名为 `equity_evaluation`，也不能据它声称原文要求或完成公平评价。

临床管理难度、一般获取／自付内容的独立标记不在本接口输出中，须由主入口另外保留；它们不作为 F 正关系混入。

## 未覆盖与局限

这是有限正则关系识别，不等价于人工语义理解。空列表只表示没有命中已实现语法，不能证明当前内容在概念上为 0。复杂指代、长距离倒装、多层条件、隐含的人群需要或限制合理性、未明示新颖性来源的注册类别序号、知识产权与实际创新资格的复杂联系，以及跨段指南对象认证没有在此展开。裸“支持创新”宗旨与间接资源供给可能漏检；实际输入中的语法缺口应单独登记，不按指标修改概念。

作用范围由字符界限和有限连接语法近似；不是完整句法解析器。载体事项与实质评价在同一无标点长句内嵌套、多个并列异对象等复杂语法仍可能需要主入口人工式审查或留待检查，不能声称排除门已穷尽全部反例。根节点保留的已认证旧指南／科学指导关系应单独注明来源和认证条件，不能以本模块空列表撤掉那些已经成立的具体关系。
