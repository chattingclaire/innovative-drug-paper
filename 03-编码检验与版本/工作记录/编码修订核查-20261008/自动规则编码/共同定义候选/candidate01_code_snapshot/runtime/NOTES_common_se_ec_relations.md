# S / Ec 当前文本关系候选范围说明

实现文件：`common_se_ec_relations.py`。只读指定共用规则；未读旧规则、人工标签、模型输出、pilot23、真实语料、保护池或其他审阅者文件。实现与测试不依赖文档 ID、部门、文件名或语料词表。

接口：`inspect_safety(text, *, drug_scope=False)`、`inspect_economics(text, *, drug_scope=False)`，返回 `start/end/quote/kind/subtype/basis` 字典列表。`end` 为原始 Python Unicode 字符串的独占末端；`quote == text[start:end]`。`drug_scope` 只能补足已核验药品对象，不提供维度关系。`inspect_quality_content(text)` 仅留质量内容标记，不增加注意力维度。

书名号《》、〈〉内的文件标题在匹配时按等长空格屏蔽；输出仍切取原文。实质关系在逗号分句内判断；当前同句前置 80 字符内的药品对象可解释后续分句的对象。需要该对象才能成立时，证据引文扩展到本句。无跨句、标题、父条款或外部引文维度继承。

S 要求药物损害、药物安全评价或药物警戒/风险控制的当前实质谓词；否定或不确定陈述可纳入。单纯纯度、质量管理、“质量安全/风险”不赋 S；明确危及患者生命或不良反应等联系可赋 S，质量内容另留痕。

Ec 要求当前价格/治疗费用、实际支付责任/标准/范围、自付报销、基金预算或成本健康产出关系。定性价格要求可纳入，不要求数字。纯谈判成功失败、目录结果、支付标准作为流程对象、仅有资格申请支付范围/标准调整、栏目名不赋 Ec。一般行政服务费不赋 Ec。

本次只运行 `selftest_common_se_ec_relations.py` 中的 **14 组自构概念成对检查（28 句）**，同时检查所有输出的 Unicode 原文跨度、标题屏蔽等长和质量标记边界。该检查是实现单元检查，不是实际政策文本测试、验证样本、效度结果或准确率估计；没有执行全量运行。

确切限制：

- 有界词表与语序规则，不能穷尽临床损害、费用责任或同义改写；语义隐含、长距离倒装、跨逗号才完整的复杂关系可能漏检。
- 同句前置对象只做 80 字符有界解析，不能解析全部代词、列举、表格、父段、明确援引条款；所需对象缺失时只能等待集成层补足已核验对象，不能推定。
- 标题屏蔽仅覆盖书名号《》和〈〉形式；未加书名号的文档名称未自动识别。
- 栏目/模板/流程排除依赖近距离文字结构；同一分句混合流程说明和实质证据要求仍可能发生误收或漏收。
- 通用“医保/基金”名称本身不提供药品对象；无药物对象或已核验 `drug_scope` 时，孤立的支付/基金语句采取保守处理。
- 质量标记不是穷尽的质量本体，也不代表质量问题已经造成损害；只记录当前文字及其是否另有明确 S 关系。

本模块不决定旧路径的门控范围、样本选择或外部语境补全；这些由集成入口单独实现。
