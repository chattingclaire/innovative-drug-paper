# 候选09定向复核的方法范围意见（离线）

定向复核可以作为既有机器编码的开发修复，但触发器只能筛选“需要复核的机制风险”，不能证明命中行错、未命中行对。若仅复核一部分，其余保留完整LLM03初判，最终结果就是有明确选择规则和行级来源的选择性复核版本，不能称作全部单元在同次、同一09流程下完成的全量编码。

本意见不扫描4924、不读取预测或政策原文，不读取私有期待，不执行或监控09B。尚未收到scope_spec，所列是可供冻结方案选用的通用机制类别，不是已经实施或检验通过的触发规则。审查人编写了Stage A库存/验证器；本意见是方法范围复核，不是外部验证。

## 最多六类可预声明的机制风险

| 类别 | 可机械观察的候选触发 | 必须保留的限制 |
|---|---|---|
| 1. 当前引导与给定清单、表列 | 当前文字含列举/引导表达，且给定contexts存在清单或表列文本；另覆盖有此结构但引导词未命中的近似情形。 | 字段名、冒号及相邻关系不证明实质承接；自足句与必须补足的宾语/条件要由判读区分。不能把清单中的全部维度复制下来。 |
| 2. 明确内容援引与资格/证据条件 | 当前文字含具体条、款、项或标准的援引，并有给定的相应条文材料；条号缺料也须单列，不能静默排除。 | 必须区分当前要求满足实质条件与仅记录已有身份/办理记录；细址不能借整条其余条件补齐，未引用条款不传播。 |
| 3. 父子条件与当前结果 | 给定父条件或当前文字包含条件—结果结构，尤其涉及保障延续、纳入退出、供应或获取安排。 | 触发不等于F=1；一般申请、转类、重谈机会不能补成实际保障。真实控制结果不能因当前子项短而丢失；其他并列条件也不能全传入。 |
| 4. 产品相对变化、注册类别或专有权利 | 当前文字出现相对既有产品的变化表达、具体产品属性、明确类别信息或专有保护内容。 | 不要求已证明优效；新申报、新上市、普通规格或具体包装设计本身也不充分。类别须有实际含义，权利须与一般保密/报送区别。 |
| 5. 创新研发的实质支持与程序安排 | 当前文字/给定关系同时涉及药物研发创新及资源、支持、资格、指导或流程安排。 | 当前是否规定实质支持由内容决定；位于支持程序中不够，既往获支持的身份资料不等于当前提供研发支持。 |
| 6. 定义、自足句、标题背景与未来文件规划 | 当前为定义、发布/制定、未来文件安排等形式，且给定背景或邻接清单含潜在实质内容。 | 定义句不一律为0；标题、主题、文件名和将来另发文件不自动变成当前要求。不能仅因contexts存在标题便让几乎全部单元入围。 |

每类须先固定可执行字段、匹配规则、缺失值处理及规则版本，再扫描统一全框并报告重叠/并集/未命中规模。上述是召回机制，正反教学对及范围外抽检仍需发现同义表达、错列和结构变体。机械词表不可冒充完整语义规则；不按真实ID设标签，不依据目标κ选择入围或正确答案。

既有LLM03标签可以用于分层、变化统计和回归检查，但不应成为“只有旧I/F=1才入围”的必要条件，否则系统排除了待发现的漏标。旧标签、A/B、期待和门禁意见不进入09模型packet；输入材料与Stage A原记录保持完整并可回查。

## 范围外抽检与回归的最低条件

在看09输出前固定未命中单元的抽样规则、种子及纳入概率。最小覆盖部门、与触发结构接近但未命中的情形、旧I/F的0与1、不同文件；不只抽容易的全0行，也不只看机器之间的分歧。抽样不能证明未抽部分无错，若要估计范围外错误率须按相应抽样设计计算，不把额外定向案例不加权并入总体表现。

每次复核都完整输出五维及来源字段。对入围行检查S/E/Ec是否被I/F修订连带删除或误增，检查子类、质量依据、逐字证据和材料状态；对合成正反控制检查应变的命题关系与应保持不变的无关背景。材料问题先保留原始A记录并阻断B，不能手修A后把它当原次输出继续。

如果未命中抽检发现同机制的明确遗漏，或已选行出现新增实质错误，先记录原冻结方案和失败事实，再按通用机制另存范围修订；不能把触发器称作已经穷尽，也不能只凭κ好转停止检查。已暴露的开发案例、已用于选触发规则的180以及已知语境不成为新的独立测试。未来要声称泛化表现，须另有未用于修订的评估材料；本意见不授权接触任何保留材料。

## 初判与行级来源

完整LLM03初判、原输入及其版本不可覆盖。每行至少保留原始ID、原输入/语境哈希、03初判哈希、触发规则及版本、是否入围、A原记录及SHA、B原输出及SHA、实际尝试和采用状态/理由；未复核行明确写仍采用03。原始输出不因理由或证据不理想而后处理改写，确认错误须作为另版修订记录。

最终可报告“完整LLM03基础上按预声明机制进行选择性复核”的组合结果，并重算其完整分母、子类敏感性和各部门分布；不能写成“完整09统一全量执行”，不能仅用入围行准确率代表整个语料，也不能把改良的开发集κ当独立验证或保证全部κ达到0.80。改变方法可能改变部门注意力占比，分类表现较高也不自行证明该占比无偏。

## 方法依据与适用边界

- Halterman与Keith（2026，正式发表于Political Analysis，DOI [10.1017/pan.2025.10017](https://doi.org/10.1017/pan.2025.10017)）：§4.1（p.191）区分训练/开发/测试；§8（pp.198–200）讨论行为测试、代码本消融和人工错误分析。支持针对已知机制做有限可检验诊断；不证明六类触发完整，也不规定必须进行本意见的具体抽样或保证κ。
- Ribeiro等（2020，正式ACL论文，pp.4902–4912，DOI [10.18653/v1/2020.acl-main.442](https://aclanthology.org/2020.acl-main.442/)）：§2.2（p.4904）区分最小功能、保持不变和方向性测试。只有命题/证据关系真正保持时才要求不变；改变真实控制关系可合理改变输出。这些测试检查所测行为，不能替代外部准确率或分布无偏性验证。
