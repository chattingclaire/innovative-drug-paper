# 五维共用编码规则

本稿将多源概念依据转为人工、自动规则和LLM共同使用的判据，按首轮真实原文检查所发现的歧义进一步澄清。当前处于规则修订及适用性检查阶段，尚未替换已采用手册、人工审定参照、机器结果或正文统计。编码对象是政策对评价内容的关注，不是药品已经达到的价值水平。

## 分析单位与共同规则

以已核验的完整政策句段为单位。五维分别记为安全性S、有效性E、经济性Ec、创新性I、公平性F，同维至多计一次，可跨维同时为1，也可全为0。共同定义由多源文献与三部门原始文本界定，部门身份及栏目位置不直接决定标签。

每个1应有当前句段的原文依据；必要语境只用于解释对象、指代、适用条件或被明确援引的实质要求，不将标题或父段的全部维度复制给子项。要求评价、比较或补充相应证据，以及否定、不确定的判断，均可能构成对该维度的关注。仅文件名、专家身份、公开格式或政策对象名称不足以赋值。

材料完整而没有符合判据的证据时填0，不因猜测政策可能有某种效果而填1。缺字、错列、缺失关键指代等实质材料问题另行登记并先修复，不把无法判读强记为0。规则适用分歧与材料缺陷分别记录。

## 必要语境与外部引用的范围

当前分析单位为待编码的完整句段。必要语境用于补全该单位已表达的对象、指代、比较基准、适用条件或明确要求，不把理解全文所需的所有事实都作为该句新增的关注内容。

1. **对象与背景。** 标题、药品名称、程序身份及一般适用法律可以解释对象和地位，不能把其全部评价标准传入当前单位。父句援引上位法，不使每个子项都自动关注该法中的安全、有效、价格等要求。
2. **明确指代。** 当前使用“应包括下列”“同时满足以下条件”“上述安全要求”等关系时，补全被具体指向的内容，并保留当前关系锚点及实际用于标签的语境引文。自足定义之后另列项目，与当前没有该关系时，不复制相邻维度。
3. **当前实质要求。** 当前直接要求药品符合某条、某款的实质条件时，须提供并核验确指的原文范围；仅“详见工作方案”“按有关规定”或程序名称属于一般指引，不能由此逐层展开全部政策并传播标签。没有数字不影响定性要求被编码。
4. **条件中的程序状态。** “不符合纳入常规目录管理的条件”等未具体展开的程序资格表述，保留其原有否定或限定范围，不据状态名称推定全部资格标准的维度。若当前实质讨论的是某一具体被排除要求，则按实际内容判断，否定本身不是排除该维度的理由。
5. **材料问题。** 需要解析的明确指代、具体条款或比较对象实际缺失时，先标记必要语境不足并补全；一般指引未展开与必要材料缺失分开记录。不得把未知内容强记为0，也不作无限递归的全文件标签继承。

上述为本文匹配注意力分析单位的操作安排，不冒称方法文献提供了这些逐句规则。跨方法使用相同范围，并在每个依赖语境的1中保存可核查的具体关系。

## 安全性 S

**共同概念：** 药物或用药带来的损害、风险及其识别、评价、预防与控制。依据卫健委2021第二章三（一）、医保2026安全性栏目和HTA安全域；质量部分另参照注册管理办法第1、3、10条的分层。

**纳入：** 不良反应、毒性、禁忌、误用、药物相互作用、药物警戒及相关风险控制；明确要求提供这些安全证据。质量问题明确涉及药物损害、使用安全风险或相应风险控制时赋S，并将质量相关依据单独留痕。

**排除：** 数据或网络安全、基金安全、一般生产安全；单纯工艺、纯度、稳定性、质量可控而无明确安全风险内容。未与药物损害或使用安全相连的质量风险另留内容标记，不仅凭“质量安全”或“质量风险”词语赋S。不能从监管机关身份自动推定所有质量条文均属安全。

**边界说明：** 卫健原安全栏目包括药品质量和疗效稳定性，药监则将安全、有效、质量可控并列。本稿采用较明确的安全风险口径，不将其称为三部门逐字相同的定义。S的赋值依据区分仅质量安全、含质量及其他安全、无质量安全依据；S=0但涉及质量内容且未建立安全联系时，另记“质量内容但未建立安全联系”，不能记成仅质量安全依据。上述留痕用于检验边界变化，不增加注意力维度。

## 有效性 E

**共同概念：** 药物防治效果、健康收益、临床获益及支持这些判断的证据。依据卫健委2021第二章三（二）、医保2026有效性栏目及HTA有效域。

**纳入：** 疗效、疾病控制、生存、健康相关生活质量、治疗优势、相应指南推荐；明确的药效研究、效果比较或补充疗效证据要求。效果不足、不确定或未被证实仍可编码为1。

**排除：** 行政有效期、行政效率、文件或数据格式有效；仅说开展试验、收集数据或说明作用机制，未与药物效果判断相连。

**留痕：** 记录关注对象及陈述性质，如证据要求、效果陈述、不确定或否定。不得把E=1解释为药物已经有效。

## 经济性 Ec

**共同概念：** 药品治疗与支付的资源投入、费用、经济影响，以及成本和健康产出的关系。依据卫健委2021第二章三（三）、医保2026经济性栏目及HTA经济域。本文的政策资源关注范围比单独的成本效果分析宽。

**纳入：** 药品价格、药费、治疗成本、支付责任或标准、报销与自付、销售金额和相关用量、基金预算影响、成本效果或成本效用评价。

**排除：** 未涉及药品治疗或支付资源的一般行政收费、科研项目经费、设备采购；只有谈判流程、专业身份或栏目名称而没有实质经济内容。

**流程边界：** 仅列价格谈判或协商阶段、协商成功/失败与目录纳入/适应症表述结果，仍属于流程，不能据目录结果补出具体支付义务。出现定性的价格水平、比较、合理性或调价要求，费用承担、医保支付范围/标准、药费支出或预算资源约束时，可有独立Ec依据；不要求一定有价格金额。普通医保目录申报资格本身不等同实质经济内容。

**留痕：** 区分价格费用、支付责任、预算资源、成本与健康产出关系。基金可负担与患者可负担分开，不将药价或预算信息直接解释为经济效率。

## 创新性 I

**共同概念：** 政策对药物技术新颖性、实质改良、创新价值及明确创新研发支持的关注。依据化学药、治疗用生物制品、中药各自注册分类，卫健委创新性定义、医保创新栏目及Kesselheim等关于创新测量的研究。不同类别药品不能套用同一注册新颖性条件。

**纳入路径：**

1. 明确讨论原创性、新颖技术、机制或靶点的新颖性、实际创新或改良型注册分类，或要求评价这些属性。知识产权内容须明确关联所保护药物技术的新颖性、实质改良或实际创新资格；仅属于药物技术的权利内容不足以赋I，不能从存在专利、权利或保护期限本身推定创新。
2. 明确讨论产品或治疗属性的实质改良。文本或已核验条件须说明改良或创新联系，不能由编码员把普通变化推定成改良；不要求句中已证明优效。
3. 当前条款实质规定面向创新研发的资源、指导、便利或支持资格。包括监管者或其他政策主体专门向已明确的创新/改良研发提供技术指导或沟通支持；需同时有特定创新研发对象和实际供给、安排或支持行为。指导可以针对安全风险，不要求其内容只谈新颖性。文件标题可用于识别被提供指南的对象，但标题或创新身份单独出现不能赋I。指南内要求申请人更新安全报告、实施药物警戒等一般安全义务不因此成为创新支持。该路径是本文对创新政策注意力的操作化，不是产品创新的官方判定条件，也不能解释为药品已取得创新认定。
4. 当前内容实质讨论已明确的创新或改良资格及其比较条件。仅程序名称、资格身份或一般临床价值不够；跨程序援引不自动传递原程序全部资格范围。

**排除：** 仅新获批、新上市、新申报；仅“创新药”作为支付或管理对象；单纯剂型、规格、适应症、功能主治或工艺变化而无上述联系；一般管理创新；创新项目内的一般安全义务或事务报送。

**修订重点：** 撤回“相对既有产品的具体属性变化”本身即为独立充分条件的规则。具体变化可以是创新或改良的材料，但还须由原文、实际注册类别或必要语境建立其创新联系。既往编码不回填更改。

**留痕：** 属性与创新价值、创新研发支持、创新资格比较条件分别记录。临床增量价值另看比较人群和替代治疗，不与技术新颖性或研发支持互相替代。

## 公平性 F

**共同概念建议：** 政策对有治疗需要者获得药品的保障机会、费用负担及相关不合理障碍或差异的关注。依据WHO公平定义，结合Levesque等对可及性及可负担性的区分；医保栏目和卫健可及性内容提供中国药品保障语境。此为本文的操作定义，不把可及性与公平性称为同义词。

**纳入条件：** 除药品获取或费用内容外，当前内容或必要语境还须有可指认的公平联系：按治疗需要保障、患者支付能力造成获取障碍、人群或地区保障差异、不合理限制，或针对这些问题的评价要求。例如弥补明确的用药保障缺口，减少同等治疗需要者因收入、地区或保障身份产生的获取障碍，讨论患者负担与支付能力、治疗需要的关系。“有治疗需要”不能作为所有药品政策天然具备的背景而省略上述判据。不要求政策已经消除差异，也不要求每句出现“公平”二字。

**患者可负担性术语：** 当前明确要求评价或改善患者能否负担药品，或使用“患者可负担性”等直接表达，按费用与患者支付能力的关系理解，可纳入F；不另要求同句重复“收入”或已证实支付障碍。该纳入将金融获取障碍视为本文公平关注的组成部分，是研究操作化，不将Levesque等的可及性框架称为公平性定义。基金可负担、普通药价、患者费用责任或某个自付比例本身不等于患者可负担性。混合栏目名称也不能代替当前实质评价要求。

**排除：** 只有人群名称；一般资料来源或数据共享；普通行政管理、物流信息；仅价格、基金总支出、普通保障覆盖清单或患者费用责任而没有上述公平联系；只有给药便利、储存条件、监测复杂性或临床管理难度而未与按需保障、支付能力或机会差异相连。一般获取或自付内容可另留内容标记，不直接等同F。

**栏目要求：** 仅凭材料被列入医保“公平性”栏目，不将其中所有价格、管理和程序内容自动赋F。明确要求评价用药保障公平及其证据可纳入；只提混合栏目名称而没有可核验的概念范围时，保留栏目提及记录，不推定其具体保障或分配内容。相应的价格或安全内容仍按独立证据判断Ec或S。

**留痕：** 保障覆盖与实际治疗获取、患者可负担、保障机会或负担分配分别记录。临床管理难度作为原文内容标记保留，但不再独立构成F的充分条件。若全文实际主要测量一般可及而非上述公平构念，一级名称应依据内容改为可及性，不能用当前定义掩盖命名不符。

本稿仍需补充NHC真实条文、F明确纳入内容及S质量边界的适用性检查；首轮意见一致不替代这些检查。

## 教学边界例句

下列均为共用规则的构造例句，不是政策引文、真实样本或独立验证结果。表中说明目标边界，不构成全部五维的预置标准答案；实际编码仍须逐维审阅。其作用是使判据可讨论，不计入总体准确率或κ。

| 构造例句 | 判定依据 |
|---|---|
| 补充长期随访中的严重不良反应数据。 | S；讨论安全证据，不代表已有安全结论。 |
| 说明该批次纯度检验方法。 | 仅此句不足以赋S；不能猜测患者损害。 |
| 尚不能确定该药能否延长生存。 | E；不确定结论仍讨论治疗效果。 |
| 申请文件有效期为两年。 | 不属于E。 |
| 比较治疗费用和质量调整生命年，并估计基金预算影响。 | E与Ec；分别讨论健康收益、成本效果及预算内容。 |
| 降低申报系统服务费。 | 不因费用二字赋Ec。 |
| 支持新靶点药物的原创研发并提供技术指导。 | I；同时有创新内容与实质研发支持。 |
| 申请变更药品适应症。 | 仅此句不足以赋I；须看实际创新或改良联系。 |
| 降低低收入患者使用该药的自付负担。 | Ec与F；费用及支付能力各有依据。 |
| 评估该药在医保基金中的总支出。 | Ec；仅此句不直接推出F。 |
| 对同等治疗需要的患者，不因所在机构缺药而限制用药，建立外配处方取药保障。 | F；明确联系同等需要与机构条件造成的机会障碍。 |
| 统一数据接口与信息上传格式。 | 仅此句不足以赋F。 |
| 该药需要专业人员实施高频监测。 | 不仅凭管理复杂度赋F；若明确涉及毒性风险另判S。 |
| 基层缺乏必要监测条件使当地患者难以获得该药治疗，应建立转诊保障以减少地区机会差异。 | F；实施条件已与地区间治疗机会差异相连。 |
| 研发改良剂型以改善现有给药方式，临床优势尚待验证。 | I；明确改良关注，不要求已证优效。 |
| 该药通过抑制某受体发挥作用。 | 仅一般机制，不据此赋I。 |
| 该药由患者按30%的比例自付。 | Ec；未说明支付能力、负担障碍或公平联系，不仅凭自付安排赋F。 |

## 实施与引用

框架构建参考Hsieh和Shannon（2005）的定向内容分析；分类矩阵可参照Elo和Kyngäs（2008）。这些文献不规定本文五维，也不证明机器实现有效。概念来源及精确节页见同目录多源依据表、方法依据说明和药监分类补充核查。

先独立审阅本稿概念与边界，再在未将答案提供给方法编写者的材料上检查可执行性。原A/B真人审定结果保存；实质变化影响的判定另存复核。新规则与旧参照不直接混算为同口径的新效度结果。边界审阅发现的问题已处理、共用判据及留痕字段冻结后，将完全相同的共用定义交给人工、自动规则和LLM，并确定受影响范围及未触及部分的检查方案。
