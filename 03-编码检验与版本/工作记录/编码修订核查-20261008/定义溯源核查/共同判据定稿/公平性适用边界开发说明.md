# 公平性适用边界开发说明

本说明用于解释固定共用手册的按需药物治疗获取边界，不覆盖该手册、既有A/C标签或原AI工作意见。以下是来源支持的研究工作判断，须在修订材料以外检验；不是新增真人裁定或效度结果。

共同判断顺序：先识别具体药品治疗获取或负担内容，再识别原文已经表达的需要、获取障碍、群体差异或保障关系。普通临床需求、一般可及性目标、疗效、研究代表性、程序名称均不能单独赋F。障碍的陈述、条件性或否定性评价也可能是关注，无须同时提出干预或证明政策已经有效。

| 边界材料 | 工作判断 | 依据及与邻近内容的区别 |
|---|---|---|
| 疾病进展/复发后，使对照组患者交叉接受已显示生存获益的试验药治疗（00292） | 倾向F=1，保留两份工作意见的原分歧 | 当前有具体治疗需要事件、原对照组与实际接受药物治疗的机会安排。依据是该段后部的需要与治疗机会关系，不是前部上市提速、替代终点或“更有效”一词。普通随机分组、一般受试者权益或代表性本身不归入F。 |
| 提前终止已达优效结果的试验，使药物更早上市、满足一般有效药物可及性需求（00306） | 倾向F=0 | 当前仅有一般上市速度与可及性目标，尚未表达特定需要保障、患者实际获取障碍或机会差异。关注内容可留痕，不能把可及性一概称为公平性。 |
| 长疗程、高费用的谈判药品与专门药品保障安排相连（04886） | 倾向F=1，保留既有边界意见 | 当前对特定长期高费用治疗设置额外保障，属于按需要区分的保障安排；费用另有Ec依据。不能仅凭高价格推定患者无力支付，也不能把普通基金总额、支付比例、目录名称一律编码为F。官方对应支付章节的解读明确指向患者待遇与负担，支持此解释；不将整份解读的目的传播给所有条文。 |
| 药品临床必需、安全有效、价格合理作为医保目录申报的一般条件（00919） | 倾向F=0 | 原文明确援引实质条件，不是虚构引用；但普通临床必需资格不自带获取缺口、按需额外保障或机会差异。不能把所有药品均有治疗需要作为隐含F依据。具体S/E/Ec按被确指条件独立判断。 |
| 数据缺失限制特定人群实际药物治疗，或经济社会条件影响持续治疗（00246、00256、03424） | 倾向F=1 | 原文将具体人群/社会条件与实际治疗获取或持续性相连，具有实质障碍关系。无需再要求措施已经安排；研究代表性或群体名称单独出现则不足。 |

00292的解释属于本文的按需治疗机会操作化，并非宣称世界医学协会已经给该段定义F或将所有试验交叉设计定义为公平。《赫尔辛基宣言》2024年第34段要求为仍需试验中已认定有益且合理安全干预的参加者安排试验后获取；它支持区分实际有需要者取得干预与普通参试身份。该条讨论试验后安排，不直接规定本样本的试验内交叉设计，也不宣称2021年中国文件采用了2024年宣言。

04886对应《双通道指导意见》第四部分，当前长疗程高费用对象与专门保障关系可从正文判断；国家医保局同期解读第五部分说明相应支付政策旨在保障患者合理待遇，第二部分说明合理支付与减轻患者负担。解读只用于核实条文含义，不作为机器私有新增语境。如机器确需使用新增解读原文，必须按完整中性来源同步给人工、规则与LLM，不能只给一个方法。

以上判断应先用于澄清通用边界和检查实现，不按目标κ选择。仍存在的真实专家适用分歧要保留；依据是来源和研究构念，不是哪一方预测更接近目标。
