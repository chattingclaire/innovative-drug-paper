# 实现修复独立构造控制

本目录含 10 条依据当前《共用编码手册》设计的合成机制控制，手册 SHA-256 为 `24007a19a7242dc9e906c9704e8c0cc4e0fa513990a18b6651d06ba05043f3f9`。它们不是真实政策样本，不替代人工参照，也不是人类效度、信度或发表合格检验。

`input.unit_text` 是当前句段；`paragraph_context`、`nearest_preceding_heading`、`immediately_preceding_paragraph` 和 `verified_parent_context` 给出完整的必要语境边界。`context_usage` 说明语境可以补足的关系，不允许由标题、文件背景或相邻句直接继承标签。

控制覆盖：

- 创新价值量化/分级的I正例，及空泛标题宗旨和背景创新的反例；
- 无数字时限的实际创新药审评试点/便利的I正例，及创新范围内一般试验义务和价格审核提速的反例；
- 普通临床基本供药和日常“按需配送”的F反例，及明确药品缺口与持续治疗需要、针对性调配相连的F正例；
- 创新研发支持撤回的I议题正例；人工解释应识别为 `withdrawn_not_currently_provided`，输出理由不得解释为仍在提供。

控制09的 `expected_interpretation.support_status` 是人工检查该条输出含义的说明，不是要求规则新增同名字段或极性分类器。规则可保持 `polarity=not_classified`；检查点只是I议题标签正确、完整引文保留“停止/不再”，且理由不声称当前仍在提供支持。

本次未读取或运行修复 agent 的新 patch，未修改真实输入、手册、既有标签或任何机器输出。

## 完整入口准备

`fixtures/合成机制控制-非政府文件.txt` 和同名 candidate JSON 是本地合成来源，源文首行、candidate `status/qa/notes` 均明确标注“非政府文件”及“非人工效度”。`build_fixture_input.py` 将它们生成与真实入口同形的 `完整入口输入10.jsonl`，绑定实际绝对路径、源文SHA、candidate SHA、unit candidate、paragraph context、标题和紧邻前段。编码器输入不含 `expected_labels`，`verified_parent_context` 为空；控制09的“该计划”只由合成TXT/candidate中的完整紧邻段落呈现，不伪造认证政策引用。

`run_actual_controls_once.py` 是一次性完整 `policy_coding_v27.code_unit(..., source_adapter=True, substantive_rules=True)` 入口。它必须同时收到 root 提供的最终 runtime 绝对路径、runtime tree SHA 和版本号；运行前冻结全部 runtime 文件、手册和合成材料，且拒绝覆盖。所有编码调用完成后才读取预期判断进行机制比较。控制09仅检查I标签、完整引文保留“停止/不再”及解释未声称当前仍提供支持；不要求新增 `support_status` 或方向分类器。当前只完成准备，尚未调用编码器。
