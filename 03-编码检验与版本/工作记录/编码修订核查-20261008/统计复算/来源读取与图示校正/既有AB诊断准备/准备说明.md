# 来源读取与图示校正后既有 A/B 诊断准备

本目录直接读取 `build_current_bundle.py` 生成的 `当前同材料结果/同材料结果绑定.json`。不再要求创建另一套来源 manifest，也不把规则侧 context 字典和 LLM 侧纯来源 context 列表强行规范成同一种序列化。

本脚本已对 SHA-256 为 `b001d8df5a304604f0ebe33865369768c7ed92dd1ba576378816810ca20bb9f7` 的最终 bundle 先执行 `validate`，通过后执行一次统计，生成175条诊断记录（机器对参照140条，A-B对称35条）。此前首次175条统计记录及其脚本、输出均未修改。

## 实际 bundle 绑定

脚本要求调用方提供实际 bundle manifest 的绝对路径与 SHA，以及既有 A/C 采用绑定的绝对路径与 SHA：

```text
python3 diagnose_final_methods_against_existing_AB.py \
  --bundle-manifest /absolute/path/当前同材料结果/同材料结果绑定.json \
  --bundle-sha256 <实际SHA> \
  --legacy-bindings /absolute/path/actual_bindings01.json \
  --legacy-bindings-sha256 <实际SHA> \
  --mode validate
```

本次已按上述顺序完成 `validate` 与 `execute`。脚本默认拒绝覆盖本目录中的既有最终结果。

bundle 必须保留完整4481目标框，其中 `RECODE25-00064` 作为已知来源未知单位留在框内；规则与 LLM 的实际执行域为4480。脚本实际核对框与执行域之差等于 bundle 的 `known_source_unknown_ids`，并要求旧240样本全部位于当前执行域。它不会删除00064或把未知补成0。

## 同材料的可证实范围

对4480个执行单位，脚本逐条核对：

- 目标框 `unit_text`、规则输入 `input.unit_text`、LLM输入 `text` 完全相等；
- 目标框文本 SHA 与规则输出 `unit_text_sha256` 相等；
- 规则 context 字典的规范哈希等于目标框 `rule_shared_context_sha256`；
- LLM纯来源 context 列表的规范哈希等于目标框 `model_contexts_sha256`；
- 两种 context 表示是否具有相同序列化只作计数，不作为同材料门槛，也不宣称相等；
- LLM合并输出逐条受 `LLM逐条执行来源.jsonl` 绑定，4479条来自原完整实际运行，03875来自固定来源校正ID的单条实际运行；选择不使用标签或性能；
- 原完整run QA、新补1run摘要、规则基线全量执行摘要、规则34条实际补跑报告与冻结记录、bundle 全部文件SHA均闭合。

规则结果的执行血缘是两段式的：NF2基线全量4480条实际运行，再对全语料编号边界静态扫描固定的保守34条做实际补跑。诊断脚本要求34条的最终行与补跑原始JSONL行字节相同，其余4446条与基线全量输出行字节相同；同时逐条核对 `规则逐条执行来源.jsonl` 的行SHA、实际输出SHA和选取根据。34条中只允许实际报告记录的 `RECODE25-01446` 五维标签变化；该组合不被表述为单次全量执行。

03875 另核对来源校正记录、目标框 `source_revision`、规则/LLM当前文本、独立AI视觉校核、校正后视觉认证、物理页图像及实际PDF SHA。这里认证的是图示节点和连线转写，不声称流程图是连续PDF文本。

来源变化 ID 与旧240样本的交集、00064与旧240样本的交集都在运行时实际计算，不能依据预先口头判断跳过。

## 指标约束

- 概率180和挑战60分开，总体及部门分别计算；概率总体沿用旧设计权重，挑战样本只作条件性诊断。
- 规则、LLM 分别对既有 A 和 B 输出 κ、Precision、Recall、F1、原始及加权四格和旧设计5000次区间。
- A–B 输出 κ及其旧设计5000次区间、一致率、双方阳性比例，并保留原始及加权四格供数学复核；不输出 Precision、Recall 或 F1，不指定 B 或 A 为 gold。
- 预计共175条记录：机器对参照140条，A–B对称诊断35条。
- `unknown` 按维度、比较和分析格逐对排除，绝不填0；零分母为 JSON `null`、CSV `NA`。
- 只读取既有绑定中的 A、C（显示为B）、抽样设计和旧数学核，不读取旧机器输出，不调用数学核 `load_context`。

结果解释固定为共同手册和来源图示校正后的机器编码对既有参照的诊断。它不是当前手册下的新独立真人验证、信效度定论或发表合格证明。
