# 两方法比较脚本准备说明

本目录仅准备比较程序，未读取正在生成的LLM预测或其执行摘要，未执行真实全量比较，未调用编码器或模型。`脚本准备核查.json`记录30项静态及人工构造的元数据、数学检查；这不验证真实运行完整性或语义效度。

全量完成并由根agent决定执行后，入口为：

```sh
'/LOCAL_HOME/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3' '/PROJECT_ROOT/outputs/编码修订核查-20261008/统计复算/测量与语义统一全量/两方法比较/compare_full_methods.py'
```

默认只接受`LLM编码/测量与语义统一/full4480/`同一运行内的`execution_summary.json`与`all_predictions.jsonl`。可在实际冻结后追加`--expected-llm-summary-sha256`及`--expected-llm-output-sha256`；其余源文件SHA已写入脚本。输出默认另存本目录下尚不存在的`actual01/`，拒绝覆盖。

摘要缺失、状态非完整、4480/批次数不符、SHA不符、工具事件或按标签/指标选择记录均拒绝统计。完成门槛先于打开预测；之后核验固定新手册、prompt/schema/validator/runner、冻结与原输入、整批切片、逐次请求、选择记录及实际原输出的哈希链。最终聚合须逐行等于该单一运行选中批次，拒绝旧批次拼接。复用冻结的结构/字面引文验证器，不重新编码。现有执行审计字段与哈希链的核验不等于独立重建服务端模型身份或语义正确性。

规则结果、规则纯来源输入、4481目标框和既有描述统计函数均绑定已核SHA。两方法4480个ID须完全一致，当前文字及文字SHA须与目标框一致；部门数固定1848/2100/533。00064保持五维未知；规则21条部分未知保留可判定单元格，未知不得补0。LLM整数标签的“可判定”仅指输出类型，不另认证这些来源已充分。

各部门及总体分别报告各维句次、可判定覆盖、未知数、条件占比及未知上下界。单位内同维计一次、可跨维多次；q分母为五维阳性句次之和。每方法自身五维完整单位集的q单列，并以双方全部五维均可判定的同一单位集作主要q对比，给差百分点和并列排序；每维最大共同可判定集另给二元四格、κ和一致率。κ在无配对或期望一致率为1时为未定义，双方不作为gold，不计算P/R。

未知界沿用已核函数：`p_d∈[a_d/N,(a_d+u_d)/N]`；`q_d∈[a_d/(A+Σ其他维u),(a_d+u_d)/(A+u_d)]`。q差界为LLM下界减规则上界至LLM上界减规则下界；是逻辑补全界，不是置信区间、准确率或共同缺失假设下的推断。自身条件q和全框界使用不同单位集合，不混用分母。

每维分歧文件保存ID、当前原文、来源位置、双方完整原输出及纯来源输入。规则原输出未单设`dimension_reasons`，保留原有证据、抑制、标记和路径，不代写解释；LLM完整理由及证据原样保留。未进入二元表的未知ID逐维另列，并输出共同单位名单、全部源绑定和产物SHA。旧source04变更附表本次未做，未读旧预测。
