# 本轮修复的方法依据

核查日期：2026年10月7日。本文档支持方法选择，不代替项目的实际验证结果。

传统词典工具可以匹配词组、处理嵌套和重叠命中，但这些功能本身不能决定“公平性”“创新性”的研究含义。本轮保留可复现的自动规则，并修复对象、谓词、条件和来源范围的对应关系；不以更换专业软件代替验证。[quanteda官方tokens_lookup说明](https://quanteda.io/reference/tokens_lookup.html)明确区分词典键、最长嵌套匹配和重叠匹配，支持检查重复计数等技术问题，未提供本研究五维概念的现成真值。

LLM的任务是执行本研究的操作定义。Halterman与Keith指出，模型可能沿用预训练中的宽泛概念，而未遵守代码本的具体定义；其框架包括共用代码本、行为测试、带标签评估及错误分析。本轮据此保留完整手册、正反控制、原始响应、逐字证据和独立确认材料。此次没有训练模型权重，不能称为监督微调。该文实证以英文单标签任务为主，本研究中文五维多标签仍需自身验证。[出版社正式论文](https://www.cambridge.org/core/journals/political-analysis/article/codebook-llms-evaluating-llms-as-measurement-tools-for-political-science-concepts/7B323A0E47F782F2698A0AE849EA00DE)

κ检验两份分类判断的一致性；精确率、召回率及F1定位相对参照的误判和漏判；同提示重复及核对顺序微扰检验输出稳定性；注意力占比及配对差检验研究结论对方法的敏感程度。几类证据相互补充，不能互相替代。0.80是本项目工作目标，不能写成期刊通用发表条件。以上论文要求研究者根据下游任务预先确定精度目标，其实证设定本身并非“全部指标至少0.80”的标准。

本轮A、C及第三方均为agent预验证，真实来源在材料和结果中保留。其判例用于培训和定位错误；未来真人验证另用未填写的独立材料执行。κ或方法分布相近不能把agent判断自动转成已完成的真人效度检验。
