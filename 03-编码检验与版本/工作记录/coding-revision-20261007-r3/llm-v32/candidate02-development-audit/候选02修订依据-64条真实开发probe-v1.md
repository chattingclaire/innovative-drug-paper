# 候选01实际开发probe逐条审查与候选02依据

完整阅读64条原句及全部给定语境，逐维审查而非只计一致率。实际与旧r2候选分歧为14条15维（E5/F4/S3/I2/Ec1）；其中12维是本次有原文依据的执行误用或过度排除，3维保留可解释边界。另发现与旧候选一致的00305F仍有普通试验转换机会过判。以上为开发诊断，旧agent候选不是人类真值；所有实际输出和参照二元原值保留。

## 一般修订建议

只补六类对称核对：S需要药物损害/安全内容锚点；E需要效果/获益/实际治疗推荐内容，泛优势与一般指南职责不补效果；创新对象须真实承接，邻句未来计划不回填；已核验专门创新支持的资格/阶段可构成实体支持内容；药物保障目的和渠道设定不能因形式是宗旨/机构遴选而排除；普通受试者更换治疗机会不自动证明获取缺口。并保留明确研究证据用途、治疗空白指代与合法退出后项的边界判读。
