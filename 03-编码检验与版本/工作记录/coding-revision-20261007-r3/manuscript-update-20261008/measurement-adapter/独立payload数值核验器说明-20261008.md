# 独立 payload 数值核验器（仅准备，2026-10-08）

脚本：`independent_verify_adopted_payload.py`。当前仅完成代码准备、语法检查及真实 PENDING 拒绝测试；没有真实完整 payload 数值 QA，没有生成 PASS 证明、采用配置或 ready payload，没有读取 partial03，也没有生成或修改 DOCX。

## 独立重算范围

核验器只使用 Python 标准库，不导入、执行或调用 adapter 的 assemble/metrics，也不调用原统计计算函数。根据实际 root 采用配置读取两个完整 4924 行输出、冻结 metadata、240 条抽样设计中的 180 条概率样本及同版 A/C 参考。完整执行证据必须先通过门禁，才能解析方法标签。

- 独立重算 31 个自动字段，包括两方法身份、规则 15 个部门五维注意力占比、12 个经济性—公平性计数/条件比例字段、15 个部门方向的相同方向数、5 维 A/C 协商前 κ 字符串。
- 对三部门×两方法重算各维阳性句次、五维总句次、精确注意力分数、内容覆盖分数、经济性—公平性四格及 P(F|Ec)。组别来自冻结 metadata，不从标题或 ID 推断。
- 概率样本权重用各层冻结总体数/实际抽样数构造 Fraction；独立累加 TP/FP/FN/TN。κ 使用二乘二行列式公式 `2(TP×TN−FP×FN)/[(TP+FP)(FP+TN)+(TP+FN)(FN+TN)]`，不使用 adapter 的 po/pe 实现。
- 表2核验 5 维×2 方法×A/C×4 指标的 80 个点值；用实际 adopted 方法/参照/维度/概率样本/设计加权 selector 唯一定位来源记录，核对 180 个相同 ID、原始与加权四格。
- 80 个主区间逐项与同一来源记录、JSON pointer 精确对应，核对 5000 次 defined+undefined、NA 状态、端点有限性和指标取值域。**不重跑 bootstrap，不以本核验声称区间覆盖率已获证明。**另核对 5 个 A/C κ 记录及其主区间。
- 表3六行共 30 个百分数、图2六组完整精确分数、15 个部门方向与 payload 逐项一致；相同比例判断使用全部 15 项，两个精确零差异计同向、仅一方零差异计不同向。
- 8 个叙述字段仅核 root 明确批准、非空完整文本、来源 path/SHA、同版方法输出 SHA、同版参考/替换稿绑定。**叙述语义由 root 另行阅读负责**。
- 最后核对 39 字段、52 段完整替换与旧文本 SHA、61 条参考集合绑定及实际输入依赖闭包；所有读入文件在结束前再验 SHA。

## 运行契约

四个路径必须明确指定，不自动搜最新文件，不按分数挑方法。`--adapter` 是实际采用并已写入 payload 输入绑定的 adapter 脚本，核验器只读取它的 SHA，不导入它；因此不得将未来 v2 结果仍绑定成 v1 的 SHA。

```text
python3 independent_verify_adopted_payload.py \
  --adoption /绝对路径/真实root采用配置.json \
  --payload /绝对路径/真实assembled_payload.json \
  --adapter /绝对路径/实际采用的adapter.py \
  --out /绝对路径/全新独立数值QA.json
```

如仅查看结果、不保存报告，使用 `--check-only`，可省略 `--out`。拒绝覆盖已有 QA 文件。PENDING 采用配置会在读取 payload、编码、参考、metadata 或统计前退出 2。真实 payload 缺失、字段不齐、输出不足 4924、参考/统计/封存不匹配或数值不一致，也会阻断；不会补齐或修正输入。

核验成功才输出 `status: PASS`、`all_checks_pass: true` 和精确的 `checked_counts = 39/52/80/80/30/15`，并绑定 adoption SHA、实际 adapter SHA、payload core SHA 和本核验脚本 path/SHA。该 PASS 只意味着本脚本声明的数值、区间来源对应及文本接入核验通过，不改写 payload 状态；由 adapter 在独立复核报告确实存在后另行完成原有 promotion 门禁。

为避免 SHA 相互循环，先封存真实 assembled payload，再对其出独立报告，再以该报告让 adapter 写入**另一个新目录**的 ready payload；不要覆盖核验报告所绑定的初始 payload。
