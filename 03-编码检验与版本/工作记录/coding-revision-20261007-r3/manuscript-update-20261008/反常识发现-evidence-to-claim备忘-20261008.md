# 反常识发现：evidence-to-claim备忘

有可推进论文的经验发现：**医保经济性议题份额更高，卫健的经济性内容却更常伴随公平性表达。** 新知识是特定药品语料中的部门内容组合差别，尚不能说它推翻了既有学术常识。绑定规则v36.2与完整冻结LLM02，不涉及candidate03部分结果。

|指标|规则：医保/卫健|LLM02：医保/卫健|
|---|---:|---:|
|经济性注意力占比：Ec/五维编码合计|610/994＝61.37% / 31/163＝19.02%|682/1170＝58.29% / 31/168＝18.45%|
|经济性单元中公平性比例：联合/Ec|125/610＝20.49% / 14/31＝45.16%|145/682＝21.26% / 13/31＝41.94%|

这不是“换分母可以逆转”的数学发现：两指标本无必然同序。可检验的增量在于，这一特定维度组合在两部门确实呈现不同排序，且现有两方法、分别6种定义与56种构成检查保持方向。卫健全部单元的F覆盖率反而略低，因此核心结果也不是“卫健整篇更常谈公平”的重述。

政策证据支持用途解释，但并不替比例背书：卫健2021-07-21指南“可及性评价”要求“了解医保报销情况以判断患者实际支付水平”（01155，p0041_02），并以用药费用/家庭收入描述可负担性（01157）；医保2025目录FAQ附件5物理p21—22解释基金与个人共同支付（00752），p11又把临床使用监测、基金支付及可及性相连（00647）。故支付与供用路径有交叉，不能写成两部门互斥分工。[卫健正式原文](https://www.nhc.gov.cn/yaozs/c100097/202107/d2a45e6ae041423f950b3865e43f5ef6.shtml)、[医保正式公告及附件](https://www.nhsa.gov.cn/art/2025/7/10/art_109_17198.html)。

史录文访谈纪要P015的“医保进了，医院不一定用”补充衔接问题，正文日期为2025-06-09；匿名医保调研纪要P003的成本—疗效比较、P009的群体保障与个体治疗机会张力，可解释多价值安排。它们是纪要文字，非已核音频逐字稿；后者年份/发言者不明。准入不等于使用已有研究和官方认识，不能冒充新发现，访谈也不能验证比例、发生率或因果。

需要保留四个竞争解释：①医保目录价格/基金条款与卫健指南可负担条款构成不同的Ec子集；现有等权、逐文件剔除不等于文件内匹配控制。②F是含可负担的宽保障获取构念，与Ec有概念交集；卫健官方可及性本来合列价格/获取/负担。③一些单元含父谓词或多项列表，应称“同一分析单元”，不能从共现推断实际决策取舍。④卫健Ec仅31个单元，双机器共用手册的误差与真人联合判读效度仍待检验。

现阶段可以称**固定语料的探索性描述差异**，不能称显著、因果、患者公平结果或全球首次。反向条件比、OR与覆盖率只作分母/尺度诊断；不新增第二个“反常识发现”。六定义、56构成是两组口径检查，不是336交叉情景或62次独立验证；规则构成情景的最小条件比例差仅2.58个百分点。

可进入结论的三句（仅限当前版本，待最终完整同版采用核对）：

> 本研究在固定药品政策语料中识别出关注份额与内容组合的不同部门排序：医保经济性注意力占比更高，卫健经济性单元中公平性共同表达的比例更高，现有规则与完整LLM02均保留这一方向。相较已有部门工具比较与医保多价值框架，本研究具体补充了同名评价内容在不同部门文本中的组合差别，而非仅重复职责分工。相关条文与访谈为支付、患者负担、供应和使用环节的衔接提供解释依据，协调建议据此落实为这些信息的联通。
