## 技术附录建议（不计入正文替换字数）

**actual_functions**：statistical_core_r3.replicate_factors / comparison / interval; final_attention_r3 uses paired weight factors for nonlinear attention ratios.

**design**：h∈{NMPA,NHSA,NHC}, N_h∈{947,760,60}, n_h=60, m_h=59, f_h=n_h/N_h; d_hi=N_h/n_h.

**counts**：For each b=1,...,5000 independently within h, M_h^(b)~Multinomial(59;1/60,...,1/60).

**factor**：a_hi^(b)=1+sqrt(1−60/N_h)*[(60/59)M_hi^(b)−1]; w_hi^(b)=(N_h/60)*a_hi^(b).

**estimand**：Multiply each paired binary confusion-cell indicator by w_hi^(b), sum within group/pooled groups and recompute κ/P/R/F1 from those replicate cells. This is not resampling already computed κ values or treating weighted cells as an independent expanded census.

**pairing**：Same component,group,sorted paired IDs reuse factors across methods/references/dimensions; source-file sensitivity uses separate factors.

**percentile**：For each metric retain finite replicate values and apply numpy.quantile at0.025 and0.975 (default linear interpolation). Store defined_repetitions and undefined_repetitions; if none defined both endpointsNA. These are approximate pointwise intervals; not simultaneous familywise intervals, BCa, studentized, or exact rare-category coverage.

**census**：NHC n=N=60 implies all a_hi=1; point-degenerate design intervals describe this frame census conditional on fixed labels, not zero semantic or generalization uncertainty.

**seeds**：BASE_SEED=2026100731; local seed=(BASE_SEED+int(SHA256("/".join(component,mechanism,"/".join(ids))) first8hex,16)) mod2^32; numpy.default_rng.
